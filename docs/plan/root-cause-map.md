### 根4 値段の合図が届かない

**何が根か**: 売りが 0 の財は島の値段が前のまま残るので、買い手がいくら払う気でも値段に出ません（綿花）。逆に、少ない量では値段が動かず取引が止まります（自動車・機械）。家計の電気は「予算を 1 円でも超えたら層の全員が 0」という崖でした。
