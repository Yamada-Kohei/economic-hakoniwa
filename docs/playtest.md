# 試し遊びの手引き（AI エージェント向け）

経済版箱庭諸国を、プレイヤーとして遊んで確かめるための資料です。Codex などの AI エージェントが読む前提で書いていますが、
人が読んでもかまいません。コードを直すための資料ではありません。**試し遊びではコードを変えません。**

これまで Claude が「クロード連邦」という国でターン 333 まで遊び、およそ 50 ターンごとに報告を書いてきました。
この資料は、その遊び方・決まり・分かっていることを、ほかのエージェントが引き継げるようにまとめたものです。

## 1. このゲームのあらまし

箱庭諸国の流れをくむ島の育成ゲームです。1 人が 1 つの島（32×32 マス）を持ち、命令を並べてターンを進めます。
いまはロードマップの **フェーズ2-3** まで入っています（フェーズ3 で政治・経済体制と島どうしの貿易、フェーズ4 で軍事の予定）。
貿易と軍事はまだないので、「ない」ことは報告しなくてかまいません。

ねらいは「なるべくリアルな経済」です。

- **生産の連鎖**: 鉄鉱石と石炭 → 製鉄所で鋼鉄 → 機械工場で機械 → 新しい工場の資材、のように施設がつながります。
  鋼鉄には鉄鉱石と石炭の両方が要り、地下資源は建国のときに 2 つまで選びます。鉱山は 1 国 2 つまでです。
- **市場**: 資源は施設ごとの在庫として、資源ごとの市場（板寄せ）で毎ターン売り買いされます。値段は売れ行きで 1 ターンに最大 1 割動き、
  施設は売れ行きに合わせて作る量を変えます。運賃は売り手と買い手の道のりで決まります。
- **人とお金**: 住民は町から通勤圏の施設に働きに行き、賃金で食料・消費財・電力を買います。政府は税を集め、公務員の賃金・公共事業・
  失業手当に使い、足りなければ国債を出します。お金は複式の帳簿で動きます。
- **金融**: 中央銀行・銀行・融資・国債の入札・倒産・民営工場と民間銀行の参入・補助金・国有化と民営化があります。
- **インフラと教育**: マスごとに道路・鉄道・上下水道・送電網の整備度があり、公共事業で整えます。学校と大学で教育水準と技術者が育ちます。
- **行政力**: 1 ターンに実行できる命令の数です。原則 1 つで、中央省庁の公務員が増えると最大 5 つまで増えます。名前の変更は数えません。
- **体制**: 政治体制（民主主義・権威主義・全体主義）、元首制度（君主制・共和制）、経済体制（市場経済・混合経済・計画経済）を建国で選びます。

くわしいしくみは、ゲームの中の **「手引き」（`/help/`）** にあります。遊び始める前に必ず全部読んでください。
施設ごとの労働者・原料・生産物の表もそこにあります。命令の中身の形は [`packs/base/data/orders.yaml`](../packs/base/data/orders.yaml)、
数値は [`packs/base/data/`](../packs/base/data/) と [`game.yaml`](../game.yaml) にあります。

## 2. 遊ぶ場所

### A. 自分の環境に建てたサーバー（既定）

リポジトリをそのまま動かします。LAN のサーバーにはつながなくてよく、ターンも自分で進められます。

```sh
pip install -e ".[dev]"
python manage.py setup_dev                 # DB とサンプルの島 3 つ（ターン 0）
python manage.py runserver 127.0.0.1:8000  # 別の端末か、後ろで動かす
```

- アカウントは `codex`、国名は「コーデックス共和国」にします（頼む人が別の名前を言ったらそれに従う）。
- ターンは `python manage.py run_turn --force` で 1 つ進みます（ターン 0 の島で 1 回 0.4 秒ほど）。
- やり直したいときは `db.sqlite3` を消して `setup_dev` からやり直せます。
- 環境は作業ごとに消えることがあります。そのときは建国からやり直し、前の報告の「引き継ぎ」を読んで、前と違う遊び方を選びます。
- 世界がいつも新しいので、**建国から 50〜100 ターンの序盤** を確かめるのに向いています。クロード連邦はターン 333 まで進んでいるので、重なりません。

### B. LAN のサーバーの Codex 用の世界（頼まれたときだけ）

1 つのサーバー（1 つの DB）には世界が 1 つだけです。2 つ目の世界は、同じコードを別の DB と別のポートで動かして作ります。
セビーリャさんの家の LAN の中のサーバーに、Codex 用の世界を置く形です（作るのはセビーリャさんか Claude）。

- 届くのは LAN の中のパソコンで動くエージェントだけです。**アドレスや資格情報を、外に出したりリポジトリに書いたりしません。**
- アドレスとアカウントは頼む人が教えます。道具には `--base` でアドレスを渡します。
- この世界は Codex のものなので、ターンは自分で進めてかまいません（進め方は頼む人が教えます）。
- 世界は消えずに残るので、前の報告の「引き継ぎ」から続けられます。
- 管理画面や DB の直接の変更で、世界を書き換えることはしません（ターンを進めるのは除く）。

### C. クロード連邦と同じ世界（頼まれたときだけ）

LAN のサーバーの、クロード連邦やセビーリャさんの国がある世界です。ほかの国と同じターンで動くので、**ターンは進めません。**
命令を並べて、ほかの人が進めた後の結果を読む、を繰り返します。アカウントは管理画面で作ってもらいます
（同じ接続元からの登録は 1 件までのため）。

## 3. 道具

[`tools/playtest/hk.py`](../tools/playtest/hk.py) は、ブラウザを使わずに遊ぶための小さな道具です（Python の標準ライブラリだけ）。
ログインの cookie はホームの `.hk-cookies.txt`（`HK_COOKIES` で変えられる）に置きます。リポジトリの中には置きません。

```sh
H="python tools/playtest/hk.py"            # B・C のときは --base <教わったアドレス> を足す
$H signup codex '<パスワード>'              # A のとき。作るとログインした状態になる
$H login codex '<パスワード>'               # 2 回目から（HK_USER・HK_PASSWORD でも渡せる）
$H found --name コーデックス共和国 --resources iron_ore,coal --economy market
$H map 4                                   # 島 4 の文字の地図と施設の一覧
$H page /islands/4/ 出来事 1500            # 画面を文字にして、「出来事」から 1500 字読む
$H page /islands/4/log/                    # ターンログ
$H check 4 '{"kind":"build","payload":{"facility":"farm","x":14,"y":12}}'
$H orders 4                                # 並んでいる命令と行政力
$H orders 4 @orders.json                   # 命令の列を丸ごと置き換える（JSON の一覧）
$H get /api/islands/4/economy              # API の JSON
```

`found` はランダムな形と勧められた首都で建国します。形や地形を選びたいときは、ブラウザの建国の画面（`/found/`）を使ってもかまいません。
島の番号は `found` の出力か `$H get /api/world` の `mine` で分かります。

読むと役に立つ画面と API（`<id>` は島の番号）:

| 場所 | 中身 |
|---|---|
| `/islands/<id>/` | 島の画面。地図・出来事・命令の列・政策 |
| `/islands/<id>/log/` | ターンログ。施設が止まった理由、命令の結果、民間が参入しない理由 |
| `/islands/<id>/economy/` | 国勢の一覧と推移（人口・失業率・物価・GDP・教育水準など） |
| `/islands/<id>/market/`・`facilities/`・`fiscal/`・`finance/` | 市場・施設の収支・財政・金融の画面 |
| `/api/islands/<id>/map` | 地形・施設（`status` と `rate`）・人口・整備度（`infra`）・工事の列 |
| `/api/islands/<id>/tiles/<x>,<y>` | 1 マスの中身。工事が進まないわけも出る |
| `/api/islands/<id>/economy` | 指標の推移（`series`） |
| `/api/islands/<id>/market/<資源>` | 約定の相手と、買えずに止まった施設 |
| `/api/islands/<id>/finance` | 銀行・融資・国債 |
| `/api/defs` | 施設・資源・命令・体制の定義と表示名 |

A では、DB を読むだけなら `python manage.py shell` も使えます。統計の記録は `StatRecord`（島・ターン・`name`・値）です。
`fiscal.in.*`・`fiscal.out.*`・`layer.*`・`bonds.*`・`volume.*` などが原因探しに役立ちます。

## 4. 遊び方の決まり

1. **コードは変えません。** 不具合を見つけても直さず、報告に書きます。直すのは Claude の担当です。
   道具（`tools/playtest/`）の小さな直しだけは、別の PR にしてかまいません。
2. 命令を並べる前に `check` で確かめます。建設の `check` は通勤圏の人手も返すので、人が集まるかが分かります。
3. 数ターンずつ進め、ターンログと出来事を読んでから次の手を決めます。何十ターンもまとめて進めると、原因が追えなくなります。
4. **およそ 50 ターンごとに報告を書いて区切ります。** 報告の終わりに「引き継ぎ」を書き、次の作業はそこから始めます。
5. 数字は画面・API・記録から取り、原因の見立てはコードを読んで書きます。見立てと確かめたことは分けて書きます。
6. ふつうのプレイヤーができることだけで遊びます。管理画面で世界を変える、DB を書き換える、などはしません（A・B でターンを進めるのは除く）。
7. 同じ遊び方を繰り返すより、まだ誰も試していないことを選びます（下の「まだ試されていないこと」）。

## 5. 見つけた点の分け方

ゲームの方針は「なるべくリアルにする。リアルさから来る難しさは残し、不具合とプレイが止まることは直す」です（2026-10-13 に決定）。
報告では、見つけた点を次の 3 つに分けます。

| 分け方 | 例 |
|---|---|
| **直したほうがよいもの**（不具合・プレイが止まる・理由が画面に出ない） | 民間の工事が資金不足で止まったまま残り、やめる決まりも働かない。止まった理由の表示が実際の理由と違う。ログのない状態の変化 |
| **決めていただきたいもの**（不具合か難しさか、自分では決めきれない） | 国債の評価益がそのまま配当として国庫に入る。移し替えで引かれた道路の維持が建材をほとんど使う |
| **難しさのうち**（現実にも起きる、遊び方の結果） | 工事を並べすぎて資材の値段が上がる。農場を建てすぎて穀物が余る。利上げで銀行が傷む |

すでに決まっていて、**報告しなくてよいもの**:

- 消費財の値段が家計の上限（直近 12 ターンの平均の 1.05 倍）を超えて、ほとんど売れないターンがある → 難しさとして残す（2026-10-14 に決定）。
- 国の工事の入札に値段の上限がない（資材の値段を毎ターン上げて買う）→ 上限は付けない。
- 石炭か鉄鉱石の出ない島の消費財と失業 → フェーズ3 の貿易で手当てする。
- 貿易・軍事がないこと → フェーズ3・4 の予定。

## 6. 分かっている点（2026-10-14、ターン 333 の時点）

クロード連邦の報告で見つかって、まだ直っていない点です。同じものを見つけたら、新しく報告せず「6 章の 3 を再現した（ターン・場所・数字）」とだけ書きます。
直ったかどうか分からないときは、確かめて書いてもらえると助かります。

1. 国が建てた銀行の名前が、いくつ建てても同じ（例「オーパス銀行公社」）。金融の画面でマスの位置も出ないので、破綻した銀行を見分けられない。
2. 国庫がターンの途中で一時的に空になると、学校と大学が「賃金を払うお金が足りず停止」し、教育水準の目標が 0% になって 1 ターンで 8 ポイント下がる。
3. 「都市に発展しました」が、都市になってから 20 ターンほど後に出る（見た目が変わる人数で知らせている）。
4. フェーズ2-3 への移し替えの後、幸福度が理由の出ないまま 12 ターンかけて下がる（重みの切り替え。上下水道のない島は 5 点減る）。
5. 技術者の「働いている人」が総数を超えるターンがあり、技術者の失業率が 0% と出る。
6. 工事の「公共事業費が足りず」が、予算の使った額と合わない（注文のときの取り置きで上限に届く）。
7. 穀物が余っていても、食品工場が「穀物不足で停止」と出る（実際は売れ行きに合わせた生産の調整）。
8. 学校が最初のターンに教材（消費財）不足で止まる。建国したばかりの島でも起きる。
9. 国債の政策を変えたログに、変えた項目が出ない。
10. 鉱山が上限でも、山のマスの建設の欄で鉱山が初めに選ばれる。

決めてもらうのを待っている点（新しく見つけたら、同じく番号だけ書く）:

11. 国債の値上がり益が配当と法人税で国庫に入り、値下がりでは国営銀行が破綻する。利回りが 1 ターンで 6 ポイント動く。
12. 移し替えで引かれた道路の維持が、島の建材をほとんど使う。
13. 利払いを止めた次のターンに、利回り 9% ほどで国債を新しく売れる。借金が減る分のほうが大きく、不履行が得な手に見える。

## 7. まだ試されていないこと

クロード連邦は権威主義・共和制・混合経済、地下資源は鉄鉱石と石炭です。LAN の世界にはセビーリャさんの市場経済の国もあります。
国債の利払いの停止と立ち直り、破綻した銀行の救済、中央銀行の国債の買い入れ、国が建てる銀行は、ターン 333 までに試されています。
序盤から遊んだ記録は、フェーズ2-3 より前の古いコードのものです。次のことは、まだ誰も確かめていません。

- 建国から 50 ターンほどの序盤（フェーズ2-3 のコードで）。標準の始まり方で国が立ち上がるか、どこで詰まるか。
- **計画経済** の島（倒産が起きない、民間が参入しない、などが手引きどおりに動くか）と、民主主義・君主制の組み合わせ。
- 地下資源の組み合わせ（石材と石炭、石材と鉄鉱石など、鋼鉄を作れない島）。
- 中央銀行の独立、銀行が 1 つしかない島の破綻処理、破綻処理の「清算」。
- 国有化・民営化、救済補助・生産補助、電気料金の上限、国の倉庫の売買。
- 地図の重ね表示（インフラ・運賃・工事）をブラウザで見ること。画面を撮れるなら撮る。

## 8. 報告の書き方

ファイル名は `report-turn<最後のターン>.md`、日本語で書きます。A では作業の最後の返事に全文を書きます（ファイルを PR にはしません）。
B・C では頼んだ人が言う場所に置きます。

```markdown
# <国名> 試し遊びの報告（ターン <始め>〜<終わり>）

（どのコード（main のコミット）で、何ターン進めたか。ターンの更新が止まったか。体制と地下資源）

## 直したほうがよいもの（不具合・理由が見えない）
1. **一文で何が起きるか。**
   - 経過: ターン・マス・数字
   - 原因の見立て: 読んだコードの場所（`path/to/file.py` の関数）
   - 案（あれば）

## 決めていただきたいもの（不具合か、難しさか）

## うまく動いたもの
（試した命令や仕組みで、手引きどおりに動いたもの）

## 難しさのうち（遊び方の結果）

## まだ試していないもの

## 数字の推移
| | ターン … | … |
|---|---|---|
| 人口 / 就業者 / 失業率 / 幸福度 / GDP / 物価指数 / 国庫 / 国債の残高 | … | … |

---

## 引き継ぎ（ターン <終わり>）

### 入り方
（A・B・C のどれか、アカウント名、島の番号、建国の種。資格情報そのものは書かない）

### 国の今の状態
（人口・失業率・幸福度・国庫・国債・施設の数・政策・予算・並べてある命令）

### 次にやること

### まだ直っていない点の一覧
（この報告で見つけたものと、6 章から残っているもの。6 章の点は番号で）
```

書き方のこつ:

- 1 つの点に 1 つの番号。「何が起きるか」を先に、一文で書きます。
- ターン・マス `(x, y)`・数字を必ず付けます。読んだ人が同じ場面を探せるようにするためです。
- 自分の手の結果（建てすぎた、税を下げすぎた）は「難しさ」に入れ、そう書きます。
- 6 章の点に当たったら、その番号を書きます。
