## 気になっている点

**地下建設の画面は `/api/defs` の追加対応待ち。** `packs/base/data/facilities.yaml` には `hide` があるが、`server/web/api.py` の `_facility_def()` が `hide` を返していない。現在の応答では、ミサイル基地と核施設を選んでも地下建設を有効にできない。画面には選べない旨を表示し、工期と資材倍率の複製・固定値は持たせていない。

Claude 側で、対象施設の定義に次の欄を含めてほしい。ほかの施設には不要。画面はこの欄が入ればチェックを表示する。

```json
{
  "hide": {
    "turns": 8,
    "materials_factor": 2
  }
}
```

これはミサイル基地の現行定義の例。核施設はその施設の定義の値を返すこと。画面はどちらも同じ処理で扱い、施設の切り替え時にチェックを解除する。

## Chromium で確認してほしいこと

1. 持ち主と他国の軍の画面。外国にいる部隊、空の一覧、捕虜、占領、降伏後の体制選択。在庫と上限。スマートフォン幅でページ全体が横にはみ出さず、表の中だけ横へ送れること。
2. 母港と外洋の輸送船団。外国への上陸と補給、取り立て、備蓄目標。軍の画面・世界マップの両方の艦隊の務め。封鎖できない理由が命令の列に出ること。
3. 自国の基地から相手の地図へ進み、マスを選ぶだけでは命令が増えないこと。座標・基地・数を確かめて追加し、自国の軍の命令列と結果に出ること。核のチェック時に赤い表示と確認文が出て、取り消すと追加されないこと。
4. 汚染がない・薄い・濃いマス、占領と建物の重なり、所有者の「地下」の印。隠した施設の非所有者への見え方は API の応答どおりであること。
5. `hide` の API 追加後、対象 2 施設だけにチェックが出ること。工期と倍率を表示し、建設の事前確認と追加の両方で `hidden: true` を送ること。ほかの施設へ切り替えると指定が消えること。
6. 外交の「核を持たない約束」の選択・予告期間・条約一覧・違反理由と、戦争中に提案した場合の API の理由表示。手引きの内容と見出し。
