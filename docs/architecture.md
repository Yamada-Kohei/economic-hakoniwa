# 全体の構成

```
ブラウザ（server/static, server/templates）
   ↓ HTML と JSON API
Django（server/）……保存・アカウント・命令の受付・ターン更新の実行
   ↓ 状態を渡して計算させる
コア（hakoniwa_core/）……ルール本体。Django も DB も知らない
   ↓ 読む
定義データ（packs/、schemas/、game.yaml）
```

## コア（hakoniwa_core）

| 場所 | 中身 |
|---|---|
| `config.py` | `game.yaml` の読み込み |
| `defs/` | パックの読み込みと検証。結果は書き換えられない `Defs` |
| `state/` | 世界・島・マス・命令の状態（`WorldState` など）と、JSON との変換 |
| `registry.py` | モジュールが登録する段・命令・式の形 |
| `modules/` | 標準のモジュール（段・命令・式）。一覧は [modules.md](modules.md) |
| `ledger.py` | お金の帳簿（複式の仕訳）。お金はここを通してだけ動き、毎ターン4つの確かめをする |
| `market/` | 板寄せ（財の市場と電力で使う） |
| `economy/` | お金の経済の部品（初めの値段と変動費、払えるお金の取り置き、国債、運賃、家計の層、収支の記録、物価指数、経済の始まりと移し替え） |
| `units.py` | 量・お金・率の単位と丸め |
| `turn/` | 段の進行役（`Engine`）、段に渡すもの（`StageContext`）、乱数 |
| `founding.py` | 建国: 形と地形の検査、描いた形からの自動の地形、首都と最初の施設・町・村の配置 |
| `facilities.py`・`stock.py`・`allocation.py`・`geo.py`・`naming.py` | モジュールが共通で使う道具（施設の定義、倉庫、優先順位での配分、距離と道、名前） |
| `autoplan.py` | 試験と一括シミュレーション用の「標準の計画」 |
| `gate.py` | フェーズ2の関門の目安と、一括シミュレーションでの確かめ |
| `orders.py` | 命令の検証（受付時と実行時の両方で使う） |
| `log.py` | ターンログの文面づくり |
| `game.py` | 設定・定義データ・モジュールをまとめて組み立てる `load_game()` |
| `simulate.py` | 画面も DB もなしで回す一括シミュレーション |

## 1回のターン更新

1. cron などが `manage.py run_turn` を呼ぶ。次の更新時刻になっていなければ何もしない。
2. 更新中の印を立てる（その後に届いた命令は次のターンに回る）。
3. DB から世界全体を `WorldState` に読み込み、写しをバックアップに取る。フェーズ1のままの島（お金の
   経済がまだない島）があれば、ここでお金と経済を始める（移し替え。`economy/start.py`）。
4. `game.yaml` の `stages:` の順に段を実行する。
5. 変わったものだけを書き戻し、ターンログと統計、お金の勘定と帳簿の記録を足し、ターン番号を進める。

3〜5 は1つのトランザクションです。途中で失敗したら何も書かず、ターンも進めず、管理者にメールします。

## Django のアプリ

| アプリ | 中身 |
|---|---|
| `accounts` | 登録・ログイン。同じ接続元からの重複登録の制限（IP は秘密鍵で混ぜたハッシュで、決まった日数だけ持つ） |
| `world` | 世界・島・マス・施設・在庫・統計のモデル、DB とコアの変換（`repository.py`）、建国（`services.py`） |
| `economy` | お金の勘定・国債の銘柄・仕訳・約定・市場の記録・施設の帳簿のモデル（フェーズ2） |
| `orders` | 命令のモデル |
| `turns` | ターン更新、バックアップと巻き戻し、ターンログ |
| `web` | 画面と JSON API。表示の文面づくりは `display.py`（ルールの計算はしない） |
| `board` | 掲示板（読むのは誰でも、書くのは登録した人だけ。管理画面で書き込みを非表示にできる） |

DB の表は、マス（`Tile`）・施設（`Facility`）・在庫（`Stock`、国の倉庫は施設なし。作られたターンごとの行）・
統計（`StatRecord`、ターンごとの人口・生産量・GDP・物価など。島・指標・ターンの索引で、指標ごとの系列を引く）です。島と施設の経済の状態と政策は、それぞれの
`economy`・`policy` の JSON の欄に入ります。書き戻しは変わった行だけで、在庫だけは島ごとに消して書き直します。

お金は `economy` アプリの表に入ります。勘定（`Account`、名前と残高）と国債の銘柄（`Bond`）は毎ターン島ごとに
書き直し、仕訳（`JournalEntry`）・約定（`Trade`）・施設の帳簿（`FacilityBook`）は `game.yaml` の
`records.*_turns` のターン数だけ残して古いものを消します。市場の記録（`MarketRecord`、財ごとの値段と売買量）は
消しません。巻き戻すと、戻した先より後の記録を消します。

## 画面

| URL | 画面 |
|---|---|
| `/` | 島の一覧と、自分の島・建国への入口 |
| `/found/` | 建国（区画・形・地形・資源・体制・名前を選ぶ） |
| `/islands/<id>/` | 島の俯瞰図、マスの情報、命令の列、島のようす（GDP・物価・失業率・国庫など）、財の表（値段と売買量）、最新の出来事 |
| `/islands/<id>/economy/` | 経済: 主な指標（GDP・物価上昇率・失業率・政策金利・財政の収支・教育水準・技術者・電力の不足率）と、その推移のグラフ。好きな統計を選んでグラフにする欄 |
| `/islands/<id>/market/` | 市場: 財ごとの値段・売買量・買いたかった量・売りたかった量の表と推移。持ち主には約定の相手と、原料を買えずに止まった施設も |
| `/islands/<id>/facilities/` | 施設: 国全体の施設の統計と推移。持ち主には施設ごとの労働者・技術者・稼働率・損益・預金・借入の表と、施設ごとの帳簿の推移 |
| `/islands/<id>/fiscal/` | 財政: 国庫の収入と支出（国債の発行と償還は分けて出す）、予算と使った額、税率、国債の一覧と推移。持ち主には税・予算・労働・国債・補助金の命令の欄も |
| `/islands/<id>/finance/` | 金融: 中央銀行の方針、金利・お金・融資の統計と推移。持ち主には銀行ごとの帳簿、破綻処理・緊急の貸し出し、金融の命令の欄も |
| `/islands/<id>/log/` | ターンログ（ターンごと） |
| `/world/` | 世界マップ |
| `/board/` | 掲示板 |
| `/help/` | 手引き（施設と命令の表は定義データから作る） |

画面の JavaScript は `server/static/js/` にあり、ビルドなしの ES モジュールです。
`map/` が俯瞰図（`overlays/` に重ねて表示する情報を1ファイルずつ足せる）、`island/` がマスの情報と命令の列、
`founding/` が建国の画面です。`chart/` は外部のライブラリを使わない小さな折れ線グラフ、`reports/` は
経済・市場・施設・財政・金融の画面です（命令の欄は `island/` の命令の列をそのまま使い、今の列の後ろに足す）。
他国の人にも5つの画面は見せますが、施設の帳簿・約定の相手・銀行ごとの中身・命令の欄は島の持ち主だけです。

## JSON API

| URL | 中身 |
|---|---|
| `GET /api/defs` | 画面が使う定義データと表示名、建国の設定、テーマ |
| `GET /api/world` | 世界マップの島の一覧 |
| `GET /api/world/shapes` | 世界マップに1マス1ピクセルで描く、島ごとの地形と町・施設の並び |
| `GET /api/islands/<id>/map` | 島のマス（地形・人口・開発禁止・送電線・汚染・幸福度・電力・インフラの種類ごとの整備度を y × size + x の順に並べたもの）、インフラの工事の列と止まっているわけ、施設。`?freight=1` のときだけ、陸のマスごとの拠点までの運賃の率も（計算が重いので） |
| `GET /api/islands/<id>/tiles/<x>,<y>` | 1マス（インフラの整備度と維持の目標、並んでいる工事を含む）と、そこにある施設の詳しい情報（技術者・学校と大学の働きを含む） |
| `GET /api/islands/<id>/economy` | 統計の系列。`?names=gdp,price.*`（末尾の `*` はその頭の統計すべて）`&from=&to=`（ターン。決めなければ直近の 120 ターン）。財政の収支と層ごとの1人あたりの所得は計算して返す。銀行ごとの統計は持ち主だけ |
| `GET /api/islands/<id>/market/<財>` | 財の値段と量の推移と直近の市場。持ち主には直近のターンの約定（買い手と売り手の組ごと）と、買えずに止まった施設も |
| `GET /api/islands/<id>/facilities/<番号>/book` | 施設の帳簿の推移（収支の項目・預金・借入・在庫の値打ち）。島の持ち主だけ（ほかは 403） |
| `GET /api/islands/<id>/finance` | 金融の統計と中央銀行の方針。持ち主には銀行ごとの帳簿と金融の政策も |
| `GET /api/islands/<id>/orders` | 待っている命令の列、次のターンの行政力、最近の命令の結果 |
| `PUT /api/islands/<id>/orders` | 命令の列を丸ごと置き換える（島の持ち主だけ）。形の誤りは 400、今の島では実行できない命令は警告 |
| `POST /api/islands/<id>/orders/check` | 命令を1つ、今の島の状態で確かめる |
| `GET /api/founding/cells` | 建国で選べる空いた区画 |
| `POST /api/founding/random-shape` | ランダムな島の形 |
| `POST /api/founding/terrain` | 描いた形から配った地形、形の問題、首都の候補 |
| `POST /api/founding` | 建国する（1人1島） |

書き込み（PUT・POST）には Django の CSRF の印が要ります。
