# 6 国の財政と政策

政府の収入と支出、税、年の予算、国庫が足りないときの支払いの順番と遅配、国の倉庫、産業政策（関税・輸出補助・輸入の割り当て・禁輸）を扱います。国債と中央銀行と銀行の救済のお金の動きはタブ 7、補助金の受け取り方と国有化・民営化はタブ 5、失業手当と最低賃金の効き方はタブ 4、公共事業と教育の中身はタブ 8、貿易の荷の流れはタブ 9、議会と経済体制はタブ 10 を見ます。

## コードの場所と試験

- 税と予算: `hakoniwa_core/modules/fiscal/`（段 `budget`、命令 `set_taxes`・`set_budget`）
- 国庫の取り置きと支払い: `hakoniwa_core/economy/funds.py`（`commit`・`pay`・`available`）、遅配は `hakoniwa_core/economy/arrears.py`
- 国の倉庫: `hakoniwa_core/modules/market/` の `warehouse_trade`・`_warehouse_orders`（命令 `set_warehouse_standing` と `economy/standing.py`）、`hakoniwa_core/stock.py`
- 産業政策（関税・輸出補助・輸入の割り当て・禁輸）: `hakoniwa_core/trade/policy.py`
- 行政力: `hakoniwa_core/modules/planning/` の `admin_power`
- 試験: tests/core/test_finance.py、tests/server/test_economy.py、tests/core/test_trade.py

## つながり

- 前提にしていること: 税の元（タブ 4・5・7）、国債と中央銀行（タブ 7）、政府の買える市場（タブ 3）、議会の採決（タブ 10）、公務員・教員・警察官（タブ 1・8・10）。
- 前提にされていること: 公共事業とインフラ（タブ 8）、失業手当と遅配（タブ 2・4・10）、国庫直轄の施設と補助金（タブ 5）、国債の発行量（タブ 7）、商社の輸入の判断（タブ 9）。
- 詳しくは下の「前提と依存」。

| 所得税（`fiscal.income_tax`。賃金から差し引く） | 公務員・教員・警察官の賃金 |
| 法人税（`fiscal.corporate_tax`。施設と銀行の利益。赤字は `firms.loss_carry_turns` 繰り越せる） | 失業手当（`fiscal.unemployment_benefit`） |
| 消費税（`fiscal.consumption_tax`。家計の買い物と電気） | 国庫直轄の施設の費用（仕入れ・賃金・電気代・運賃） |
| 関税 | 公共事業（工事と維持の資材と賃金） |
| 国庫直轄の施設の売上 | 教育（学校と大学の教員の賃金と教材） |
| 国営の独立採算の施設と国営銀行の納付 | 治安（警察官の賃金） |
| 中央銀行の納付（利益の全額） | 補助金と輸出補助 |
| 国の倉庫の売上 | 国債の利払いと償還 |
| 国債の発行 | 国有化の代金、銀行の救済と預金保護、国の倉庫の買い入れ |

- 政府のお金は中央銀行にある国庫の口座だけで、足りない分は国債で借りる。お金はすべて帳簿の仕訳で動く（タブ 1・7）。
- 税率は命令で変え、次の段から効く。民主主義の国で税を大きく変えるときは議会の賛成が要る。
- 中央銀行の納付で国債の利子が国庫に戻る（中央銀行の持つ国債の利払いは、実の重さにならない。タブ 7）。

### 予算

- 公共事業費・住宅費・教育費・治安費・補助金・国の倉庫の買い入れは、命令で年の額を決め、毎ターンその12分の1まで使う。使い残しは持ち越さない。
- 住宅費（W-190 の回で作る。FS-26）は、国が町の床を足す資材（命令「住宅を建てる」と、計画経済の国の町の育ち）と国の床の手入れに使う。国の床に住む層は家賃を払う（FS-27。ソ連の国営住宅の家賃は家計の支出の 3% ほど）。町の床と国営住宅の形はタブ 2。
- 公共事業費は優先度の高い工事から、作業員の賃金と資材の代金の両方に充てる（タブ 8）。教育費は学校と大学の教員の賃金と教材、治安費は警察官の賃金（タブ 10）。
- 建国のときの年の予算は、住民1人あたりの決めた額（`fiscal.budget.*`）で、教育費は学校の運営の `education.start_budget_years` 分。治安費・補助金・国の倉庫は 0 から始まる。住宅費は計画経済の国だけ住民1人あたりの決めた額で、市場・混合の国は 0 から。
- 公務員の賃金、失業手当、国庫直轄の施設、国債は予算を決めず、要るだけ払う。
- 政府の買い物は、ほかの買い手と同じく市場の板寄せで買う。売りに出ていない物にはお金を取り置かない（取り置きでほかの支払いを止めないように）。

### お金が足りないときの順番と遅配

- ターンの初めに、前のターンの実績から各項目の支払いを `fiscal.reserve_margin` だけ多めに見積もり、国庫の残高を `fiscal.payment_order` の順に取り置く。各段は取り置いた額を上限に払う。
- 順番は、国債の利払い（償還は借り換えで払う。払えなければ債務不履行。タブ 7）→ 今月の人件費と運営費の組（公務員・国庫直轄の施設・教育・治安）→ 失業手当 → 昔の未払い賃金 → 公共事業（維持が先、新しい工事が後）→ 住宅費（手入れが先）→ 補助金 → 国の倉庫の買い入れ。
- 組の中は、国庫が見積もりの合計に足りなければ、見積もりに同じ割合を掛けて取り置く。国営の穀物の農場だけが押し出されることはなく、どこも同じ割合で遅配になる。昔の未払いは今月の分と失業手当の後に残ったお金で返す（今月の給料を止めてまで先に返さない）。救済に出せる額（`fiscal.rescue_after`）は、その項目の入った組までを国庫に残す。
- 取り置けなかった項目はそのターン削られる（工事が止まる、国庫直轄の施設が仕入れられない、など）。賃金は削らずに未払いとして負債に残す（遅配）。
- 遅配: 払えなかった賃金は未払い賃金として政府の負債に残し、お金が入ったら新しく雇う前に払う（政府は上の順番で取り置けた分だけ）。働く人はすぐ全員は辞めず、未払いの続く月数に応じて少しずつ辞める（`labor.arrears_quit`）。未払いの間は幸福度と政情が下がる。現実の例は1990年代のロシアで、公務員や工場の賃金の遅配が数か月続き、多くの人は働き続けた。
- 国庫が空で人を雇えない施設は「賃金が払えない」で止まったと出す。取引先への支払いの遅れ（企業どうしの掛け）はまだ入れない。
- 国債の支払いは自動では止めない。止めるのはプレイヤーの命令 `set_bond_payment` だけ（タブ 7）。標準の計画は、返す力の比が高いか賃金を払いきれないと増税する（タブ 12）。

### 国庫と国債のつなぎ

- 国庫を空にしないため、国債の段が毎ターン「次のターンの支払いの見込み（利払いを含む）＋手元に残す額−国庫の残高」を自動で発行する。手元に残す額は1ターン分の支出。
- 満期の償還は、償還のターンに国庫で足りない分をその場で発行して充てる（借り換え。前のターンに発行すると、国債の残高と国庫が1ターンだけ膨らんで見えるため）。
- 発行はすべて銀行の入札に出し、売れ残りの扱いは命令 `set_bond_policy` で決める。独立した中央銀行は引き受けないので、売れ残った分は支払いの順番で支出が削られる（タブ 7）。
- 国庫の余り（上の手元に残す額を超えた分）は、国債の段の終わりに市中銀行へ政府の預金として預ける（FS-24。回5）。政府が黒字の島では、税と国営の施設の売上で銀行の準備預金が国庫へ流れ、銀行が国債を持っていなければ戻る道がない。預けないと、島に銀行が1つの計画経済の島で銀行が毎ターン中央銀行から借り続けた。現実の例は、アメリカが 2008 年まで国の余りを市中銀行に預けた国庫の税・借入勘定（TT&L。担保付きで利子は低い）と、ソ連で国の予算の余りを国営銀行が貸し出しに回した形。画面と標準の計画の「国庫」は政府の預金を含めた額で、預け入れと引き出しは収入・支出に数えない。政府の預金に利子は付けない（銀行は準備預金の利子を受け取る）。
- 銀行の救済と預金保護（支出の項目の外）に国庫から出すのは、次のターンの `fiscal.rescue_after` までの支払いを国庫に残した額まで。出したターンは、次のターンの支出の分まで国債を出して国庫を戻す（戻さないと次のターンの賃金が払えなかった）。

### 国の倉庫

- フェーズ1の島の共同倉庫は、政府が持つ「国の倉庫」になった。国の工事（国営施設と公共事業）はここにある資材を先に使う。
- 命令 `warehouse_trade` で市場に売ったり、備蓄として買い入れたりできる（買い入れは国の倉庫の予算から）。このターンだけの 1 回の売り買いで、毎ターン続けるなら下の「決まった売り買い」の設定を使う。
- 国の穀物の備蓄（FS-25。`hakoniwa_core/economy/reserve.py`、W-186 の直し 回1）: 現実の国の備蓄（日本の米は年の消費の約 1.5 か月分を持ち古い物から入れ替える。中国やインドは値上がりで放出し、値下がりで買い入れる）に倣い、命令がなくても政府が次のようにする。目安は住民の食べる量の `food_reserve.turns` ターン分で、建国のときに倉庫に入れておく。昔から積んできた物なので、作られたターンを入れ替えまでのターン数にならしておく（同じターンにすると、約 20 ターン後に全部が一度に入れ替えの時期になり、農場の売上を奪って値崩れさせる）。漁港が災害で止まるなどして、前のターンに飢えた家計があればいつもの値段を指値に（計画経済の公定価格や値段の上限の下でも売れる）、値段がいつもの値段の (1 + `food_reserve.release`) 倍以上になっていればその値段を指値に、倉庫の穀物を売りに出す（放出）。ふだんは売りに出さない（出しておくと、需要が生産を上回っても市場の売りが足りて見え、農場が建たない）。日持ちの残りが `food_reserve.rotate` ターン以下の組は今の値段で売る（入れ替え）。放出しないターンは、入れ替えで売った分と、目安に足りない分の `food_reserve.refill` の割合を（目安まで）、いつもの値段を指値に国の倉庫の予算（`fiscal.budget.warehouse`）から買う（予算を 0 にすれば買わない）。契約の輸入や命令で倉庫が穀物を売りに出しているターンは買わない（自分の売りを買わない。入れ替えの売りは少しずつなので、同じ板で一部を買い戻すことはある）。売り買いの結果はログに出さない。前は余分の農場 3 つで飢饉に備えていた（タブ 2 PO-14）。標準の計画は、飢饉の月の手（穀物への作り替え・倉庫の食べ物を全部売る・緊急の買い入れ）だけを命令で出す。
- 中身はそのターンの値段で政府の資産に数える。腐る物は持ち越せる期間を過ぎると捨てる（タブ 3）。
- 契約で届いた物は、買い手が契約ごとに「市場に出す」（既定）か「国の倉庫に入れる」かを選ぶ。腐る物はどちらでも届いたらすぐ市場に出す。
- 撤退した施設の残りの在庫は国が市場の値段で引き取る（タブ 5）。民営の工事をやめたときに買ってあった資材は国の倉庫に入る。
- 命令を並べる前の確かめでも国の倉庫を読む（倉庫の財を売る命令に「ありません」と出ないように）。

### 国の倉庫の決まった売り買い（W-235）

公開の世界の遊び手の声（掲示板 #13）から入れる。今の命令 `warehouse_trade` は 1 品目を 1 回だけ売り買いし、毎ターン続けるには毎ターン行政力を 1 ずつ使う。現実の国の買い入れと備蓄は、一度決めた制度を役所が続けて動かすものなので、品目ごとに置いておける設定にする。

**現実の制度との比べ（妥当性）**

| 現実の制度 | 何をするか | この設定のどれに当たるか |
| --- | --- | --- |
| EU の公的介入（小麦・バター・脱脂粉乳） | 決めた介入価格以下で、決めた量まで政府が買い上げる | 買う（指値＝介入価格、1 ターンの量＝買い上げの枠） |
| アメリカの余剰農産物の買い上げ（Section 32）、日本の政府調達 | 予算と量を決めて市場から買う | 買う（代金は国の倉庫の予算から） |
| 備蓄の払い下げ・放出（日本の政府備蓄米の売り渡し、各国の在庫の処分） | 量を決めて市場に売る。安すぎる値では売らない | 売る（下限の指値） |
| 中国の最低買付価格と備蓄の競売、昔の国際スズ協定・ココア協定の緩衝在庫 | 安いときに下限で買い、高いときに上限で売って値段を帯の中に保つ | 備蓄（買い入れの上限と放出の値段の 2 つ） |
| 石油の国家備蓄（IEA は純輸入の 90 日分を義務づける。アメリカの SPR は安いときに買い戻す） | 目安の量まで積み、値上がりや途絶で放出する | 備蓄（目安の量） |
| 日本の政府備蓄米の回転備蓄 | 古い物から売って新しい物と入れ替える | 備蓄の入れ替え（腐る物） |

- 政府の注文はほかの買い手・売り手と同じ板寄せに入る指値の注文にする。遊び手の声は「残った売りから先に取る」だったが、現実の政府の買い上げも値段を押し上げる（それが価格を支える目的）。注文を板に入れずに残りだけを取る形にすると、政府が買っても値段が動かなくなり現実と離れるので採らない。代わりに、割り当てで分けるときは政府を誰よりも後にする（優先順位の設定 `warehouse.standing_priority` は game.yaml に置き、どの注文よりも低い負の値にする。今の注文の優先順位の既定は 0）。約定の値段より高い指値の注文は全部約定するので、値段が民間の付け値の間で決まれば政府は高い指値で先に買える。ただし今の板寄せには値幅がなく、買いが余って値段がいちばん高い指値で止まると、そこで並んだ指値なしの買い手（家計など）と政府は優先順位で分けるので民間が先になる。政府の高い指値はそのとき値段を押し上げるだけになる。現実でも政府の買い上げが市場を押し上げて民間の払う値段を上げることはあるので、この形のままにする。
- 備蓄の値段を 2 つにするのは、1 つにすると同じ値段で買いも売りもして値段を 1 点に止める形（固定価格）になるため。現実の緩衝在庫も下限と上限の帯で動かす。
- 現実と同じ難しさは残す: 上限を守ろうと放出を続ければ倉庫が尽き、下限を守ろうと買い続ければ予算が尽きる（国際スズ協定は 1985 年に資金が尽きて崩れた）。値段を帯に押さえると、民間がその品目の施設を建てる儲けも押さえられる。腐る物は持ち続けると傷む。
- 倉庫の保管の費用は入れない（今の国の倉庫にもない）。持つ損は、腐る物の傷みと、買うお金の国債の利子で表れる。日本の備蓄米や石油の国家備蓄の保管の費用は値打ちの年数 % ほどと言われ、国債の利子と同じくらいの大きさなので、利子で持つ損を表せば大きくは離れない。

**動き**

- 命令 `set_warehouse_standing` の中身は、品目・種類（買う・売る・備蓄・やめる）・量・指値・放出の値段・続けるターン数（書かなければ止めるまで）。品目ごとに 1 つで、置き直すと前の設定と入れ替わる。量と値段は命令 `warehouse_trade` と同じく見せる単位で書く。ためておけない財（電気）には置けない。
- 市場の段で、国の倉庫の注文を次の順に出す: 契約の輸入と閉じた施設から引き取った物の売り → 命令 `warehouse_trade`（軍の自動の買いもここ）→ 国の穀物の備蓄（FS-25）→ 決まった売り買い → 備蓄の放出の決まり（MK-39）。穀物の備蓄を決まった売り買いより前にするのは、飢饉の備えが予算の取り合いで知らせなしに止まらないため（FS-25 の買い足しを先に取り置く）。同じ品目に命令 `warehouse_trade` があるターンは、その品目の設定は休む。軍の自動の買い（国防費で兵の食べ物と備蓄を補う）は命令に数えない（数えると軍が補う間ずっと設定が休む）。
- 自分と売り買いしない: 同じ品目で倉庫がそのターンに逆の向きの注文を出していれば、設定は休む。買う・備蓄の買いは、契約の輸入や引き取った物の売り・穀物の放出と入れ替え・命令の売りがあるターンに休む。売る・備蓄の放出は、軍の買い・穀物の買い足し・命令の買いがあるターンに休む。備蓄の入れ替えの売りだけは逆の向きに数えない（FS-25 と同じく、少しずつなので同じ板で一部を買い戻すことはある）。決まった売り買いを置いた品目は、MK-39 の放出の決まりが出さない（遊び手が自分で決めている物を役所が勝手に売らない）。
- 買い: 1 ターンの量を指値で買う。代金は国の倉庫の予算（`fiscal.budget.warehouse`）の月割りから、そのターンの決まった買いをまとめて取り置き、足りなければどの品目も同じ割合で減らす（今の `_afford` と同じ）。国庫が足りないときの順番は国の倉庫の買い入れの位置（FS-09 の最後）。
- 売り: 倉庫の量から、軍の備え（兵の食べ物と国防費で決めた備蓄の目標。標準の計画の `_military_keep` と同じ）と、並んだ国の工事にこれから要る資材（標準の計画の `_reserved_materials` と同じ）を除いた分まで、1 ターンの量を売りに出す。
- 備蓄: FS-29。目安に足りない分を買い入れの上限で買う。腐る物は入れ替えた分を買い直す。前のターンの値段が放出の値段に近づいたら（(1 − `market.band`) 倍以上）、軍の備えと工事の資材を除いた全部を放出の値段で売りに出す。目安の分は、国営施設が市場で買う前に倉庫から自動で引き出す分（W-225）と国の工事に使わせない（使わせると、国営施設が備蓄を食べて毎ターン買い直すだけの通り道になる。現実の戦略備蓄も、ふだん使う在庫と分けて持つ）。腐る物は日持ちが `food_reserve.rotate` の 2 倍以上の財（今は穀物）だけに置ける。魚・食品・肉のように日持ちの短い物は、入れ替えの時期がすぐ来て積めないので置けない（現実の国も生鮮品は備蓄しない）。値段がそれより安いターンは出さない（出しておくと、需要が生産を上回っても売りが足りて見え、施設が建たない。FS-25 と同じわけ）。放出するターンは買わない。
- 国の工事（FS-15）は今までどおり倉庫の資材を先に使うが、備蓄の目安の分には手を付けない。工事のために前もって資材を集めたいときは「買う」の設定を使う。
- 計画経済の公定価格の財: 値幅がなく割り当てで分けるので、決まった売り買いの買いは配給・国営施設・輸出のどれよりも後の順位に置く（通常の倉庫の買いとは分け、設定の負の優先順位を割り当てでも使う）。指値は使わず公定価格で約定する。備蓄の放出は値段でなく、前のターンに買えなかった量があれば出す（ソ連の国家備蓄も品不足のときに出した）。
- 混合経済の値段の上限・下限のある財: 上限より高い放出の値段と、下限より安い買いの指値は約定しないので、置くときに断る。
- 腐る物を「買う」の設定で積むと、日持ちを過ぎた分は今までどおり捨てる（タブ 3）。入れ替えをするのは備蓄の設定だけ。
- 伏せ方（UI-04）: 「買う」の設定の命令は、今の買い入れと同じく実行まで伏せる。「売る」と「備蓄」は出した時から見せる（現実の介入価格や備蓄の放出の決まりは公表する制度）。動いた売り買いは市場の約定に出るので、ほかの国も 1 ターン遅れで分かる。
- 知らせ: 設定を置いた・変えた・止めた・決めたターン数が過ぎて終わった、備蓄の放出を始めた・やめた、予算 0 で何も買えなかった（続く間は最初の 1 回だけ）をログに出す。毎ターンの約定はログに出さず、画面の設定の欄に前のターンの結果（出した量・約定した量・使ったお金・減らしたわけ）を出す（UI-60）。
- 穀物の備蓄の設定を同じ品目の手動命令で休ませても、FS-25 の飢餓時放出と古い組の入れ替えは残す。設定による通常の放出と買い足しは休む。
- 標準の計画（autoplan）はこの設定を使わない（今の世界の測りの結果を変えない）。

**試験の世界の妥当性**

- 1 島の試験の世界では輸入がないので、備蓄の放出が値段を押さえる効きが実際の公開の世界（商社と商人が輸入で値段に応える）より強く出る。試験では仕組みが正しく動くこと（量・お金・帳簿・順番・伏せ方）だけを確かめ、効きの大きさは数島の世界で見る。
- 標準の計画が使わないので、50 島の測りでは崩れが増えないことだけを確かめる。設定を置いた島を何島か入れた試し回しを X870 で回し、帳簿が合うこと・倉庫と予算が尽きたときに止まらず休むことを見る。

### 産業政策

幼稚産業の保護など、国ごとの戦略を出す道具。どれも命令で行政力 1、次のターンから効き、政策の欄に持つ。

| 道具 | 効き方 |
| --- | --- |
| 関税 | 輸入の財ごとの率。荷を下ろすとき、輸入した商社（契約で国の倉庫に入る分はかからない）が「約定の値段を自国通貨に直した額×率」を国庫に払う。商社は関税を見込んで指値を下げる |
| 輸出補助 | 財ごとに1単位あたりの額。圏の市場で売れたとき、国庫から商社へ補助金の予算で払う。商社は補助を見込んで島で高く買える |
| 輸入の割り当て | 財ごとの1ターンの上限。商社の買い注文をそこで止める（契約の分は数えない） |
| 禁輸 | 国ごと、または国×財ごと。圏の市場でその国との組を割り当てず、その国との契約は止まる。禁輸した国への援助は断られる |

- 貿易圏の代表は「圏内の関税をなくす」決まりを設定でき、その圏の市場で買った荷には関税がかからない。圏内の固定価格はタブ 9。
- 民主主義の国では、関税と禁輸に議会の賛成が要る（タブ 10）。報復関税などは遊ぶ人どうしに任せる。
- 補助金（生産・設備投資・救済）はタブ 5、商社と圏の市場はタブ 9、計画経済の公定価格と値段の規制はタブ 10。

## 前提と依存

### この仕組みが前提にしていること

- 税の元: 賃金（タブ 4）、施設と銀行の利益（タブ 5・7）、家計の買い物（タブ 4）、輸入（タブ 9）。
- 国債の入札と中央銀行の引き受け（タブ 7）。
- 政府の買い物ができる市場（タブ 3）。
- 議会の採決（タブ 10）。

### この仕組みの結果を前提にしている仕組み

- 公務員と行政力（タブ 1）、教員と学校（タブ 8）、警察官と治安（タブ 10）。
- 公共事業とインフラの工事と維持（タブ 8）。
- 失業手当で暮らす家計（タブ 4）、遅配と幸福度・政情（タブ 2・10）。
- 国庫直轄の施設の仕入れと稼働（タブ 5）、補助金で建つ民営工場（タブ 5）。
- 国債の発行量と利回り、銀行の救済（タブ 7）。商社の輸入の判断（関税・輸出補助。タブ 9）。
- かみ合い: 人口 × 公共事業費 × 借金（失業が減ると借金の比が膨らんで見える）。中央銀行の独立 × 建国の国債 × 自動の不履行（回1）。
