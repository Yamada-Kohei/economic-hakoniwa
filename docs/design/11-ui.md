# 11 画面と統計

遊ぶ人が国のようすを読み、命令を出すための画面と、その元になる統計と記録を扱います。画面の作り方、誰に何を見せるか（持ち主だけの中身と実行まで伏せる命令）、統計の名前と計算のしかた、記録を残す期間、暦の書き方とグラフ、島の俯瞰図と重ね表示と絵、世界マップ、統計の順位と称号、産業の鎖、ターンログと注意、手引き、AI が遊ぶための入り口（AI 用の鍵・国の要約と差分・MCP）と人と同じにそろえる決まり、管理画面です。URL と API の一覧は [docs/architecture.md](../architecture.md) の「画面」「JSON API」「AI 用の入り口」にあり、ここには決まりだけを書きます。各仕組みの画面に何を出すかは、それぞれのタブの「統計と画面」にあります（人口はタブ 2、市場はタブ 3、労働と家計はタブ 4、施設はタブ 5、財政はタブ 6、金融はタブ 7、インフラと教育はタブ 8、貿易と為替はタブ 9、政治と計画はタブ 10）。公電と掲示板の決まりはタブ 10、関門で統計をどう見るかはタブ 12 を見ます。

## コードの場所と試験

- 画面（テンプレート）: `server/web/views.py`、`server/templates/web/`。手引きの図は `tools/help_diagrams/diagrams.py`（出力は `server/static/img/help/`、試験は `tests/server/test_help_figures.py`）。国の公開ページの中身は `server/web/country.py`、国旗・紹介文・紀年・一言の保存と書き込みは `server/country/`（国旗の検査は `png.py`）、不具合の報告は `server/feedback/`、掲示板は `server/board/`、予算の目安は `server/web/budget_guide.py`。画面の中身の組み立ては `server/web/reports.py`（経済・市場・施設・財政・金融）、`trade.py`（貿易と為替）、`politics.py`（政治と計画）、`chain.py`（産業の鎖）、`rankings.py`（統計の順位）、`display.py`（文と数の組み立て）
- JSON API: `server/web/api.py`（URL は `server/web/urls.py`）。建国は `server/web/founding.py`
- AI の入り口: 国の要約と差分 `server/web/overview.py`、MCP `server/web/mcp.py`、AI 用の鍵 `server/accounts/keys.py`、回数の数え `server/accounts/throttle.py`、ログインの上限 `server/accounts/loginguard.py`、接続元の読み方 `server/accounts/clientip.py`、stdio の橋渡し `tools/playtest/hk.py`
- 画面の JavaScript: `server/static/js/`（`map/` 俯瞰図と `overlays/`、`island/` マスの情報と命令の列、`chart/` 折れ線グラフ、`reports/` 統計の画面、`world/` 世界マップ、`founding/` 建国、`calendar.js` 暦）。絵は `server/static/themes/<名前>/`（決まりは [docs/map-art.md](../map-art.md)）
- 統計: 記録の段 `hakoniwa_core/modules/records/`（GDP は `hakoniwa_core/economy/books.py`、物価は `hakoniwa_core/economy/stats.py`、国際収支は `hakoniwa_core/trade/balance.py`）。保存と古い記録の削除は `server/world/repository.py`
- ターンログの文面: `hakoniwa_core/log.py` と定義データの `messages`。暦は `hakoniwa_core/dates.py`、テンプレートの `turn_date`（`server/web/templatetags/calendar_tags.py`）
- 試験: tests/server/test_country.py、tests/server/test_feedback.py、tests/server/test_board.py、tests/server/test_web.py、tests/server/test_reports.py、tests/server/test_ai_parity.py、tests/server/test_ai_players.py、tests/server/test_calendar.py、tests/server/test_review_fixes.py、tests/server/test_phase1.py、tests/server/test_phase3_2.py、tests/server/test_phase3_3.py、tests/server/test_trade.py、tests/server/test_theme_sprites.py、tests/core/test_log_messages.py、tests/core/test_dates.py

## つながり

- 前提にしていること: 記録の段と帳簿の確かめ（タブ 1）、段が残したお金と物の流れ（タブ 3・4・5・6）、島と世界の `ext` に段が残す状態（タブ 7・9・10）、命令の定義と確かめ（タブ 1）、暦（タブ 1）。
- 前提にされていること: 遊ぶ人と AI の判断のすべて、関門と測りの統計（タブ 12）、政情の物価上昇率と格差（タブ 10）、中央銀行の金利の決め方の物価上昇率と失業率（タブ 7）、標準の計画の読む統計（タブ 12）。

### 画面の作り方

- ほとんどの画面は Django のテンプレートでサーバーが HTML を作ります。JavaScript で動かすのは、島の俯瞰図とマスの情報と命令の列、建国、グラフ、世界マップだけです。JavaScript はブラウザがそのまま読める ES モジュール（`<script type="module">`）で書き、ビルド作業は入れません（2026-10-12 決定）。
- 外部の JavaScript のライブラリは使いません。グラフも `static/js/chart/line.js` の小さな部品で描きます。外部の素材を足すときは同じ変更で `THIRD_PARTY.md` に出典とライセンスを書きます。
- 画面と API は、ルールの計算をしません。段が保存した統計・市場の記録・約定・施設の帳簿・勘定と、島と世界の `ext`（貿易・政治・計画など）と、定義データの表示名だけを読みます（`server/web/` の各モジュールの頭の説明）。数の意味を変える計算は段の側に置き、画面は読むだけにすることで、画面と AI の入り口と関門が同じ数を見ます。
- 島の画面と、その統計の画面の上にあるリンク（地図・経済・市場…）は、境目に線のあるつながった 1 本の帯にします。今の画面は色を反転し、入りきらないときは帯の中を横に送ります（2026-10-25、W-145）。
- 画面の一覧（URL と中身）は docs/architecture.md の「画面」にあります。島の画面から、経済・市場・産業の鎖・施設・財政・金融・貿易・為替・政治・計画（計画経済は「計画」、混合経済は「値段の規制」）・ターンログへ移れます。

### 見せる範囲

- ほかの国の画面も開けます。現実の国が公表する統計（GDP・物価・失業率・国庫・国債の残高・レート・国際収支・政情の段階・支持率・議席など）は誰にでも見せ、持ち主だけが知っている中身は持ち主にだけ出します。
- 持ち主だけのもの: 施設ごとの帳簿・借入・約定の相手、銀行ごとの帳簿、契約・商社・船団・運ぶ途中の荷の中身・海外の商人・外貨の持ち高と非居住者の預金の内訳、政情の目標の内訳と採決の履歴とたまった不満、計画経済の公定価格と生産目標と行列の内訳、産業の鎖、命令の欄と命令の確かめ。
- 命令の列: 待っている命令はほかの国の人にも見せます。ただし、現実の国が前もって公表しない命令（金融政策・国債の利払い停止・緊急の貸し出し・銀行の破綻処理・為替介入・固定相場・資本規制・外国の国債の売買・国有化・議会の解散・二国間契約・国の倉庫の買い入れ・施設の優先度と生産方式。`orders.yaml` の `secret`）は実行するまで伏せます。国の倉庫の売り（備蓄の放出）は、現実の備蓄米や石油備蓄の放出のように前もって発表するものとして、出した時から誰にでも見せます。予算・税・関税など前もって公表する命令は、待っている間も見せます。実行した命令は誰にでも見せ、伏せる命令が失敗したときは本人だけです（2026-10-16 のカード「種類で分ける」と、迷う 5 つのカード）。
- `secret` は `true` なら種類ごと、`{side: buy}` のように書くと中身がその値の命令だけを伏せます。書き方の誤りは定義データの読み込みで止めます。

### 統計

- 統計は記録の段（`records`）が、そのターンの仕訳・約定・市場の記録と、段が残したお金と物の流れ（`hakoniwa_core/economy/books.py`）から島ごとに作ります。名前は「人口 `population`」「在庫 `stock.<財>`」「値段 `price.<財>`」のように付け、サーバーが統計の表（`StatRecord`）に名前とターンで保存します。生産量と電力は生産の段が書きます。
- 主な指標:

| 指標 | 計算のしかた |
| --- | --- |
| GDP（生産の側） | 施設の付加価値（売上＋在庫の増減−仕入れ・電気代・運賃）と、工事の作業員・公務員・教員の賃金の合計 |
| GDP（支出の側） | 家計の消費（物・電気・運賃・住まいとサービス）＋投資（工事の資材と賃金と運賃、在庫と国の倉庫の増減）＋政府の消費（賃金・物・運賃）＋輸出−輸入。生産の側との差を `gdp.gap` に残す |
| 物価 | 家計が買う品目の物価指数。重みは直近 `records.cpi_weight_turns` ターンに買った量。上昇率は 1 年前との比 |
| 雇用と賃金 | 労働力人口・就業者・自給農家、完全失業率（一般）と技術者の失業率、平均賃金、実質賃金（平均賃金 ÷ 物価指数）、未払いの働き手、商業・サービス業就業者数、産業ごとの従業者数（施設の今の値から） |
| 家計の層 | 層（労働者階級・資本家階級・技術者・失業者）ごとの人数・可処分所得・消費・預金・幸福度と、格差（資本家階級と労働者階級の 1 人あたり可処分所得の比） |
| 金融 | 預金の合計、貸出の残高、貸し倒れ、政策金利、銀行間の金利、期間ごとの国債の利回り、銀行ごとの自己資本比率（持ち主だけ） |
| 財政 | 収入と支出（種類ごと）、国庫の残高、国債の残高と対年 GDP 比（年 GDP は直近 1 年の合計） |
| 企業 | 民営・国営の施設の数、参入・撤退・倒産の数、利益の合計（売上のない公務員の施設は入れない。タブ 5 FM-48） |
| 生産の基盤 | 教育水準、技術者の数、インフラの種類ごとの平均の整備度、発電量と電力の不足率 |
| 貿易と国際収支 | 輸出・輸入・貿易収支、経常収支と金融収支の内訳、レート、外貨準備 |
| 人口 | 出生数・死亡数・餓死者数・国際人口移動（入国者数・出国者数・帰国者数）と個人送金・在外自国民・在留外国人 |

- 財政の収入・支出・収支と、層ごとの 1 人あたりの所得は保存せず、統計の系列を返すときに計算して足します。統計の系列の API は名前の末尾の `*` でその頭の統計をまとめて読めます。銀行ごとの統計は持ち主だけです。
- 統計の表示名と単位は `server/web/reports.py` の `stat_label` にまとめ、画面・国の要約・MCP で同じ名前を使います。為替の売買量など、ほかの国の通貨で数える額の単位は `money:<その通貨の記号>` で、グラフの縦軸と吹き出しに記号を付けます（為替の画面の売買量のグラフは通貨ごとに 1 枚。W-70）。
- 市場の値段には種類を付けます（UI-56。W-171）: 約定（そのターンに売買が成立した値段）・気配（買いと売りの注文はあったが折り合わず、その間に置いた値段）・持ち越し（注文が片側だけかなく、前の値段のまま）・未観測（市場の記録がない）。市場の記録の売買量と買い注文・売り注文の量から決め（市場の段の板寄せ、タブ 3 MK-04）、約定でない値段には最後に売買が成立したターンを添えます。市場の画面・島の画面の資源の表・市場の API・国の要約・MCP で同じです（`price_kind`・`observed_turn`）。
- 市場の画面の持ち主だけの中身（W-225・W-222）: 国営の施設が市場で買う前に国の倉庫から自動で引き出した原料の量を品目ごとに出し（統計 `warehouse.to_state.<財>`。ほかの国には統計の系列でも見せない。国全体の額 `warehouse.to_state` はこれまでどおり）、原料を買えずに止まった施設の一覧には国営・民営の印を付けます。国営企業の買い注文や買えなかった量の割合は出しません。穀物（国の穀物の備蓄の財）の約定で政府（国の倉庫）が買い手か売り手の組には、備蓄の入れ替え・放出・買い足しの分を含むと説明を添え、買い手も売り手も政府の組は「備蓄の入れ替え」と出します。
- 表示名は統計の正式な言い方にそろえます（2026-10-19、UI-37）。働ける人の全体は労働力人口、仕事のある人は就業者、仕事を探している人は失業者、その割合は完全失業率、村で自給の農業をしている人は自給農家、施設で働く人は従業者です。家計の層は労働者階級・資本家階級・技術者・失業者と呼びます。人口の増減は出生数・死亡数・餓死者数、国の間の移り住みは国際人口移動（入国者数・出国者数・帰国者数・在外自国民・在留外国人）です。1 ターンの間の流れの量は名前の後ろに「（1ターン）」と書き、「このターン」とは書きません（残高や人数のような今の量と分けるため）。

### 記録を残す期間と巻き戻し

| 記録 | 残す期間 | 理由 |
| --- | --- | --- |
| 仕訳 | `records.journal_turns` | 1 島 1 ターンで数百行になるため。集計は統計と施設の帳簿に残る |
| 約定 | `records.trades_turns` | 「誰から買えなかったか」をさかのぼる分 |
| 施設の帳簿 | `records.books_turns`（200 年） | 200 年分のグラフ（2026-10-12 決定） |
| 市場の記録・統計・ターンログ | ずっと | 1 島 1 ターンで数十行 |

- 古い行はターン更新のトランザクションの中で消します。
- 巻き戻しでは、戻すターンより後の統計・ターンログ・記録を消し、勘定・融資・国債はバックアップの写しから戻します。バックアップは `backups.keep` 個残します。

### 暦とグラフ

- 画面のある時点は「箱庭暦32年11月（ターン 383）」のように日付を主にしてターンを添えます（2026-10-16 のカード）。テンプレートは `{{ turn|turn_date }}`、JavaScript は `calendar.js` の `turnDate` で書き、暦の名前と始まりの年（`calendar.name`・`calendar.first_year`）はページに埋め込みます。国ごとの年の数え方（世界の暦のまま・建国紀元・元号）は、国の公開ページの日付に使います（UI-39。ほかの画面は世界の暦）。
- グラフは横軸をターンにした折れ線で、目盛りは暦の年と月です。凡例は HTML で作って狭い画面でも折り返し、押すとその線を隠します。指やマウスを乗せると一番近いターンの日付と値を出し、値のないターンは線を切ります。表示する期間は画面で選べます（決めなければ直近の 120 ターン）。
- 経済の画面には決まったグラフ（GDP・物価上昇率・失業率・政策金利・国債の利回り・財政の収支・階級ごとの所得と格差・出生数と死亡数など）と、好きな統計を選んでグラフにする欄を出します。
- 全体を分けた割合を見るものは円グラフでも出します（2026-10-19、UI-36）。時間の流れは折れ線のままで、円グラフは読んだ期間の中から選んだ 1 つのターン（初めは直近）の内訳を、つまみでターンを替えて見ます。今は人口の階級ごとの内訳（経済）、歳入と歳出の内訳（財政）、産業ごとの従業者数（施設。施設の今の値だけでターンは選ばない）です。切れが多いと読めないので、大きい順に 6 つまで出し、残りは「そのほか」にまとめます。部品は `static/js/chart/pie.js` です。輸出入の品目ごとと電力の使い道は、品目ごと・使い道ごとの統計がまだないので、円グラフにしていません（タブ 14 W-72 の、コアにあると画面が助かる統計）。

### 島の俯瞰図と重ね表示と絵

- マスはひし形に並べ、奥のマスから手前のマスへ（x＋y の小さい順に）描いて、高い建物が奥を隠すようにします。クリックやタップの位置は逆の計算でマスに戻します。マスの幅と高さと 1 段の高さは、テーマの `theme.yaml` に置きます。
- マスを押すと、そのマスの情報（と持ち主にはそのマスへの命令）を、マスのそばの小さな窓（ポップオーバー）に出します（2026-10-19、UI-35）。窓は右上の × か Esc で閉じ、ほかのマスを押すとそのマスの情報だけに替わり、地図を動かすとマスに付いて動きます。窓はマスの右に、入らなければ左に出し、上下は地図の中に収めます。狭い画面では下から出す板にし、選んだマスが板に隠れないように画面を送ります。横の欄がない分、地図を広く取り、本文より広い画面では左右に広げます。地図でマスを選んで出す命令（インフラの工事・送電線・区域）の入口は窓の外、地図の上に出し、窓を閉じても選び続けられます。
- ファイルは座標の変換・描画・小さな地図・操作・重ね表示に分けます。重ね表示は `map/overlays/` に 1 種類 1 ファイルで足し、一覧（`overlays/index.js`）に並べます。今は人口・幸福度・電力・汚染・区画・インフラの種類ごと（定義データから作る）・運賃の率・工事です。運賃の率は計算が重いので、選んだときだけ地図の API に問い合わせます。重ね表示の間は建物を低く描き、マスを色分けします。
- 絵はテーマごとに `static/themes/<名前>/` に置き、`theme.yaml` の `sprites` に並べます。絵がない・読めないものは色付きのひし形と箱で描きます。首都の建物は政治体制で 6 通りに描き分け、町は段階で描き分けます。名前・大きさ・基準点・形式・ライセンスと見直しの観点は docs/map-art.md にあります。
- 自分たちで描いた絵か、出典とライセンスの分かる MIT と両立する素材だけを使います。絵の名前・ファイル・大きさ・危ない SVG・`THIRD_PARTY.md` の書き忘れは試験が調べます。

### 世界マップ

- 区画ごとに島の形を 1 マス 1 ピクセルで描き、気候帯・貿易圏の色の縁取り・港・運ぶ途中の荷のある航路を重ねます。
- 航路（どの島からどの島へ、何隻分の荷が向かっているか）は誰にでも見せ、荷の中身（財と量）は見ている人の島が積み出すか受け取る荷だけです。

### トップ画面

- 元の箱庭諸国のトップと同じく、島の順位の表を置きます。列は順位・島の名前（AI の印）・体制・人口・GDP・1 人あたり GDP・失業率・物価上昇率・幸福度・称号で、列の頭を押すと並べ替わります（既定は GDP の多い順。見る人の通貨に直せない国は後ろ）。前回比の列に、前のターンの GDP の順位からの上下を出します（前のターンの GDP も今のレートで直して比べる。昔のレートは直接の相場の分しか残らないので、全部の国を同じ物差しにするため）。建国から 1 年（12 ターン）のうちの国には NEW! を付けます。お金の額は下の「統計の順位と称号」と同じく見る人の通貨に直します。部門ごとの順位の画面は表の下からリンクします。
- 表の下に世界の様子（国の数、世界の人口・GDP・輸出額を見る人の通貨に直した合計と前のターンからの増え方、貿易圏・二国間の契約・運んでいる船荷の数。直せない国はお金の合計に入れず、その数を書く）と、為替の相場表（貿易を始めた国の通貨 1 単位が見る人の通貨でいくらかと、前のターンからの上下。直接の相場がなくほかの通貨を通した値は「目安」）を置きます。
- 昭和・平成の個人サイトの品を置きます: アクセスカウンタ（数字の絵、今日と昨日の数、同じ人の読み直しは数えない）、閲覧中の人数（5 分のうちにトップを開いた人）、キリ番（報告を促す一言だけで、ゲームの得はない）とキリ番ゲッター様の一覧（ログインしている人が踏んだときだけ、アカウントの名前と国名を残す。管理画面で消せる）、全部の島の最近の出来事、歴代の記録（最大の人口・最多の施設・最高の幸福度・最も長く続く国と、その国と年月。お金の額は通貨が国ごとで昔の為替レートも残らないので比べない）、更新履歴、管理人より、リンク集、当サイトのバナー（88×31 の絵と、貼るための HTML）、下の端の決まり文句。音は使いません。点滅は NEW! の印（建国したばかりの国と、7 日のうちの更新履歴）だけで、動きを減らす設定のブラウザでは止めます。カウンタは接続元をそのまま残さず、日ごとの重複を見分けるだけにします。更新履歴は管理画面で足す・直す・隠すができ、遊ぶ人に見える変更のコミットに書いた「更新履歴:」の行は、反映のときに自動でそこへ写ります。ゲームの画面にはライセンスの表記とソースコード（GitHub）へのリンクを出しません（リポジトリの LICENSE はそのまま）。
- 全部の画面を青基調の昔っぽい見た目（薄い水色の地・紺の字・青の細い線の表・濃い青の見出しの帯・中央寄せ）にそろえます。地図の絵は変えません。

### 統計の順位と称号

- 部門ごとの順位（GDP・1 人あたり GDP・人口・幸福度・輸出額）は、どの島の直近のターンの統計からも誰にでも見せます。
- お金の額は島ごとの通貨なので、見る人が選んだ通貨（決めなければ、お金の額を直せる国がいちばん多い通貨。同じ数なら見る人の国、さらに同じなら番号の小さい国。2026-10-25 の U05）に今のレートで直して比べます。共通の通貨を通しても直せない国は、順位から外して最後に並べます。
- 世界の企業: 動いている施設の多い順（同じなら働く人の多い順）に上位の企業（`server/web/rankings.py` の `FIRMS_TOP`）を、名前・国・民営か国営か・施設の数と種類・働く人で並べ、誰にでも見せます。企業のお金の数字（預金・利益・税・配当）は持ち主の国の施設の画面だけです（UI-54）。
- 得意産業と称号は、各産業の経験の累積と、世界の段 `rankings` が書いた称号から作ります。称号は経験の累積が世界で 1 位の国に付きます。島の画面と経済の画面にも出します。
- 称号の名前は産業ごとの史実のあだ名です（農業「世界の穀倉」、鉱業（鉄鉱石）「アイアン・レンジ」、鉄鋼「鋼都」、非鉄（アルミ）「アルミの都」、機械「世界の工場」、自動車「自動車王国」、繊維「綿の都」、石油「黒い都」、食品「天下の台所」、消費財「商店主の国」、造船「海の馬車屋」、エネルギー「光の都」）。称号を得たときと失ったときのターンログにもこの名前を出します。名前は定義データの言語（`locale`）の表示名に置き、差し替えは表示名だけで済みます。

### 産業の鎖

- 自国だけの画面です。品目ごとに、作った量・施設が使った量・市場で売買された量・輸入と輸出の量・値段の動きと、島で作る施設と使う施設を並べます。
- 市場で買いたい量の `records.shortage.share` 以上が買えないターンが `records.shortage.turns` ターン続いた品目を品不足として目立たせ、ターンログでも知らせます。売りに出ているのに買い手の指値と合わずに売れ残った品目は、品不足と分けてそう出します。
- 止まっている工場は、待っているもの（材料・電力・働き手・技術者・売れない）ごとにまとめ、建設と貿易の画面へ移れるようにします。
- 輸入は商社と海外の商人が島の市場で売った量、輸出は商社と海外の商人が島の市場で買った量です（二国間の契約で国の倉庫に直に届く荷は含みません）。貿易の画面の「海外の商人」に、売る値段と買う値段を並べて出します。財政の画面に、役所の決まった事業（タブ 8 IN-26）を始める・止める命令と今の状態を出します。

### ターンログと注意

- ターンログには文の種類と引数（名前）だけを保存し、文面は表示のときに定義データの `messages` から作ります。名前を変えると過去のログの文も変わります。文の種類と止まった理由のどれにも文があることを試験が確かめます。
- 文には施設やマスへのリンクを付け、原因が分かる書き方にします（どの施設が、何を待って止まったか）。
- 島の画面と国の要約の「注意」は同じ文で、画面の値を言葉にしただけです（政情の段階・食料と電力の不足・飢えている層・止まった施設・売りが届かなかった財・次のターンに満期の国債・混乱期間）。飢えている層は、どの層が、物がないのかお金がないのかと、亡くなるまでの危うさとして出します（タブ 4 LB-35 の支え合いが入るまでの、国が手を打つための知らせ）。赤字の独立採算の施設と未読の公電は持ち主だけです。
- 稼働準備中（工事が済んでまだ動いたことがない）の施設は、次の更新で動き出すので「止まった施設」に数えず、地図の赤い点も付けません（W-219）。
- 建国から 1 年のあいだ、持ち主の島の画面の上に「次にすること」を出します（UI-52）。島の今の状態から、急ぐ順に 3 つまで、行き先の画面へのリンクを付けて出します。建国直後は「まだ一度も更新されていない（命令がなくても島は動く）」「工業団地の指定」「命令の欄」です。国の要約の `next_steps` も同じ中身です。

### 手引き

- 手引きは 3 つあります。初めて遊ぶ人向けの入門（`/help/start/`。最初の 1 年・経済体制で変わること・画面の見取り・困ったとき・施設の状態の言葉）、仕組みの決まりをすべて書いた詳しい仕組み（`/help/`）、従来の箱庭を遊んだ人向けの手引き（`/help/hakoniwa/`。同じところ・違うところ・読み替え。2026-10-25、W-149）。見出しの「手引き」は入門を開き、入門と詳しい仕組みは互いにリンクします（UI-53）。各画面の上には、その画面を説明する節への「この画面の手引き」を出します。MCP の `guide` は `which` で選びます（`which=terms` で利用規約。UI-57）。手引き（`/help/`）の施設と命令の表は定義データから作るので、定義を変えれば表は合います。用語と操作の説明は手で書いており、仕組みを変えた PR で追いつかないことがあります。ずれはタブ 14 の「手引きのずれ」に 1 行ずつ足し、ベータ版の前にまとめて直します（W-41）。手引きには図があり（UI-51）、図には数字を書かないので、仕組みの数字が動いても文と表だけ合わせれば済みます。

### スマートフォンと言葉

- 画面は CSS だけで縦画面に合わせ、マップは指での移動と拡大縮小に対応します。
- 画面の文字列は Django の翻訳の仕組みで分けておきます。定義データの表示名は `locale` の言語を必ずそろえます（定義データの読み込みで確かめます）。

### AI が遊ぶための入り口

ベータ版の公開の後も AI に遊んでもらえるよう、人の画面とは別に、機械が読みやすい入り口を置きます（2026-10-16、思いつきの相談 2 のカード 2 枚）。人の画面は変えず、同じ情報を AI の読みやすい形で出します。

- **AI 用の鍵**: アカウントの画面（`/accounts/keys/`）で作って AI に渡します。AI は API と MCP に `Authorization: Bearer <鍵>` を付けて呼び、そのアカウントのログインと同じに扱います。鍵はブラウザが勝手に付けないので CSRF の印は要りません。鍵そのものは作ったときに 1 度だけ見せ、DB には SHA-256 のハッシュだけを置きます。鍵が効くのは `/api/` と `/mcp` だけで、画面・管理画面・ログインには使えません。1 つの鍵が 1 分に使える処理の数はサーバーの設定（`HAKONIWA_AI_CALLS_PER_MINUTE`）で抑え、`/mcp` のまとめ送信は 1 回に `HAKONIWA_MCP_MAX_BATCH` 件までで、含まれるメッセージの数だけ枠を使います（UI-48）。ログインの試しすぎの上限は UI-47、接続元の読み方は UI-49 です。
- **AI の国の印**: 取り消していない鍵を持つアカウントの島と、鍵を最後に使ってから 1 年の間の島には、国の一覧と国の画面に「AI」の印を出します（2 枚目のカードで「出す」）。持ち主は消せません。AI がパスワードで入って画面から遊ぶと印は付かず、技術で見分けるのは難しいので、「AI に遊ばせるときは AI 用の鍵で入る」を決まりにしています（docs/playtest.md と AGENTS.md）。
- **国の要約と差分**: 国の今の状態を 1 回で読める要約（主な指標と前のターンからの変化、政情、止まった施設とわけ、工事、財ごとの値段と買えなかった量、満期の近い国債、出来事、注意、得意産業と称号、地下資源から作れる財。持ち主には赤字の施設・命令の列と結果・未読の公電・移民の扱い）と、あるターンより後に起きたこと（ターンログ・変わった指標・命令の結果・届いた公電）。長い間を空けたときはターンログを決めた長さで切ります。
- **MCP のつなぎ先**（`POST /mcp`）: MCP の Streamable HTTP で、状態を持たず、1 つの POST に 1 つの JSON で答えます。道具（要約・差分・ターンログ・地図・マス・統計・画面の中身・定義・命令の確かめと置き換え・世界・順位・公電・掲示板・建国・手引き・API の GET）は、サーバーの中で JSON API のビューを同じアカウントで呼ぶだけです。stdio でしかつなげない AI のために、`tools/playtest/hk.py mcp` が橋渡しをします。
- AI に出すのは人が画面で見られる情報だけで、ほかの国の非公開の数字や先の見込みの計算は出しません。命令も人と同じ確かめと行政力の範囲です。
- **人と同じにそろえる決まり**（2026-10-17 05:00 JST、セビーリャさん「MCPのほうは変更のたびに人間と同様に使えるように反映してね」）: 命令・画面・画面に出す値・地図の重ね表示を足したり変えたりしたら、同じ PR で JSON API・MCP の道具・国の要約と差分も合わせます。合わせ漏れは `tests/server/test_ai_parity.py` が落とします（人が見る画面がすべて MCP の道具か「AI に要らない画面」に載っている、画面に渡す値が道具の答えのどこかにある、画面の命令がすべて定義にある、重ね表示がすべて文字の地図になる）。
- 残り（国の日誌・命令の書き方の例とまとめての確かめ・AI が作った道具の取り込み）はタブ 14 W-37、Codex の試し遊びで読めなかった情報と表示の不具合の束は W-36 です。

### 管理

- 管理は Django の管理サイトで行います: 設定、更新の一時停止、巻き戻し、何ターンかまとめて進める（失敗したターンで止まる）、アカウントの停止、公電と掲示板の書き込みの非表示、国旗・国の紹介文・来訪者の一言の非表示（自作の記念碑は記念碑と一緒に）。放置された国は自動で消さず、島の一覧に出る「命令が途絶えたターン数」と「最後のログイン」を見て、管理者が休止中にする・無人の島にする（UI-40）。
- ターンはサーバーのコマンド（`run_turn`・`rollback_turn`）で進め、戻します。間隔は `turn.interval_minutes` で、ベータ版もこの間隔で進めます（台帳 2026-10-18）。
- 同じ接続元からの登録の数は `accounts.signups_per_ip` で決め（0 で制限しない。IPv6 は /64 でそろえ、読めないときは数えない。特定の人に複数登録を認めるときは、管理画面の「登録の記録」でそのアカウントの行に追加の人数を入れる）、照合用の接続元のハッシュは `accounts.remember_days` 日だけ残します。1 つのアカウントで持てる島は 1 つです（2026-10-14 の確認）。
- 公開の前に作る運用のもの（ゲームを動かす係・HTTPS・静的なファイルの配り方・見張り・登録の守り）は、タブ 14 の「公開のこと」にあります。

### 統計と画面の残り

- 利回りが上限に張り付いたことを画面と知らせで分かるようにする（タブ 14 W-09）、公電が届いたときの知らせ（W-39）、最後の画面の段の直し（W-61）、統計でコアにあると画面が助かるもの（W-72）。

## 前提と依存

### この仕組みが前提にしていること

- 記録の段が毎ターン統計を残し、帳簿の確かめを通していること（タブ 1）。段がお金と物の流れを残していること（タブ 3・4・5・6）。
- 島と世界の `ext` の形（貿易はタブ 9、政治と計画はタブ 10、銀行と中央銀行はタブ 7）。
- 命令の定義（`orders.yaml` の `payload`・`secret`・`parliament`）と、命令の確かめ（タブ 1）。

### この仕組みの結果を前提にしている仕組み

- 物価上昇率と失業率と格差: 政情の目標（タブ 10）、中央銀行の金利の決め方（タブ 7）、公共事業費の見直し（標準の計画、タブ 12）。
- GDP の不突合と統計: 関門と測り（タブ 12）。
- 国の要約と差分と MCP: AI の試し遊び（docs/playtest.md）と、Claude と Codex の対戦（タブ 14）。
- かみ合い: 統計の名前 × 画面 × AI の入り口（名前を変えると、画面の表示名・国の要約・関門の読む名前を一緒に直す）。伏せる命令 × 差分（失敗した伏せる命令はほかの人の差分にも出さない）。
