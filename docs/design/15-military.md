# 15 軍事と戦争

フェーズ4 の軍事です。戦争の状態（宣戦・停戦・講和）と条約の軍事の条項、兵士の集め方と軍の維持、武器と装備の品目と施設、部隊と艦隊、島の中と海の上の動き、見える範囲、陸の戦闘、海の戦いと護衛と通商破壊と封鎖、占領、ミサイルと防空、反乱と内戦、電子機器と銅、経済とのかみ合いを扱います。国際会議場と条約の土台（経済の取り決め）はタブ 10、記念碑はタブ 2、画面の全体はタブ 11 です。

2026年10月20日にスレッド「フェーズ4（軍事）の設計」で書きました。部隊・艦・兵器・維持・戦い・見え方・ミサイルの初めの値の案は /mnt/project-files/phase4/military-values-draft.md にあり（設計書には数字を書かないため）、実装で定義データと `game.yaml` の `military.*` に写して、測りで直します。まだ作っていないので、決まりの状態は「決定（4-N で作る）」です。N は下の「回の分け方」の回です。

## コードの場所と試験

まだコードはありません。作るときの置き場所の予定です（docs/architecture.md の「フェーズ4」）。

- 部品: `hakoniwa_core/military/`（`units.py` 部隊と艦隊、`upkeep.py` 軍の維持、`moves.py` 動き、`combat.py` 陸の戦闘、`naval.py` 海の戦い・護衛・通商破壊・封鎖、`occupation.py` 占領、`missiles.py` ミサイルと防空、`visibility.py` 見える範囲、`civil_war.py` 反乱と内戦）
- 段: `hakoniwa_core/modules/military/`（島の段 `military`: 募集・編成・維持・除隊。全島の段 `operations`: 動き・海の戦い・陸の戦闘・占領・ミサイル）。反乱は段 `politics` の後に `civil_war`
- 定義: `packs/base/data/units.yaml`（部隊と艦の種類）、`goods.yaml` と `facilities.yaml` に品目と施設を足す。命令は `orders.yaml`
- 保存: Django アプリ `server/military`（部隊・艦隊・作戦・戦争の状態・占領・見た記録）
- 試験: tests/core/test_military_*.py、tests/server/test_military.py（作るときに足す）

### 戦争の状態と条約の軍事の条項

- 国と国の間は平時か戦争（MI-02）。戦争の状態は世界の状態に国の組ごとに持ちます。部隊が戦い、マスを占領し、船を沈め、ミサイルを撃てるのは戦争の相手にだけです。中立の国の船と部隊には手を出しません。
- 宣戦布告は重い命令で、民主主義は議会の過半数が要ります（MI-03。タブ 10 PL-14 の議会の要る命令に足す）。出すと国際会議場に声明が自動で載り、次のターンから戦争です。布告を出したターンに動かした部隊は、相手が備える前に着く奇襲になり、初めの戦闘で強くなります（真珠湾）。
- 停戦と講和は条約で、両国が署名すると効きます（MI-04・MI-05）。講和には、引き揚げのターン数、捕虜を返すこと、賠償（通貨・額・期日）を書けます。引き揚げと捕虜の返還と占領を解くことは、講和が効いたときにゲームが行います。
- 条約の軍事の条項は、外交を遊ぶ人に任せる今の決まり（タブ 10 PL-37）のまま、ゲームが止めも強いもしません（MI-06。10-20 のカード「記録と信用だけ」）。破った国は違反として記録され、国債の不履行と同じく信用の傷になります（タブ 10「国どうしのやりとり」）。
  - 不可侵: 破棄の予告から決めたターンがたつ前に宣戦すると違反。宣戦の命令そのものは止めません（1941 年の独ソ）。
  - 同盟: 互いの見える範囲を分け合い、相手の軍港と港で補給できます。同盟国が攻められても自動では参戦せず、参戦するかは各国が宣戦の命令で決めます（NATO の 5 条も同じ）。
  - 賠償: ゲームは払わせません。払う国がお金の援助の命令（タブ 9 FX-26）で送り、講和に書いた期日までに書いた額が届かなければ違反として記録します（1923 年のドイツの支払いの遅れとルール占領）。
- 首都を落とされたときの扱い（降伏）は「占領」の節です。

### 兵士と軍の維持

- 建国の島は軍を持たず、国防費は 0 です（MI-07）。軍を持たない国は現実にもあります（コスタリカ）。持つかどうか、どれだけ持つかは国の判断です。
- 兵士は軍が雇う公務の働き手です（MI-08）。志願では、軍が出す賃金で失業者から先に集め、足りなければ働いている人から集めます。賃金が島の賃金より低いと集まりません。
- 徴兵（MI-09）は命令で入れ、決めた人数を家計の層から人数の割合でくじで集めます。賃金は志願より低く、働いていた人が仕事を離れるので、人手の足りない施設が出ます。支持率が下がり、民主主義は議会の過半数が要ります。全面の戦争で人口の 1 割を超える兵を集めると、国の生産が大きく落ちます（第二次大戦の各国）。
- 兵士の食べ物・燃料・弾薬は軍が持ち、家計の食べ物の数からその人数を外します（MI-10）。軍は国防費で市場から国として買い（公共事業の資材と同じ形）、兵舎と軍港の倉庫に置き、部隊が持って動きます。
- 新しい兵は訓練を終えるまで練度が低く（MI-11。現実の基礎訓練は 3 か月ほど）、練度は訓練と戦いで上がります。
- 除隊（MI-12）した兵は家計に戻り、仕事を探す失業者になります。戦争の後の失業の波（1919 年、1946 年）が出ます。
- 国防費（MI-13）は予算の項目で、兵の賃金・装備の買い入れ・食べ物と燃料と弾薬に使います。払う順番は公務員・治安と同じ組で、足りなければ同じ割合で削られます。
- 払えないとき（MI-14）: 賃金の遅れは士気を下げ、士気の低い部隊からは毎ターン兵が逃げます。食べ物が尽きると戦う力と練度が落ち、病気と飢えで兵が亡くなります。燃料が尽きると車両と艦は動けず、弾薬が尽きると戦う力が大きく落ちます。どれも、蓄え（部隊が持つ分）で遅れて効きます。

### 部隊と基地

- 部隊の種類（MI-18）: 陸は歩兵（兵と武器）と機甲（兵と武器と軍用車両）。海は艦隊で、軍艦と潜水艦をまとめたもの。艦の乗員も兵士です。種類ごとの兵の数・装備・毎ターンの維持・強さ・速さは `units.yaml` に置き、パックで足せます。
- 編成（MI-19）は命令で、種類・大きさ・置く基地を決めます。工事と同じく、兵と装備がそろうまで編成中で、そろった分から使えます。装備は国の倉庫と市場から買い集めます。
- 基地（MI-20）: 兵舎は陸の部隊が平時にいる所で、兵の数に上限があります。軍港は海に接するマスに建て、艦隊の母港として修理と補給をします。レーダーは見える範囲を広げます。ミサイル基地と防空陣地は「ミサイルと防空」の節。要塞はマスを使う施設で、大きな工事で建て、そのマスで守る部隊を大きく強くします（現実の要塞・沿岸の砲台）。陣地（塹壕）はマスを占めず、町・畑・施設のあるマスにも兵と建材で何ターンかかけて掘り、守りを少し上げます（第一次大戦の塹壕）。10-20 セビーリャさん「要塞はマスを使うようにしよう、陣地はそのままでいい」。
- 部隊の持つもの: 持ち主の国・種類・場所（島のマスか世界の区画）・兵の数・装備の数・持っている食べ物と燃料と弾薬・練度・士気・今の命令。保存は Django の部隊と艦隊の表（W-69 のように JSON にせず、初めから表にする。見える範囲で引くため）。

### 動き

- 島の中（MI-21）: 部隊は1ターンに決めたマスまで進み、道路の整備度で増え、山と森で減ります。車両は進んだマスに応じて燃料を使います。海のマスには入れません。
- 島をまたぐ（MI-22）: 島どうしは海だけでつながるので、陸の部隊は輸送船に載せて運びます。船の数は部隊の重さで決まります。輸送船は軍が造船所から買って持つか、海運業から借り上げます（徴用。借り賃を払う）。借り上げた分だけ貿易に使える船が減り、輸入が細ります（第二次大戦の日本の船の徴用）。
- 船の道（MI-23）: 出発の区画から行き先の区画へ直線にたどり、どのターンにどの区画にいるかが決まります。速さは今の船の速さ（`trade.ship_speed`）と艦の種類の速さで、遅い方に合わせます。貿易の船も同じ道をたどるようにし、待ち伏せと封鎖はその区画で起きます。
- 揚陸（MI-24）: 相手の港か、海に接する平地のマスに下ろします。港でない所は1ターンに下ろせる量が少なく、下ろしたターンの戦闘で弱くなります（ノルマンディー）。港を取れば、後の補給が楽になります。
- 補給（MI-25）: 相手の島にいる部隊の補給は、船で運んだ分と、占領したマスで取り立てた分だけです。補給の船も通商破壊と封鎖に遭います。届かなければ持っている分を使い切り、MI-14 になります（ガダルカナル）。

### 外国の島にいる部隊

- 部隊が外国の島に入るのは、戦争で揚陸したときと、同盟の条約で駐留するとき（MI-63。在日米軍のような形）だけです（MI-51）。中立の国の島には入れません。
- 外国の島にいる部隊は、その島の人口・家計・雇用・市場に入りません（MI-64）。食べ物・燃料・弾薬は自国から船で運び、占領したマスでは取り立てます。その島の市場で買う形（現実の受け入れ国の支援や、兵の買い物）はベータ版の後に回します。帳簿が 2 つの国にまたがらないようにするためです。
- 部隊の状態は世界の状態に持ち、全島の段 `operations` だけが書きます（MI-54）。その島の段（雇用・生産・市場・人口）は、部隊のいるマスを「占領」「戦場」の印でだけ知り、占領のマスは働き手が通えず、施設は売れません（MI-36）。
- 駐留の部隊は、その国が戦争を始めても、同盟国の島から自分で宣戦しない限り戦いません。駐留先の国が攻められたときに一緒に戦うかは、駐留している国が宣戦の命令で決めます（条約の軍事の条項は記録と信用の傷だけ、MI-06）。
- 講和・停戦・条約の終わりで引き揚げるとき、船がなければその場で除隊して家計に戻します（見直し役が挙げた場面への手当て）。

### 見え方

- 見える範囲はサーバーが国ごとに計算します（MI-26）。自分の島の全部（入ってきた敵も見える）、自分の部隊と艦隊の周り（種類ごとの広さ）、レーダーの周り、同盟国の見える範囲です。潜水艦は近くの軍艦にしか見えません。
- 見えないものは画面にも JSON API にも MCP にも国の要約にも出しません。前に見た場所とターンだけを出します。基地などの施設は今と同じく島の俯瞰図で誰にでも見えますが、核施設とミサイル基地は隠せます（下の「隠した施設」）。偵察（偵察の部隊・衛星）はベータ版の後です。
- 動きと攻撃の命令は、実行まで伏せる命令にします（MI-27。`orders.yaml` の `secret`）。宣戦布告・停戦・講和・徴兵は現実でも公になるので伏せません。

### 陸の戦闘

- 戦争の相手の部隊が同じマスにいるとき、全島の段 `operations` で戦います（MI-28）。動いて入った側が攻め、もとからいた側が守ります。
- 強さは兵の数 × 装備のそろい（持っている数 ÷ 要る数）× 補給 × 士気 × 練度。守る側は地形（山と森）・要塞・陣地・町（住宅のマス）で強くなります。攻める側は、その場で 3 倍ほどの強さがないと崩しにくい（現実の目安）ように、守りの倍率を `units.yaml` と設定で合わせます。
- 毎ターンの損害は、相手との強さの比で決まる割合で兵と装備が減り、戦死・負傷（決めたターンの後に一部が戻る）・捕虜に分けます。弾薬は戦ったターンに使います。戦死した兵は家計の人口から減ります。
- 士気は損害と強さの比で下がり、崩れた側は隣の味方のマスへ退きます（MI-29）。退く所がなければ降伏して捕虜になり、講和で帰ります。
- 戦場のマス（MI-30）: 住民の一部が亡くなり、残りは同じ島のほかの町か、難民を受け入れる国へ逃げます（移民の段の逃げる形）。施設は乱数で止まるか壊れ、直すには工事が要ります。持ち主の資産は失われ、借りていた銀行は貸し倒れになります。
- 乱数は世界の種・ターン・段・島から作り、島の順番に結果が左右されないようにします（タブ 1 OV-09〜OV-11）。

### 海の戦い・護衛・通商破壊・封鎖

- 海の戦い（MI-31）: 戦争の相手の艦隊が同じ区画にいて、どちらかが相手を見つけたら戦います。強さは艦の種類と数と電子機器（レーダー）と補給。損害は沈む艦で、乗員は亡くなります。見つけた側だけが先に撃てます。
- 護衛（MI-32）: 艦隊を自国の海運業の船団に付ける命令です。護衛のある船団を襲うと、先に護衛と戦います（第二次大戦の大西洋の船団方式）。
- 通商破壊（MI-33）: 艦隊と潜水艦に区画を見張らせます。戦争の相手の商船が見張りの区画を通ると、見張りの数と種類で見つかり、護衛がなければ沈みます。荷と船と乗員を失い、輸入が届かず、値段が上がります。
- 封鎖（MI-34）: 相手の島の区画に艦隊を置くと、その島に出入りする船を止めます。相手の国の船は沈め、中立の国の船は追い返します（第一次大戦のドイツの封鎖）。食べ物を輸入に頼る島は飢えに向かい、それは今の市場と飢えの仕組みで出ます。
- 運賃（MI-35）: 海運業は沈んだ船を船の傷みと同じく費用に数え、運賃に乗せます（タブ 9 FX-10）。戦争の相手の見張りがある区画を通る航海には、見込みの損失を運賃に足します（戦争の危険の上乗せ。現実の戦争保険）。商社の指値は運賃を見込むので、危ない道の輸入はひとりでに減ります。

### 占領

- 戦闘の後に戦争の相手の部隊だけがいるマスは占領されます（MI-36）。現実の占領（ハーグ陸戦条約の軍政）と同じく、マスは元の国のままで、住民も元の国の人です。
- 占領されたマスの施設は元の国の市場に売れず、働き手も通えません。占領した国は、そこの産出と在庫を部隊の補給に取り立てられます（現実の徴発）。住民は残るか逃げます。
- 占領は部隊が去るか、追い出されるか、講和で解けます。
- 首都のマスを占領された国は降伏します（10-20 のカード「軍政と首都で降伏」）。体制が倒れて持ち主が体制を選び直し、混乱期間に入り、首都を落とした相手とは停戦になります（1940 年のフランス）。反乱で倒れるときと同じ作りです。停戦の間も占領と取り立ては続き、講和で解けます。ほかの国との戦争は続きます。
- 土地を講和で相手の国に渡すこと（割譲）は入れません。1つの島に 2 つの国が混ざる作り直しが要るためです。

### ミサイルと防空

- ミサイル（MI-37）はミサイル工場で作り、ミサイル基地に置きます。命令「ミサイル攻撃」で、戦争の相手の島のマスと数を決めて撃ちます。射程は世界マップの距離。1 発は高く（自動車の数十台分の材料と工賃）、乱発できません。
- 撃てるのは軍・施設・港と道路・住宅です（10-20 のカード「都市と核も」）。施設は壊れるか止まり、港と道路は整備度が下がります。住宅に当たると住民の一部が亡くなり、残りは逃げて難民になります。住宅を撃った国は戦時の決まりの違反として記録され、信用の傷になります（現実の都市への爆撃と戦争犯罪の扱い）。
- 防空陣地（MI-38）は周りのマスへ来たミサイルを、迎撃ミサイルの数で落とします。落とせる割合は電子機器の経験で上がります。海に接するミサイル基地は、近くの区画の軍艦も撃てます。
- 箱庭の災害の形（毎ターン撃つ基地、陸地を壊す弾）は取りません。マスごと消える壊れ方も入れません（タブ 2 の災害の決まり）。

### 隠した施設

- 核施設とミサイル基地は、建てるときに「隠す」を選べます（MI-62。10-20 セビーリャさん「核施設とミサイル基地は隠せるようにしてほしい」）。現実の地下の核施設（イランのフォルドゥ）と、山に隠したミサイルの基地に当たります。
- 隠すと地下に造るので、工事の資材と工期が増えます（数字は `facilities.yaml`）。山のマスにも建てられます。
- ほかの国には元の地形のマスに見えます。俯瞰図・世界マップの島の形・施設の数の統計・電力や雇用の国全体の数（その施設の分を含めたまま、施設の名前は出さない）・API・MCP・国の要約のどれにも、その施設の名前と場所を出しません。ターンログの工事の行も持ち主だけに見せます。
- 見つかるのは、相手の部隊がそのマスか隣のマスに来たとき、占領されたとき、そこからミサイルを撃ったとき（撃ったターンに見つかる。発射の炎と軌道で位置が分かるため）です。見つかった施設は、見つけた国（と同盟国）にはその後ずっと見え、ほかの国には隠れたままです。
- 見つかっていない施設は、ミサイルで狙えません（狙うマスを選べても、そこに施設があることを知らない）。元の地形のマスを撃った弾がたまたま当たることはあります。
- 隠した施設の絵は、持ち主の俯瞰図ではふつうの絵に「地下」の印（コードが描く）を重ね、ほかの国の俯瞰図では元の地形の絵で描きます。新しい絵は要りません。

### 核兵器

- 核兵器も入れます（MI-46。10-20 のカード「都市と核も」）。現実と同じく、作るのに長い年月と大きな費用がかかる形にします（マンハッタン計画は約 3 年、国の生産の 1% ほど）。
- 材料のウラン鉱石は、原油やボーキサイトと同じく限られた島にだけある鉱業資源です（建国で選べ、前からある世界では移し替えで種から少しの島に置く）。持たない国は輸入するしかなく、ウラン鉱石は武器と同じく貿易圏の市場に出さず、国どうしの契約でだけ動きます（MI-17 に足す）。
- 核施設は国だけが持てる施設で、建てるのに大きな工事が要り、動かすのに大きな電力と技術者（大学で育てた人。タブ 8）を使います。決めたターンかけてウラン鉱石から核弾頭を少しずつ作ります。核施設は隠して建てられ（MI-62）、隠さなければ俯瞰図でほかの国に分かります。
- 核弾頭はミサイルに積んで撃ちます。防空陣地で落とせる割合は、ふつうのミサイルより低くします。
- 当たると、そのマスから決めた広さのマスで住宅の多くの人が亡くなり、施設は壊れ、港と道路とインフラの整備度が大きく下がります。汚染（タブ 2 PO-36）が長い年月残り、幸福度と農場と漁港の産出と肥沃度を下げます。マスは消えません（タブ 2 の災害の決まり）。現実の例: 広島では 1945 年の終わりまでに人口の 3〜4 割が亡くなり、爆心から 2km ほどの建物がほぼ壊れました。
- 核を使った国は大きな違反として記録され、信用の傷は住宅へのふつうの攻撃より重くします。
- 核を持たない・使わない約束は条約の条項として結べます（MI-47）。2 国の間でも、国際会議場で多くの国が署名する条約（核兵器不拡散条約に当たる）でもよく、破ってもゲームは止めず、違反として記録して信用の傷にします（条約の軍事の条項と同じ扱い）。
- 標準の計画は核施設を建てません。

### 反乱と内戦

- 政情が反乱の前触れのまま決めたターン続くと反乱になり、反乱軍が首都から遠い大きな町に部隊として現れます（MI-39。タブ 10 PL-38 の続き）。兵は失業者と所得の低い層から出て、家計の働き手から抜けます。武器は近くの兵舎と警察の分を奪い、残りは持ち込んだ分です。
- 反乱軍は島の中の主体で、ゲームが動かします（MI-40）。首都へ向かい、占領したマスで兵と物を集めます。政府は軍と警察で戦い、警察は弱い歩兵として守ります。士気が低く賃金の遅れた部隊は乱数で反乱軍に寝返ります（現実の革命では軍の寝返りが決め手になる。1917 年のロシア）。
- 反乱軍が首都を落とすと体制が倒れ、持ち主が体制を選び直して混乱期間に入ります（MI-41。タブ 10 PL-18）。反乱軍が尽きるか、政情が落ち着いて決めたターン続くと、反乱は終わり、残った兵は家計に戻ります。
- 外国が反乱軍や政府を助ける形（武器の援助・部隊を送る）はベータ版の後に回します。

### 電子機器と銅

- 電子機器は銅と化学品と機械から作ります（MI-43）。軍ではレーダー・ミサイル・軍艦・潜水艦・軍用車両の材料で、4-2 で入れます。自動車の材料に電子機器を足すこと（W-76 の続き）も 4-2 で一緒に入れます。
- 軍の外の使い道は、どれも「電子機器が人手の代わりになる」形で入れます（10-20 のカード「全部」。4-4 で入れる）。倍率で結果を足すのでなく、作り方と人手の数で効かせます。
  - 工場の自動化: 工場は電子機器を使う作り方を選べ、同じ産出を少ない人手で作れます（産業用ロボット。1980 年代の日本の工場）。人手の余った分は辞めさせるので、失業が増える国が出ます。
  - 役所: 中央省庁と役所が電子機器を持つと、同じ行政力を少ない公務員で出せます（事務の計算機）。浮いた人数で公務員の賃金が減るか、同じ人数で行政力が増えます。
  - 銀行: 銀行が電子機器を持つと、同じ預金と貸し出しを少ない行員で扱えます（勘定系の計算機。1960〜70 年代の銀行のオンライン化）。
  - 学校: 教材として電子機器を使うと、教員 1 人あたりの育ちが上がります（タブ 8 IN-18 の教材に足す）。教育費から買います。
- 電子機器は施設の設備として持ち、年月で傷んで買い替えが要ります（設備の傷みはタブ 5 の回6 の形）。買い替えないと人手の多い作り方に戻ります。
- 銅は電子機器のほかに、送電線と電力の施設の工事の資材にも使います（現実の電線）。銅のない国は輸入に頼り、銅の値段が電子機器の値段に効きます。

### 経済とのかみ合い

- 国防費は国の支出で、国債の返す力の計算（タブ 7 BK-26）にそのまま入ります。戦費を国債で賄えば利回りが上がり、中央銀行が引き受ければお金が増えて物価が上がります（現実の戦時のインフレ）。
- 徴兵と戦死で働き手が減り、装備の注文で鉄鋼・機械・化学品・燃料の値段が上がります。輸送船の借り上げと通商破壊と封鎖で輸入が細ります。どれも今の市場と雇用の仕組みで出ます。
- 戦争の政情（MI-42）: 宣戦の後は一時だけ政情の目標が上がり（旗の下の団結）、それから自国の戦死者の人口に対する割合の対数に応じて下がります（厭戦。朝鮮戦争とベトナム戦争の支持の下がり方）。自国のマスの占領と徴兵も目標を下げます。
- 戦争と災難の記録（戦死者・難民・沈んだ船）は、記念碑の条件（戦いの碑・慰霊碑・平和記念碑）と伝統の賞に使います（4-1）。

### 標準の計画と測り

- 標準の計画（MI-44）は宣戦せず、核施設を建てません。宣戦されたら軍を編成して守り、相手が出した停戦と講和に署名します。戦争のない測りでは部隊 0・国防費 0・核施設 0 のまま回り、崩れが main より増えないことを関門の確かめにします（タブ 12。電子機器と銅が入るので、経済の数字そのものは変わります）。
- 測りに戦争の場面を足します: 隣どうしの 2 国のうち 1 国が決めたターンに宣戦し、揚陸・占領・通商破壊・講和までを試す計画で回し、崩れ（飢えで島が空になる、ターンが止まる、帳簿が合わない）が出ないかを見ます。戦争で人が亡くなり値段が上がるのはリアルさの難しさとして残し、ゲームが止まることだけを直します。

### 統計と画面

- 統計: 兵の数・練度・士気・国防費・装備の在庫・戦死と負傷と捕虜・沈んだ船・占領されたマス・難民・取り立てた物。国全体の兵の数と国防費は誰にでも見せ、部隊ごとの中身は持ち主だけ（タブ 11 UI-03）。
- 画面: 軍の画面（部隊・艦隊・基地・維持・命令）、戦況の画面（戦争の相手・戦いの記録・占領・沈んだ船）、島の俯瞰図の部隊と占領の重ね表示、世界マップの艦隊と見える範囲。Codex の分は「回の分け方と担当」。
- 画面と同じものを JSON API・MCP・国の要約と差分に出し、見える範囲の決まりも同じにします（MI-45）。合わせ漏れは tests/server/test_ai_parity.py が見つけます。

### 見直し役が挙げた場面への手当て

- 船が沈むと運ぶ途中の荷の突き合わせが合わずターンが止まる → MI-48（沈んで失った荷を突き合わせと帳簿に入れ、船に区画の位置を持たせる）。
- 首都を占領されたままだと毎ターン降伏する → 降伏は首都の占領が始まったときの 1 回だけ。混乱期間中に降伏したら体制の選び直しは省き、持ち主のいない島は今の体制のまま残す（MI-36）。
- 自動の停戦が MI-04 と食い違い、停戦から戦争へ戻る道がない → MI-04 に降伏の例外と予告つきの破棄を書いた。
- 厭戦の式が戦死 0 と人口 0 で壊れる → MI-42 を log(1＋k×r) にした。
- 陸の戦闘が割合の損害だけで終わらない、強さが 0÷0 になる → 1 回の戦いの損害に最小の人数を置き、強さに下限を付け、決めたターン続いても決着しなければ攻めた側が元のマスへ退く（MI-28 の実装の決まり）。
- 反乱軍が首都と陸でつながらない離れ小島に出て終わらない、武器が何もない所から生まれる → 反乱軍が出るのは首都と陸でつながる町だけ。武器は近くの兵舎と警察から奪った分と、闇で買える分（反乱軍が持つ失業者の蓄えから市場の値段で）だけにする。反乱が決めたターン続いても決着しなければ、反乱軍は兵の逃げで少しずつ減る（MI-39〜MI-41 の実装の決まり）。
- 占領したマスで働き手が通えないのに産出を取り立てる、取り立てと壊れの仕訳がない → 取り立てるのは在庫だけ（産出は止まる）。取り立ては施設の在庫の損失、壊れは設備の除却の損失として仕訳する。暴動（PL-08、在庫と帳簿はそのまま）と違い、戦争では物と設備が本当に失われる。
- 船がなくて講和の引き揚げができない、停戦で補給が止まり飢える → 補給と引き揚げの船は停戦中も通す（MI-04）。期限までに戻れない部隊は、その場で除隊して自国の家計に戻す（帰国の船に乗れるまで国防費で食べさせる）。
- 捕虜の扱いがない → MI-49。
- 国防費の装備が失業手当より先に払われる、兵の未払い賃金、核の汚染を残す状態がない → MI-13 を直した。核の汚染は、毎ターン計算し直す汚染（タブ 2 PO-36）とは別に、マスに「残る汚染」を持たせて年月で減らす（4-3 でタブ 2 にも書く）。
- 平時の揚陸と、ターンの中の段の順が書かれていない → MI-51 と MI-50。

### 2 回目の見直し（実装の目で今のコードと照らした）

10-20 にセビーリャさんの頼みで、別の Claude が今のコードを読み、入れるときに作り直しになりそうな所を 12 挙げました。手当ては MI-52〜MI-61 と、MI-13・MI-27・MI-44 の書き直しです。

- 行政力（`max_admin_power`）がすぐ尽き、戦争が遊べない → MI-52。
- 兵と捕虜をマスの人口の外に出す形がない（`facilities.py` の `labor_force`、`households.py` の `split_persons` は層の和がマスの人口の和の前提） → MI-53。
- 部隊を Django の表だけに置くと写しと巻き戻しから漏れ、島の段は他の島を書けない（OV-08） → MI-54。
- 伏せる命令が実行の後に誰にでも見え、戦いのログと統計も公開になる（`api.py` の `_secret_orders`、`turn_log`、`reports.py` の `visible`） → MI-27・MI-55。
- 船団は「ターンごとの隻数」の束で位置がなく、荷は積んだターンに売り手から出る（`ships.py`、trade の `_ship`） → MI-56。
- 運賃が島に 1 つで、道ごとの上乗せの置き場がない（`ships.freight_rate`、`traders.py` の指値） → MI-57。
- 予算の項目 1 つに払う順番 1 つ（`funds.py` の `open_treasury`）で、国防費を 2 か所に置けない。開戦の直後は前の支出が 0 で取り置きが付かない → MI-13。
- 体制を選び直す命令がなく、混乱期間中の変更は断られる（politics の `_check_change`） → MI-58。
- 標準の計画はサーバーで動かず、持ち主のいない島の守りが動かない → MI-44・MI-59。
- 標準の計画が使われていない鉱業資源に施設を建てるので、銅とウランの鉱脈があると精錬所と核施設を建て、測りの「軍を入れる前と同じ」が崩れる → MI-44 で核施設を外す。関門の確かめは「部隊 0・国防費 0・核施設 0・崩れが main より増えない」にする（電子機器と銅で経済の数字は変わるので、同じにはならない）。
- 移し替えの乱数がターンで変わり、上限と経済のない島の扱いが決まっていない → MI-60。
- 戦場とミサイルで押し出される難民の受け皿がない（移民の段は暮らしの見込みの差だけ、難民の政策は飢えた家計だけ） → MI-61。

## 前提と依存

### この仕組みが前提にしていること

- 働き手と失業者と家計の層と賃金（タブ 4）、国庫と予算の項目と払う順番（タブ 6）、国が市場で買う形と国の倉庫（タブ 3・6）。
- 港・輸送船・海運業・運賃・船の速さ（タブ 9）、移民の段の逃げる形と難民の受け入れ（タブ 2）。
- 政情と段階と議会と混乱期間と体制の選び直し（タブ 10）、条約と国際会議場（タブ 10、4-1）。
- 道路の整備度（タブ 8）、地形と町と首都（タブ 2）、工事の形（タブ 5・8）、全島の段と乱数（タブ 1）。

### この仕組みの結果を前提にしている仕組み

- 人口（戦死・難民）と幸福度（タブ 2）、雇用と失業（兵士に取られる人・除隊。タブ 4）、物の値段（装備の注文・封鎖。タブ 3）。
- 施設の止まりと壊れと貸し倒れ（タブ 5・7）、国の支出と国債の利回り（タブ 6・7）、運賃と輸入（タブ 9）、政情（タブ 10）。
- 記念碑の条件と伝統の賞（タブ 2・11）、画面と AI の入り口（タブ 11）、関門と測りの戦争の場面（タブ 12）。
- かみ合い: 徴兵 × 島に 1 つの食料の施設（農場の働き手を取ると飢える。徴兵は層の割合で集めるので農家も取られる。標準の計画は徴兵しない）。封鎖 × 食料の輸入 × 飢え（リアルさの難しさとして残す）。輸送船の借り上げ × 商社の輸入（借り上げで船が減り、輸入の足りないわけに「船」が出る）。戦死 × 厭戦 × 反乱（長い戦争は内戦に向かう）。
