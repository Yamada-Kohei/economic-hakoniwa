# 4 仕事と家計

住民が施設に雇われて賃金をもらい、家計の層ごとに所得を使い、残りを預金する仕組みです。雇用の段・賃金の段と、市場の段の家計の注文、人口の段の家計の層の入れ替えを扱います。飢えの進み方・人の生まれ亡くなり・幸福度の項目はタブ 2、値段と板寄せはタブ 3、施設の採算と企業はタブ 5、税率と予算はタブ 6、預金の利子と銀行はタブ 7、技術者の育成と引退はタブ 8、労働の動員と政情はタブ 10 を見ます。

## コードの場所と試験

- 雇用: `hakoniwa_core/modules/employment/`（段 `employment`、`unemployment_rate`・`settle_arrears`）、通勤は `hakoniwa_core/facilities.py` の `commute_labor`
- 賃金と手当: `hakoniwa_core/modules/labor/`（段 `payroll`、式 `wage_update`、命令 `set_labor_policy`）、遅配は `hakoniwa_core/economy/arrears.py`
- 家計の層と使い方: `hakoniwa_core/economy/households.py`（`consumption`・`init_layers`）、市場の家計の注文は `hakoniwa_core/modules/market/`
- サービスの店（仮の形）: `hakoniwa_core/economy/services.py`
- 試験: tests/core/test_economy.py、tests/core/test_rules.py、tests/server/test_economy.py

## つながり

- 前提にしていること: 施設の操業目標（タブ 3・5）、失業の受け皿（今は仮の店）、町と通勤圏（タブ 2）、国庫（タブ 6）、銀行の預金と融資（タブ 7）、技術者（タブ 8）、市場に物があること（タブ 3）、物価（タブ 11）。
- 前提にされていること: 生産と採算（タブ 3・5）、需要と値段（タブ 3）、飢えと移民（タブ 2）、税と手当（タブ 6）、預金（タブ 5・7）、幸福度と政情（タブ 2・10）、関門（タブ 12）。
- 詳しくは下の「前提と依存」。

## 仕組み

### 労働者の種類と通勤

労働者は一般と技術者の2種類です（定義は `packs/base/data/workers.yaml`）。一般の労働者は町に住み、通勤圏 `labor.commute_radius`（施設の定義で施設ごとに変えられる）の中の施設に通います。技術者は島全体の人数として持ち、通勤圏を見ずに島のどこの施設にも通います。技術者は大学で育ち、引退すると一般の層に戻ります（タブ 8）。施設ごと・マスごとに雇った人数は施設の `economy["staff"]` に残します。雇われなかった人は失業し、村の住民は自給の農業に戻ります。

### 雇い方（雇用の段）

各施設は操業目標の分だけ（工事中は手元の資材で進められる分だけ）雇いたい人数を決め、払える賃金の分までに抑えます。国庫が空で雇えない施設は「人手不足」ではなく「賃金が払えない」で止まったと出ます。そのうえで次の順に雇います。

1. 前のターンに雇っていた人を雇い続ける。雇いたい人数より多ければ、遠いマスの人から減らす。
2. 賃金の高い施設から順に（同じ賃金なら優先順位の高い順、番号の小さい順）、足りない人数を通勤圏の失業者から近いマスの順に雇う。
3. それでも足りなければ、通勤圏の中で賃金が `labor.poach_gap` 以上安い施設と店の働き手を、安い施設から引き抜く。1つの施設から引き抜かれるのは1ターンに `labor.poach_limit` まで。引き抜かれた施設は次のターンに賃金を上げる。

技術者は 2 の前に、前のターンの技術者を雇い続けたうえで、技術者の賃金の高い施設から順に席に割り当てます。席は定義の技術者数に雇いたい人数の割合を掛けた分で、埋まらない席は一般の席にし、足りない分だけ稼働率の上限が下がります（`labor.engineer_floor`）。3 の後に余った技術者は、まだ埋まらない一般の席に賃金の高い施設から島のどこへでも就き、賃金は一般のものです。

工事の作業員は施設が雇った後に残った失業者から、通勤圏を見ずに島のどこからでも、前のターンの島の平均賃金で雇います（引き抜かない）。インフラの維持の分は施設より先に、新しい工事の分は施設の後に、作業員の賃金と資材の代金を公共事業費から取り置きます（タブ 8）。運送業・港・海運業・商社は運ぶ荷の量に合わせて雇います（タブ 3・9）。店は 2 と 3 の後に、場所ごとの通勤圏に残った失業者を雇います（下の「サービスの仕事と店」）。労働の動員をしている島では、最後に残った失業者を国営の施設の空いた席に動員の賃金で割り当てます（タブ 10）。

### 賃金の決まり方

賃金は施設ごと、労働者の種類ごとに持ち、賃金の段の最後に次のターンの賃金を見直します（名前付きの式 `wage_update`・`engineer_wage_update`）。初めの賃金は `labor.initial_wage` で、値段の基準になります。

- 物価の上がった分（直近1年の物価上昇率）のうち `labor.indexation` の割合を追います。物価が下がっても、それだけでは賃金を下げません。
- 雇いたい人数に届かなかった施設は「足りない人数 ÷ 雇いたい人数」に `labor.wage_speed` を掛けて上げます。全員を雇えた施設は、通勤圏の失業率がふつうの失業率 `labor.natural_unemployment` を超えた分に応じて `labor.slack_speed` で下げる向きに動きます。
- 1ターンの変化は上がる方が `labor.max_raise`、下がる方が `labor.max_cut` までです（賃金は下がりにくい）。
- 施設の生産性が伸びた分は、年に1回、施設の月（施設の番号で12か月にばらし、同じ月に値段が跳ねないようにする）に賃金に乗せます。比べるのは、それまでに賃金に乗せた一番高い生産性です（下がった年は下げず、下がってから戻った分は二度乗せない。新しい施設は最初の施設の月に記録するだけ）。上げ幅の上限 `labor.max_raise` の外で乗せ、独立採算の施設の変動費の利益の上限は効きます。技術者の賃金にも同じ割合を乗せます。集積・インフラ・教育で伸びた分や、作り方を替えて伸びた分も乗ります（W-186 回2。長い目で見ると賃金は生産性の伸びについていく。前は経験で伸びた分が値下がりにだけ出て、家計の所得が増えなかった）。政府が最低賃金 `fiscal.minimum_wage` を決めると、それより下がりません。
- 独立採算の施設は、今の値段で変動費の利益が 0 になる賃金より上げません。店はサービスの値段 × `services.per_worker` までです。
- 技術者の賃金は施設ごとに持ち、初めは一般の `labor.engineer_wage_ratio` 倍です。同じ式で、人手の足りなさは技術者の席の埋まらなかった割合、失業率は島の技術者の失業率（席に就けなかった技術者の割合）で見て、施設の一般の賃金より下げません。値段の原価・融資の審査・参入の計算の人件費にも入れます。
- 失業が多い島でも物価の上がった分は賃金に追わせる形は、回5 で入れます（今は失業がふつうより多いと、下げる向きが追う分を打ち消して賃金が凍る）。

### 賃金と手当の支払い（賃金の段）

施設は、稼働率にかかわらず雇った人数分の賃金を払います。雇う人数は操業目標で決まるので、売れない施設は人を減らします。工事の作業員は工事の持ち主が、公務員・教員・警察官は国庫が払います（教員は教育費、警察官は治安費から。タブ 6）。所得税 `fiscal.income_tax` は賃金から差し引いて政府に払います。電気・送電網・原料が足りずに動けなかった分の働き手には、休業手当として賃金の `labor.furlough_pay`（6割。労働基準法の休業手当）だけ払います（回7 後半。LB-38）。人は辞めずに残るので、物が戻ればすぐ動けます。前は止まった店や工場が人を雇ったまま満額を払い続け、停電の 4〜5 ターンで手元が尽きて倒れていました。原料が高い・買うお金がない（施設の都合）と、自分で操業目標を下げた分（雇う人数を目標に合わせている）は満額です。賃金を市場の段より先に払うのは、家計がそのターンの賃金で食料を買えるようにするためです。

失業手当は「失業者1人に平均賃金の何割」を政府が決め、国庫から失業している家計の層に払います（失業した技術者にも）。建国のときの値は `fiscal.unemployment_benefit` で、命令 `set_labor_policy` で失業手当と最低賃金を変えられます。仕事も手当もない家族が市場に食べ物があるのに買えず飢える件は、当面この手当だけが支えです（下の「家計の支え合い（回7）」）。

### 賃金の遅配

払い手（政府・独立採算の施設）が賃金を払えなかった分は、払えなかったターンに施設や省庁を止めるのではなく、「未払い賃金」として払い手の負債に残します（持ち手は家計の層）。お金が入れば、新しく雇う前に未払いを先に払います。政府は予算の段で、支払いの順番 `fiscal.payment_order` の `arrears`（今月の人件費と失業手当の後）に取り置きます。払えない分の働き手は払われないまま働き続け、未払いが続いた月数に応じて毎ターン `labor.arrears_quit` ×（月数 + 1）の割合が辞めます（すぐ全員は辞めない）。未払いの間は幸福度が `population.happiness.arrears` の分だけ下がり、政情にも効きます。施設の帳簿の賃金には払えなかった分も入れ、未払い賃金は施設の値打ちを下げます。現実の例は 1990 年代のロシアで、公務員や工場の賃金の遅配が数か月続き、多くの人は働き続けました。

倒産と撤退のとき、お金と設備・在庫を売った代金は、先に未払い賃金、次に未払いの税、残りを貸し手の割合で分けます（タブ 5）。取引先への支払いの遅れ（企業どうしの掛け）は入れていません。

### 家計の層

家計は次の4つの層に分け、層ごとに所得・預金・食べた量・飢えの蓄え・幸福度を持ちます（`game.yaml` の `household.layers`。状態は `economy.households[層]`）。

- 一般の労働者: 仕事のある一般の労働者と家族、村の住民。
- 失業している家計: 一般の労働者のうち仕事のない人（村で自給の農業をしている人を除く）と家族。人数は賃金の段の初めに雇用の結果から数え直し、仕事を失った人・見つけた人の預金を1人あたりの額で一緒に動かします。失業手当はこの層に入り、仕事のある家計とは所得・預金・食べた量を別に持つので、お金のない家計から飢えます（カードで「家計を分ける」に決定）。
- 技術者: 技術者と家族。島全体の働き手の人数から家族を合わせた人数を持ちます（`household.layers.engineers.workers`）。
- 資本家階級: 住民の `household.layers.owners.share` で、働かずに配当と預金の利子で暮らします。島全体の人数として持ち、その分だけ一般の労働者が減ります。計画経済の島は民営の施設がないので置きません。

収入は、働く層が賃金・失業手当・預金の利子、資本家階級が配当と預金の利子です。民営の施設と民間銀行への出資は資本家階級の預金から出し、配当と出資の払い戻し、国有化の代金もこの層に入り、民営化で施設を買うのもこの層です（タブ 5・7）。

人の移り変わり: 大学が育てた技術者は一般の層から技術者の層へ、引退した技術者は一般の層へ移ります。人口の増減と移動は層の人数に比例して割り振り、資本家階級は決めた割合に保ちます。人が層を移るときは、元の層の1人あたりの預金と飢えの蓄えを一緒に移します（仕訳で付け替える）。

格差は、統計に資本家階級と一般の労働者の層の1人あたり可処分所得の比を残し、政情には3層の所得から出したジニ係数が効きます（タブ 10）。

### 家計の使い方

層ごとに使う額を決め、残りは預金に残ります（名前付きの式 `consumption`）。使う額は、直近 `household.income_turns` ターンの可処分所得（賃金 − 所得税 + 失業手当 + 預金の利子 + 配当）の平均に層ごとの割合 `household.layers.<層>.c1` を掛けた分と、預金に `household.c2` を掛けた分の和です。割合は預金の実質金利（預金金利 − 物価上昇率）が高いほど `household.c1_rate_effect` ずつ下げ、動かす幅は `household.c1_range` までです。所得の少ない失業の家計ほど所得のほとんどを使います。回5 で、預金から使う割合を物価上昇率と実質金利で動かします（物価が上がると見れば先に買い、実質金利が高ければ貯める）。

層ごとに使う額を次の順に使います。

1. 電気代: 生産の段ですでに払った額を差し引く。電気代に使う上限は `power.household_share`。
2. 必需品（食べ物・電力・衣料。財の定義の `need`）: 必需品に使う額の上限は `household.necessity.share` から、実質の使う額（1人あたり、物価指数で割る）が `household.base_income` の倍になるごとに `household.necessity.fall` 下がる（下限 `household.necessity.floor`）。食料は必要な量（人口 × `population.food_per_person`）を、前のターンの値段で「質を足した栄養あたりの値段」の安い順に `household.food_elasticity` で財ごとに割り振り、前のターンに売りに出ていた量を上限に、前の値段の `market.band` 増しを指値にして注文する。要る量は `household.hungry.steps` の段に分け、段 F までの量の指値はその ÷ F にする（同じ食費で買える量まで高く買う。値幅がないので、品不足の食料はここまで上がる）。予算が足りなければ量を減らす。上限までの差の分だけ質の高い食料（食品・肉）に替える。衣料は1人あたりの目安 `household.targets.clothing` を買う。
3. サービス: 必需品の残りのうち所得に応じた割合（下の「サービスの仕事と店」）。
4. ぜいたく品（消費財・嗜好品）と自動車: 残りのうち `household.consumer_goods_share` を、売りに出ている物の間で `household.luxury_weights` の重みで割り振る。売りに出ている量で買える額を超える分はほかのぜいたく品に回し、売りに出ていない物は買いたい量だけ記録する（作る施設や商社が動く合図）。自動車は層ごとに台数を持ち、欲しい台数（所得で増える。`household.cars.layers.*`）との差の `household.cars.catch_up` と傷んだ分（`household.cars.wear`）を、ぜいたく品の予算の `household.cars.share` までで買う。車は燃料 `household.cars.fuel.fuel` を使い、燃料が買えないと満足が下がる。
5. 町の資材: 都市の発展の段が「育てる」と決めた町の資材を、一般の層が預金の `household.housing_share` まで注文する。そろったら次のターンに町が育つ（タブ 2）。住宅への投資として数える。

消費財の注文は「いつもの値段」（家計が買ったターンの値段だけの直近 `household.usual_price_turns` ターンの平均。買っていなければ今の値段）の `household.consumer_goods_tiers` の段の指値に分け、高い段ほど少なく買う需要の曲線にします。今の値段がいつもの値段の一番下の段より安いときは、今の値段の `household.consumer_goods_low_tiers` の段を足し、値段が下がった分だけ多く買います（使う額は値段によらずほぼ予算のまま）。一番上の段より高ければ買わずに預金に残します。原価がこの上限を超えると消費財がほとんど売れないターンがあるのは、難しさとして残します（2026年10月14日）。この段の縛りは仮で、回5 で消費財の指値に直近の物価上昇率（物価の見通し）を足します。

値上がりへの慣れ（回7 後半。LB-39、W-77）: いつもの値段は買った月の値段の平均なので、費用が上がって値上がりした財（自動車・燃料）は、店に並んでいても家計が1年近く買わず、売り手も買い手もいるのに取引が止まっていました。売りに出ていたのに家計が1つも買わなかったターンが `household.reprice_turns` 続いたら、いつもの値段をその間の一番安い売りの値段との半ばまで上げます（人は値上がりに少しずつ慣れる。続けばまた半ばまで）。売りのないターンは数えません。家計が買えば数え直し、買った値段の平均が慣れた値段に届けば慣れた値段は消えます。工事の資材の指値（MK-16）と家計の車・燃料も同じいつもの値段を使います。

注文は出すときに「量 × 指値」のお金（運賃と消費税を含む）を取り置き、取り置けない分は出せません。家計の買い注文の優先順位は `market.household_priority` です（板寄せの細部はタブ 3）。

### 飢えた家計の買い方

前のターンに食べた割合が `household.hungry.threshold` より少なかったか、飢えの蓄えが残っている家計は、使う額に預金の `household.hungry.savings` を足した額を食費の限りにし、ほかの層の分にも手を伸ばして、要る量の累積の割合 `household.hungry.steps` の段ごとに、飢える前の値段から `household.hungry.elasticity` で決まる倍率まで買い上がります（値幅の上端を超える）。値段は買い手のせり合いで上がり、その売上で農場は穀物に戻り、商社は輸入を始めます。お金のない家計から買えなくなるのは現実と同じです（値段の側はタブ 3、飢えの進み方はタブ 2）。

食料が足りないとき（売りに出ている量では足りないか、前のターンに食べきれなかったとき）は、食費のうち足りない割合の分をサービスにもぜいたく品にも使わず、手元に残します。飢えた家計の買い上がる指値の取り置きは、サービスとぜいたく品の予算から引きません（層の中の少しの人が飢えただけで、層の全員が何も買わなくなるため）。

村の仕事のない住民は、自給の農業で自分の食べる分をまかない、市場で買いません。前のターンに一般の家計が食べられなかった割合の村の働き手は、仕事を休んで自分の畑で食べる分を作ります（耐えられる少しの不足 `population.hunger.tolerance` までなら戻らない）。畑に戻った人は、食べ物を作る施設（農場・漁港・牧場・食品工場）には勤められます。市場に食べ物が出るようになったら、1ターンに `labor.back_to_work` ずつ仕事に戻ります。一般の層の飢えの蓄えは、市場で食料を買う人と畑で食べている人とで分けて持ちます（タブ 2）。

### 消費税の家計側

消費税 `fiscal.consumption_tax` は、家計が市場で買う物（食料・衣料・ぜいたく品・サービス）と電気に、代金に上乗せして政府に払います。家計の指値は税込みの予算から税抜きに直して板寄せに出し、運賃も同じように割って出すので、税と運賃を払っても指値より不利にはなりません。サービスには運賃がかかりません。税率は命令で変えられ、次の段から効きます（タブ 6）。

### サービスの仕事と店

家計が所得の一部を商店・飲食・理美容・娯楽・修理などのサービスに使い、その売上で島の商業・サービス業が人を雇います。回7 で、品物の売り場は企業の商店と百貨店に移しました（タブ 5「店と小売り」）。島に1つの商業・サービス業は、飲食・理美容などのサービスと、店で買いきれなかった品物を割高に売る小さな店と屋台の集まりとして残り、屋台で売った分の人はサービスを出しません。

- 品目と施設: 財「サービス」（`services.good`）はその場で作ってその場で使い、持ち越せず、島の外へ運べません。島に1つの商業・サービス業（`services.facility`。マスを持たない施設）が出し、多くの小さな店の集まりとして倒産と撤退はしません。持ち主は経済体制の既定（市場経済と混合経済は民営、計画経済は国営）です。働く人1人が1ターンに `services.per_worker` を出し、初めの値段は賃金 ÷ 1人の量に `market.initial_prices.markup` を上乗せした額です。
- 買い方: 家計の層は、必需品（食料・衣料）を買った残りのうち `household.services.share` をサービスに使います。実質の所得が `household.base_income` の倍になるごとに `household.services.rise` ずつ増え、半分になるごとに減ります（`household.services.floor`〜`household.services.max`）。所得の低い国では食べ物に、高い国ではサービスに多く使います。消費税がかかり、運賃はかかりません。
- 店の場所と雇い方（仮）: 住民は通勤圏の中でいちばん人の多い集落（同じなら近い方）でサービスを買い、そこが店の場所です。雇う人数は場所ごとに買いに来る住民の数で割り振り、村の人は近くの町へ買いに行くので町に店が集まります。店は、場所の通勤圏から前のターンの人を雇い続けてから、ほかの施設が雇った後に残った失業者を近いマスの順に雇います。店はほかの施設から引き抜かず、ほかの施設は賃金にかかわらず店から引き抜けます。村の自給の農家も雇われます（町の仕事に移る人の流れ）。店で雇いきれなかった席は、人手の足りない施設と同じく人を呼び、町を育てます（タブ 2）。
- 値段と雇う人数: 値段はほかの施設と同じく店の希望価格を売れ行きで上げ下げし、板寄せで決まります。売れ残りはそのターンのうちに消えます。雇う人数の目安は、直近の売上（その値段で買えなかった分も足す）× `services.labor_share` ÷ 賃金で、前のターンから `market.sales_smoothing` の割合だけ近づけます。計画経済の島では、公定価格での需要（買えなかった分を含む）に `planning.target_markup` を上乗せした分を雇います。賃金は今の決まり方で、上げる上限は値段 × 1人の量です。
- 資金: 運転資金は銀行から借ります。審査は目安の人数を雇ったときの売上 − 賃金で見ます。借りられなければ持ち主が出資します。
- 統計と画面: 統計にサービスで働く人と売上、施設の画面に店の場所ごとの人数を出します（タブ 11）。
- 起きていること: 今の店は売上に見合う人数まで誰でも雇うので、失業率がふつうの失業率を下回る島が多くあります。失業の低さは仕組みの結果ではなく「最後に雇う」決まりから出た数です。

**回7 の作り直し**（2026年10月16日のカードで、置き場所は「両方」、受け皿は「自営の小商い」）: 店を企業の施設として、ほかの産業と同じ仕組みにします。雇い方はほかの施設と同じく賃金を出して人を取り合い、「最後に雇う」と「賃金にかかわらず店から引き抜ける」はやめます。レシピに人手のほか電力・食料（飲食の分）・消費財（店の消耗品）を少し使います。店を開くには建設費が要り、設備は減価償却し、民営は見込みの利益率が借りる金利と上乗せを超えると参入し、赤字が続けば撤退し、借金が払えなければ倒産します。持ち主は企業（チェーン店・百貨店。財閥も持てる）で、計画経済では国営の店です。小さな店は町の中に入り、町の段階で入る店の数が決まります（マスは取らない）。百貨店やショッピングモールのような大きな店は、工業団地と同じく指定した商業地のマスに民間が建て、計画経済では国が建てます（地図の絵が1つ要る）。職のない人は、失業手当より稼げると見込めば自分で小さな店や屋台を始め、稼ぎは雇われるより少なく、店と客を取り合います。失業手当が手厚い国ほど自営は少なく、失業として数えられる人が多くなります。家計がサービスに使う割合と、品目「サービス」1つは残します。失業が今より上がる島が出ますが、式で下げず、店がなぜ建たないかを測りで見ます。案は共有フォルダの ideas/services-rework-20261016.md と ideas/firms-20261015.md にあります。

### 家計の支え合い（回7）

仕事のない家計が食べ物を買いきれないとき、一般の層と技術者の層（働く家族・親せき・村）が、そのターンの可処分所得の `household.support.share` までを上限に、足りない分を送ります（賃金の段。`hakoniwa_core/economy/households.py`）。送った分は送った側の所得から引き、受けた分は食べ物だけに使います。手当のない国でもすぐには飢えなくなる代わりに、働く家族の買い物が減り、働く家計も貧しければ送れる分は少なくなります（現実でも、仕送りは世帯の所得の1割ほど）。足りない分は今までの飢えの仕組み（預金を崩す、村へ逃れる）に進みます。送った額は統計（`households.support`）に出し、飢え始めたら国の要約と注意で知らせます（タブ 11）。きっかけは Codex の試し遊びの北洋国で、失業した家計が食べ物を買えず、市場に穀物と魚が余っていたのに3か月で人が亡くなったことです（1943 年のベンガル飢饉では、食べ物はあったのに賃金で暮らす人が買えずに亡くなった）。

### 幸福度と政情への効き目

幸福度は家計の層ごとに出して人数で平均します。一般の層はマスごと（働き口・電力・汚染はマスの値）、ほかの層は島全体で出し、資本家階級の「働き口」はいつも満点です。項目の重みと配り直しはタブ 2 です。仕事と家計から来る減点は、実質賃金が1年前より下がった分（`population.happiness.real_wage_per_point`、最大 `population.happiness.real_wage_max`）、物価上昇率が `population.happiness.inflation_threshold` を超えた分（`population.happiness.inflation_per_point`、最大 `population.happiness.inflation_max`）、未払い賃金（`population.happiness.arrears`）、飢えの蓄え（`population.happiness.hunger`、最大 `population.happiness.hunger_max`）です。政情の目標には失業率（`politics.weights.unemployment`・`politics.weights.unemployment_free`）と格差が、支持率には実質賃金と失業率の1年の伸びが効きます（タブ 10）。

### 統計

記録の段で島ごとに残す仕事と家計の統計は、層ごとの人数・可処分所得・預金・幸福度（`layer.<層>.*`）、平均賃金（一般の労働者だけ。`wage.average`）と技術者の賃金（`engineers.wage`）、実質賃金、失業率（一般と技術者）、格差、未払いの働き手（`arrears.workers`）、自給の人数、サービスで働く人と売上です。層ごとの1人あたりの所得は画面の側で計算します。画面と API はタブ 11、統計の名前の一覧は `GET /api/islands/<id>/economy/overview` の `choices` です。

## 前提と依存

### この仕組みが前提にしていること

- 施設の操業目標（売れ行き）が雇う人数を決めること（タブ 3・5）。フェーズ1の「人手が縛り」は市場が入って「売れ行きが縛り」に変わった。
- 失業の受け皿（サービス業・企業・自営）があること。今は仮の店が受け皿で、回7 の企業の仕組みに載せ替える。
- 町（住む所）と通勤圏があり、人が働き口の近くへ移ること（タブ 2）。店で雇いきれなかった席も人を呼ぶ。
- 政府が賃金・手当を払える国庫を持つこと（タブ 6）。払えないときは遅配で遅らせる。
- 銀行が家計の預金を預かり、利子を付け、運転資金を貸すこと（タブ 7）。預金が使われない分が投資の需要として戻る。
- 大学が技術者を育て、引退させること（タブ 8）。技術者の席の割合はレシピの定義。
- 市場に食料・消費財・サービスが売りに出ていること（タブ 3）。品切れなら買いたい量の記録だけが残る。
- 物価指数と物価上昇率（タブ 11 の統計）。賃金の追い方と使う額の割合がこれで動く。

### この仕組みの結果を前提にしている仕組み

- 施設の稼働率と変動費（人件費）→ 生産と採算、参入の判断（タブ 3・5）。
- 家計の注文 → 食料・消費財・サービス・自動車・電力の需要と値段（タブ 3）。売れ行きの見込み → 操業目標 → 雇う人数、の輪。
- 食べた量と飢えの蓄え → 人の生まれ亡くなり・逃れ・移民（タブ 2）。失業している家計から飢える。
- 所得税・消費税の収入と失業手当の支出 → 財政（タブ 6）。公共事業費は失業の多さで膨らみ、失業が減ると借金の比が表に出る。
- 家計の預金 → 銀行の預金と貸し出し、資本家階級の出資（タブ 5・7）。
- 失業率・実質賃金・格差 → 幸福度（タブ 2）と政情・支持率（タブ 10）。政情の失業の重みは設計の値に戻してある。
- 平均賃金 → 公務員・作業員の賃金、初めの値段と公定価格の原価、関門の測り（タブ 6・3・12）。
- 標準の計画と民営の場所探しは、店で働く人を「いつでも雇える人」と数える（回7 で見直す）。
