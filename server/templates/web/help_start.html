{% translate "このゲームでプレイヤーがすること" %}

{% translate "プレイヤーは国の政府です。工場を一つずつ動かすのではなく、施設を建て、予算・税・規制を決め、足りない物を国の倉庫や貿易で補います。働く人・会社・銀行・家計は自分で考えて動き、その結果が毎月（1ターン）の更新で出ます。" %}

{% translate "命令を出さなくても島は動きます。まずは何ターンか更新を待ち、何が足りないかを見てから手を打つのが基本です。一度にたくさん変えると、どれが効いたのか分からなくなります。" %}

{% translate "建国の直後（まだ一度も更新されていない）" %}

{% translate "首都と町、村、初めの農場・漁港・発電所・工場、学校、銀行、置ける場所があれば港と商社がそろっています。初めの施設は「稼働準備中」で、最初の更新で動き出します。止まっているわけではありません。" %}

{% translate "市場経済・混合経済では、最初の命令に「工業団地・オフィス街の指定」をおすすめします。民営の工場は工業団地のマスにしか建たず、建国の島には工業団地がありません。地図で首都の近くの空いた平地を選び、工業団地に指定すると、民間の会社が採算を見て工場を建てます。計画経済では民間の会社はないので、工場は国が「施設の建設」で建てます。" %}

{% translate "独立採算の施設には建国のときの手元資金があり、失業手当も初めから払われますが、その後の収支は「施設」で確かめます。" %}
