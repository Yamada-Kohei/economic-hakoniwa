{% translate "手引き" %}

{% translate "進行の流れ" %}

  1. {% translate "登録後に建国します。島の形・地形・地下資源・首都・体制・名前・地名の様式を決めます。" %}
  2. {% translate "島の画面で地図のマスを選択し、施設の建設などの命令を追加します。" %}
  3. {% translate "決まった時刻ごとにターンが進み、命令が上から実行され、施設が稼働し、人口が増減します。" %}
  4. {% translate "結果は島の画面の「出来事」とターンログで確認できます。" %}

{% translate "仕組み" %}

{% translate "労働者" %}
{% blocktranslate with r=commute %}住民の一部が労働者となり、町から {{ r }} マス以内の施設に通勤します。優先度の値が大きい施設から順に労働者が配置されます。村の住民は就業先がなくても自給農業で生活できます。{% endblocktranslate %}
{% translate "生産と市場" %}
{% translate "施設は労働者・原料・電力がそろった割合で稼働します。生産した資源は施設の在庫に入り、毎ターン資源ごとの市場（板寄せ）で売買されます。値段は売れ行きに応じて1ターンに最大1割ずつ動き、施設は売れ行きに合わせて生産量を調整します（生産調整中）。原料は市場で購入し、原料が届くまでは労働者を雇いません。買えなかったときは、品不足なら「原料不足」、原料が高くて採算が合わなければ「原料が割高」、お金が足りなければ「資金不足」と表示されます。売り手と買い手は島の運送業に運賃を半分ずつ払います。運賃は売り手から買い手までの道のりで決まるので、取引の相手が近い施設ほど費用がかかりません。国の倉庫の資源は命令で売買できます。一定期間で劣化する資源もあります。" %}
{% translate "お金と賃金" %}
{% translate "就業者は施設から賃金を受け取り、食料・消費財・電力を市場で購入します。賃金は施設ごとに決まり、労働者が足りない施設は賃金を上げます。労働者は賃金の高い施設から順に配置されます。政府は所得税・消費税・法人税を集め、公務員の賃金・公共事業・失業手当に使います。公共事業費は、優先度の高い工事から作業員の賃金と資材の代金に充てます。国庫が足りないときは国債を発行します（下の「金融と企業」を参照）。税率・予算・失業手当・最低賃金は命令で変更できます。" %}
{% translate "銀行" %}
{% translate "家計と施設の預金は銀行が預かります（下の「金融と企業」を参照）。国営の施設は、国庫直轄（売上も費用も国庫）か独立採算かを命令で選べます（地図で施設のマスを選択し「会計方式の変更」）。" %}
{% translate "電力" %}
{% translate "発電所と接続された施設と町にだけ電力が供給されます。施設同士の隣接か送電線のマスで接続します。電気料金は送電網ごとの市場で決まり、発電量が電力需要に満たないときは優先度の高い所から供給し、足りなかった施設は「電力不足」と表示されます。発電所のない送電網にある施設は「送電網につながっていません」と表示されます。命令で電気料金の上限（公共料金）を決めることもできます。送電線は海を越えられないため、離れ小島には島内の発電所が必要です。" %}
{% translate "人口と町" %}
{% translate "食料が足りると人口が増えます。仕事のある人の割合と幸福度が高いほどよく増えます。町は働き口の近くに自然に形成され、人口が増えると村・町・都市・大都市へ発展します。形成・発展には市場で購入する資源（木材・建材など）を使い、不足すると止まります。広げたくない所は開発禁止区域に指定できます。食料が不足すると人口が減り、幸福度が低いと国外へ移住する人が出ます。汚染は周辺の幸福度を下げます。" %}
{% translate "行政力" %}
{% blocktranslate with base=base_admin max=max_admin people=admin_per_office %}行政力は1ターンに実行できる命令の数です。原則 {{ base }} つで、中央省庁で働く公務員 {{ people }} 人ごとに1つとなり、最大 {{ max }} つまでです。超えた命令は次のターン以降に繰り越されます。国名・地名・施設名の変更は数に含みません。{% endblocktranslate %}
{% translate "地名" %}
{% translate "島を区画に分け、建国時に選んだ様式（日本風・イギリス風・アメリカ風・ドイツ風・ロシア風・スペイン風など）で区画ごとに地名が付きます。首都のある区画は首都名です。地名は命令で変更できます。" %}
{% translate "地下資源" %}
{% translate "建国時に選択した地下資源だけを、山の鉱山・採石場で採掘できます。鉱山の数には上限があります（下の施設の表を参照）。鋼鉄には鉄鉱石と石炭の両方が必要なため、どちらかがない島では鋼鉄を生産できません。" %}
{% translate "災害" %}
{% translate "まれに地震・台風・洪水・火災が発生し、施設が一定期間停止します。" %}

{% translate "金融と企業" %}

{% translate "金融の命令は島の画面の「金融の命令」から、施設ごとの命令は地図で施設のマスを選択して出します。" %}

{% translate "銀行と融資" %}
{% translate "銀行は家計と施設の預金を預かり、独立採算の施設に融資します。次のターンの支払いに預金が足りない施設は運転資金を、民営工場は建設資金を借ります。借りられるのは、返済に足りる利益があり、借入が多すぎず、貸す銀行の自己資本比率が規制の値以上のときで、金利のいちばん低い銀行から借ります。融資の金利は「政策金利 ＋ 銀行の利ざや ＋ 借入の多さの上乗せ」で、毎ターン変わります。家計は預金の一部を金利の高い銀行へ移し、自己資本比率が規制を下回った銀行や中央銀行から借りている銀行からは預金が流れ出します（取り付け）。" %}
{% translate "政策金利と中央銀行" %}
{% blocktranslate with turns=cb_lock_turns %}中央銀行が政府の下にあるときは、命令で政策金利と、中央銀行が毎ターン国債を売り買いする額を決めます。独立させると、中央銀行が物価上昇率と失業率を見て政策金利を少しずつ動かし、政府は国債の売買・直接の引き受け・銀行への緊急の貸し出しを決められなくなります。独立を切り替えた後 {{ turns }} ターンは戻せません。準備預金が足りない銀行には、国債と延滞のない融資を担保に中央銀行が貸し、担保が足りなければ資金繰りが破綻します（緊急の貸し出しの命令で、担保のない分も貸せます）。{% endblocktranslate %}
{% translate "国債の入札と債務不履行" %}
{% translate "国庫が足りなくなる分は、毎ターン国債を入札で発行して銀行に買ってもらいます。利回りは政策金利・期間・借金の対GDP比・物価上昇率で決まります。売れ残りは、政策が「中央銀行が引き受け」で中央銀行が独立していなければ中央銀行が引き受け、そうでなければその分の支出を減らします（支払いの順番の後ろから削られます）。利払いと償還に国庫が足りないとき、または命令で止めたときは債務不履行になり、額面が切り下がって国債を持つ銀行が損をし、国債の利回りがしばらく跳ね上がります。" %}
{% translate "倒産と差し押さえ" %}
{% blocktranslate with arrears=arrears_limit turns=foreclosure_turns %}融資の返済が {{ arrears }} ターン続けて遅れた施設は倒産し、止まって労働者は失業します。預金は貸した銀行に返し、返しきれない分は銀行の損（貸し倒れ）になります。施設はいちばん多く貸していた銀行が差し押さえ、{{ turns }} ターンの間売りに出します（民間の参入か国有化で買えます）。売れなければ取り壊します。民営の施設は、売れない状態や赤字が続くと閉鎖に入り、在庫を売り切ってからマスを空けます。計画経済の島では倒産は起きません。{% endblocktranslate %}
{% translate "銀行の破綻" %}
{% translate "自己資本がマイナスになった銀行と、資金繰りに行き詰まった銀行は破綻し、新しい融資と預金の受け入れを止めます。地図で銀行を選択し、次のターンまでに処理を選びます（行政力を使いません）。救済は政府が資本を入れて国営銀行として残し、引き継ぎは預金・融資・国債を健全な銀行（預金の最も多い銀行）に移し、清算は融資を安く売ったとして損失を数えてから同じく移します。引き継ぎと清算の損失は、保護されない預金（預金保護の上限を超えた分）と、破綻した銀行に貸していた銀行が負い、足りない分は政府が払います。選ばなければ引き継ぎ（引き継ぐ銀行がなければ救済）になります。" %}
{% translate "民営工場と民間銀行の参入" %}
{% translate "市場経済と混合経済の島では、品不足か値段が原価より高い資源について採算が合えば、民間の資本が工業団地のマスに工場を建てます（混合経済では基幹産業を除きます）。建設費の一部を資産を持つ層が出し、残りを銀行から借ります。地図の「工業団地の指定」でマスを指定してください。民間銀行は、参入の政策が「自由」なら採算を見てオフィス街に開業し、「許可制」なら免許の命令を出したときだけ開業します。" %}
{% translate "補助金" %}
{% translate "年の予算の「補助金」から出し、独立採算の施設（銀行を除く）にだけ出ます。生産補助は資源ごとか施設ごとに売上の割合を、設備投資補助は資源ごとに新しく建つ民営工場の建設費の割合を、救済補助は施設ごとに赤字の分を出します。割合 0 の命令でやめられます。" %}
{% translate "国有化と民営化" %}
{% translate "民営の施設は、純資産（資産 − 借入）の額で政府が買い取れます（借入も引き継ぎます）。差し押さえ中の施設は銀行から売り値で買います。国営の施設は、経済体制で民間が持てる施設なら、純資産の額で資産を持つ層に売れます。銀行の持ち主は国有化・民営化では変わりません（破綻処理で変わります）。" %}
