{% blocktranslate with r=commute %}住民のうち働ける人（労働力人口）が、町から {{ r }} マス以内の施設に通勤します。まず前の月の雇用を続け、不足する施設は賃金の高い順に人を雇い、一定の賃金差があれば他の施設から引き抜きます。同じ賃金なら優先度の高い施設が先です。{% endblocktranslate %}

{% translate "生産と市場" %}

{% translate "施設は労働者・原料・電力がそろった割合で稼働します。生産した資源は施設の在庫に入り、毎ターン資源ごとの市場（板寄せ）で売買されます。値段は売り手と買い手の付け値だけで決まり、1ターンに動く幅の上限はありません。売り手の希望価格は売れ行きに応じて1ターンに最大1割ずつ動き、ふだんの買い手は前の値段の1割増しまで買います。" %}

{% translate "品不足のときは、家計は食料を同じ食費で買える量まで高く買い、工場は買い負けた原料を1ターンに1割ずつ、採算の合う値段まで買い上がるので、値段はそこまで上がります。施設は売れ行きに合わせて生産量を調整します（生産調整中）。原料は市場で購入し、原料の見込みも雇う人数と操業を左右します。買えなかったときは、品不足なら「原料不足」、原料が高くて採算が合わなければ「原料が割高」、お金が足りなければ「資金不足」と表示されます。" %}

{% translate "売り手と買い手は島の運送業に運賃を半分ずつ払います。運賃は売り手から買い手までの道のりで決まるので、取引の相手が近い施設ほど費用がかかりません。国の倉庫の資源は命令で売買できます。買いは年の予算の「国の倉庫の買い入れ費」の範囲で注文し（建国のときは 0 です）、売りは国の工事・インフラの維持・設備の直しが倉庫の物を先に使った残りまでです。" %}

{% translate "倉庫の物を使うのは国の工事だけで（民営の工事は市場で買います）、1ターンに1段分ずつ使い、尽きると公共事業費で市場から買います。計画経済では、公共事業費で買えなかった資材も生産目標に数えます。約定した量と、足りなかったわけはターンログに出ます。一定期間で劣化する資源もあります。劣化してそのターンの終わりに捨てられる分は、売り手が値段を問わず売りに出し、その場で食べる家計に先に回ります。" %}

{% translate "工場がそれしか買えなかったときは使う前に捨てられるので、原料不足（次のターンまで持つ物が高く売れ残っていれば原料が割高）と表示されます。" %}

{% translate "お金と賃金" %}

{% translate "就業者は施設から賃金を受け取り、食料・消費財・電力を市場で購入します。賃金は施設ごとに決まり、労働者が足りない施設は賃金を上げます。労働者は賃金の高い施設から順に配置されます。電力・送電網・原料の不足で動けなかった分は休業手当を払い、人を残します。原料が割高、資金不足など施設の都合による停止は通常の賃金です。政府は所得税・消費税・法人税を集め、公務員の賃金・公共事業・失業手当に使います。" %}

{% translate "公共事業費は、優先度の高い工事から作業員の賃金と資材の代金に充てます。国庫が足りないときは国債を発行します（下の「金融と企業」を参照）。" %}

{% translate "幸福度は食事・働き口・電力・衣料・ぜいたく品・上下水道・教育などで変わり、汚染・値上がり・実質賃金の低下・未払い賃金・飢えが下げます。国外への移民は、町の幸福度だけで決まる仕組みではありません。" %}

{% translate "生まれる人と亡くなる人" %}

{% translate "生まれた町に空きがなければ、空いた町へ移ります。どこにも住む所がない人は消えず、過密に住みます。過密が続くと暮らしと人口の増減にも響きます。" %}

{% translate "市場に食料があっても、お金のない家計は買えません。「市場」で物が足りないのか、家計の所得が足りないのかを確認します。失業手当や働く家族からの支え合いは、仕事のない家計の食費を支えます。" %}

{% translate "食べ物が買えない村の働き手は仕事を休んで畑へ戻ります。食べ物を作る施設には勤められ、供給が戻れば少しずつ元の仕事へ戻ります。町で飢えが続いた人は、空きのある村へ逃れて自給します。食料と働き口が戻れば、村から町へも少しずつ戻ります。" %}

{% translate "買いたい人がいるのに穀物が品切れなら、作り始められる値段や輸入が引き合う値段へ向けて値上がりします。作れる民営の農場は通常の見直しを待たずに作付けを見直しますが、蒔き直した畑は育つまで収穫できません。" %}
