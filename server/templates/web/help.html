{% translate "しくみ" %}

{% translate "働き手" %}
{% blocktranslate with r=commute %}人は住宅地から {{ r }} マス以内の施設に通って働きます。優先度の数が大きい施設から先に人が回ります。村の人は働き口がなくても自給の農業で暮らせます。{% endblocktranslate %}
{% translate "生産と倉庫" %}
{% translate "施設は働き手・原料・電力がそろった割合だけ動きます。作った物は島の倉庫に入り、優先度の高い施設から原料として配られます（このフェーズではお金は使いません）。古くなると傷む物もあります。" %}
{% translate "電力" %}
{% translate "発電所とつながった施設と住宅地にだけ電気が届きます。施設どうしが隣り合うか、送電線のマスでつなぎます。足りないときは優先度の高い所から配ります。" %}
{% translate "人口と住宅地" %}
{% translate "食料が足り、働き口があると人口が増えます。住宅地は働き口の近くに自然に広がり、人が増えると村・町・市・大都市へと育ちます。広げたくない所は「開発禁止」にできます。食料が足りないと人が減り、幸福度が低いと島を出て行く人が出ます。" %}
{% translate "行政力" %}
{% blocktranslate with base=base_admin %}命令にはそれぞれ行政力が要ります。行政力は {{ base }} に、官庁で働く人の分が足されます。足りない命令は次のターン以降に回ります。{% endblocktranslate %}
