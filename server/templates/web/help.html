{% translate "仕組み" %}

{% translate "労働力人口と就業者" %}
{% blocktranslate with r=commute %}住民のうち働ける人（労働力人口）が、町から {{ r }} マス以内の施設に通勤します。優先度の値が大きい施設から順に労働者が配置されます。仕事のある人が就業者、仕事を探している人が失業者で、完全失業率は労働力人口のうちの失業者の割合です。村の住民は就業先がなくても自給農業で生活でき（自給農家）、失業者に数えません。家計は、労働者階級・資本家階級・技術者・失業者の層に分けて数えます。{% endblocktranslate %}
{% translate "生産と市場" %}
{% translate "施設は労働者・原料・電力がそろった割合で稼働します。生産した資源は施設の在庫に入り、毎ターン資源ごとの市場（板寄せ）で売買されます。値段は売り手と買い手の付け値だけで決まり、1ターンに動く幅の上限はありません。売り手の希望価格は売れ行きに応じて1ターンに最大1割ずつ動き、ふだんの買い手は前の値段の1割増しまで買います。品不足のときは、家計は食料を同じ食費で買える量まで高く買い、工場は買い負けた原料を1ターンに1割ずつ、採算の合う値段まで買い上がるので、値段はそこまで上がります。施設は売れ行きに合わせて生産量を調整します（生産調整中）。原料は市場で購入し、原料が届くまでは労働者を雇いません。買えなかったときは、品不足なら「原料不足」、原料が高くて採算が合わなければ「原料が割高」、お金が足りなければ「資金不足」と表示されます。売り手と買い手は島の運送業に運賃を半分ずつ払います。運賃は売り手から買い手までの道のりで決まるので、取引の相手が近い施設ほど費用がかかりません。国の倉庫の資源は命令で売買できます。買いは年の予算の「国の倉庫の買い入れ費」の範囲で注文し（建国のときは 0 です）、売りは国の工事・インフラの維持・設備の直しが倉庫の物を先に使った残りまでです。倉庫の物を使うのは国の工事だけで（民営の工事は市場で買います）、1ターンに1段分ずつ使い、尽きると公共事業費で市場から買います。計画経済では、公共事業費で買えなかった資材も生産目標に数えます。約定した量と、足りなかったわけはターンログに出ます。一定期間で劣化する資源もあります。劣化してそのターンの終わりに捨てられる分は、売り手が値段を問わず売りに出し、その場で食べる家計に先に回ります。工場がそれしか買えなかったときは使う前に捨てられるので、原料不足（次のターンまで持つ物が高く売れ残っていれば原料が割高）と表示されます。" %}
{% translate "お金と賃金" %}
{% translate "就業者は施設から賃金を受け取り、食料・消費財・電力を市場で購入します。賃金は施設ごとに決まり、労働者が足りない施設は賃金を上げます。労働者は賃金の高い施設から順に配置されます。政府は所得税・消費税・法人税を集め、公務員の賃金・公共事業・失業手当に使います。公共事業費は、優先度の高い工事から作業員の賃金と資材の代金に充てます。国庫が足りないときは国債を発行します（下の「金融と企業」を参照）。税率・予算・失業手当・最低賃金は命令で変更できます。" %}
{% translate "銀行" %}
{% translate "家計と施設の預金は銀行が預かります（下の「金融と企業」を参照）。国営の施設は、国庫直轄（売上も費用も国庫）か独立採算かを命令で選べます（地図で施設のマスを選択し「会計方式の変更」）。" %}
{% translate "電力" %}
{% translate "発電所と接続された施設と町にだけ電力が供給されます。施設同士の隣接か、送電網の整備度が30%以上のマスで接続します。電気料金は送電網ごとの市場で決まり、発電量が電力需要に満たないときは優先度の高い所から供給し、足りなかった施設は「電力不足」と表示されます。発電所のない送電網にある施設は「送電網につながっていません」と表示されます。命令で電気料金の上限（公共料金）を決めることもできます。送電線は海を越えられないため、離れ小島には島内の発電所が必要です。" %}
{% translate "人口と町" %}
{% translate "食料が足りると人口が増えます。仕事のある人の割合と幸福度が高いほどよく増えます。町は働き口の近くに自然に形成され、人口が増えると村・町・都市・大都市へ発展します。形成・発展には市場で購入する資源（木材・建材など）を使い、不足すると止まります。広げたくない所は開発禁止区域に指定できます。食料が不足すると人口が減り、幸福度が低いと国外へ移住する人が出ます。汚染は周辺の幸福度を下げます。" %}

{% blocktranslate with base=base_admin max=max_admin people=admin_per_office %}行政力は1ターンに実行できる命令の数です。原則 {{ base }} つで、中央省庁で働く公務員 {{ people }} 人ごとに1つとなり、最大 {{ max }} つまでです。超えた命令は次のターン以降に繰り越されます。1つの命令に要る行政力がそのターンの行政力より大きいときは、列の先頭に来たターンに、そのターンの行政力を全部使って実行します。国名・地名・施設名の変更は数に含みません。{% endblocktranslate %}

{% translate "金融の命令は島の画面の「金融の命令」から、施設ごとの命令は地図で施設のマスを選択して出します。" %}

{% translate "銀行と融資" %}
{% translate "銀行は家計と施設の預金を預かり、独立採算の施設に融資します。次のターンの支払いに預金が足りない施設は運転資金を、民営工場は建設資金を借ります。借りられるのは、返済に足りる利益があり、借入が多すぎないときで、金利の低い銀行から順に、その銀行が貸せる分ずつ借ります。銀行が貸せるのは、貸した後も自己資本比率が規制の値以上で、1つの民営施設への融資の残高が銀行の自己資本の25%以内の分までです（大口融資の規制。国営施設は対象外）。民営工場の建設資金を借りきれなければ、資本家階級が多く出資します。融資の金利は「政策金利 ＋ 銀行の利ざや ＋ 借入の多さの上乗せ」で、毎ターン変わります。家計は預金の一部を金利の高い銀行へ移し、自己資本比率が規制を下回った銀行や中央銀行から借りている銀行からは預金が流れ出します（取り付け）。" %}
{% translate "政策金利と中央銀行" %}
{% blocktranslate with turns=cb_lock_turns %}中央銀行が政府の下にあるときは、命令で政策金利と、中央銀行が毎ターン国債を売り買いする額を決めます。独立させると、中央銀行が物価上昇率と失業率を見て政策金利を少しずつ動かし、政府は国債の売買・直接の引き受け・銀行への緊急の貸し出しを決められなくなります。独立を切り替えた後 {{ turns }} ターンは戻せません。準備預金が足りない銀行には、国債と延滞のない融資を担保に中央銀行が貸し、担保が足りなければ資金繰りが破綻します（緊急の貸し出しの命令で、担保のない分も貸せます）。{% endblocktranslate %}
{% translate "国債の入札と債務不履行" %}
{% blocktranslate with premium=default_premium decay=default_decay exclusion=default_exclusion crunch=default_crunch %}国庫が足りなくなる分は、毎ターン国債を入札で発行して銀行に買ってもらいます。利回りは政策金利・期間・借金の対GDP比・物価上昇率で決まります。売れ残りは、政策が「中央銀行が引き受け」で中央銀行が独立していなければ中央銀行が引き受け、そうでなければその分の支出を減らします（支払いの順番の後ろから削られます）。銀行は国債を時価で自己資本に数えるので、金利が上がって国債が値下がりすると自己資本が減り、マイナスになれば破綻します。値上がり益と値下がり損は、売るか償還されるまで損益に入れず、法人税と配当（国営の銀行は国庫への納付）にも、中央銀行の納付にも回りません。利払いと償還に国庫が足りないとき、または命令で止めたときは債務不履行になり、額面が切り下がって国債を持つ銀行が損をします。債務不履行には次の罰があります。国債の利回りに {{ premium }}% が上乗せされ、{{ decay }} ターンかけて減ります。{{ exclusion }} ターンのあいだは銀行が国債を買わず、入札では売れません（売れ残りは上と同じく中央銀行が引き受けるか、その分の支出を減らします）。損をした銀行は {{ crunch }} ターンのあいだ新しい融資を止め、返す元金の借り換えだけを貸します（民営工場の参入と、新しい運転資金の借り入れが止まります。計画経済の島を除く）。{% endblocktranslate %}
{% translate "倒産と差し押さえ" %}
{% blocktranslate with arrears=arrears_limit turns=foreclosure_turns %}融資の返済が {{ arrears }} ターン続けて遅れた施設は倒産し、止まって労働者は失業します。預金は貸した銀行に返し、返しきれない分は銀行の損（貸し倒れ）になります。施設はいちばん多く貸していた銀行が差し押さえ、{{ turns }} ターンの間売りに出します（民間の参入か国有化で買えます）。売れなければ取り壊します。民営の施設は、売れない状態や赤字が続くと閉鎖に入り、在庫を売り切ってからマスを空けます。資材を買えずに進まない民営の工事は、しばらく続くと取りやめになります。計画経済の島では倒産は起きません。{% endblocktranslate %}
{% translate "設備の傷みと直し" %}
{% translate "農場・鉱山・工場・発電所・造船所は、建てたときの資材（機械・鋼鉄・建材・木材）を設備として持ち、毎ターン少しずつ傷みます（機械は年8%、鋼鉄は年3%、建材は年2.5%、木材は年4%）。一番傷んだ資材の残りの割合までしか作れません（施設の欄の「設備」）。国営の施設は、国が年の予算の「公共事業費」で傷んだ資材を買って直します。国の倉庫の資材を先に使い、新しい工事より先に買います。予算が足りないと傷んだまま作れる量が落ち、7割を切るとお知らせします。民営の施設は、稼ぎが直す費用に見合うときだけ自分のお金で直し、見合わなければ直さずに使い、3割を切ると閉じます。直した代金は設備への投資で、帳簿の減価償却は傷んだ分の値打ちです。海運業は、寿命の近い輸送船を、使っている分だけ前もって買い替えます。" %}
{% translate "銀行の破綻" %}
{% translate "自己資本がマイナスになった銀行と、資金繰りに行き詰まった銀行は破綻し、新しい融資と預金の受け入れを止めます。地図で銀行を選択し、次のターンまでに処理を選びます（行政力を使いません）。救済は政府が資本を入れて国営銀行として残し、引き継ぎは預金・融資・国債を健全な銀行（預金の最も多い銀行）に移し、清算は融資を安く売ったとして損失を数えてから同じく移します。引き継ぎと清算の損失は、保護されない預金（預金保護の上限を超えた分）と、破綻した銀行に貸していた銀行が負い、足りない分は政府が払います（残った預金までが預金保護で、それを超える中央銀行からの借り入れなどの穴は、政府の肩代わりとして別にログに出ます）。選ばなければ引き継ぎ（引き継いでも自己資本比率が規制の値を下回らない銀行がなければ救済）になります。" %}
{% translate "民営工場と民間銀行の参入" %}
{% translate "市場経済と混合経済の島では、品不足か値段が原価より高い資源について採算が合えば、民間の資本が工業団地のマスに工場を建てます（混合経済では基幹産業を除きます）。農場と漁港は、指定のない人の住んでいないマスにも建ちます（開発を止めるマスには建ちません）。建設費の一部を資本家階級が出し、残りを銀行から借ります。工事の資材は市場で買うので、島で作っていない資材（機械など）は、国の倉庫から売りに出さないと民間は工場を建てられません。地図の「工業団地の指定」でマスを指定してください。民間銀行は、参入の政策が「自由」なら採算を見てオフィス街に開業し、「許可制」なら免許の命令を出したときだけ開業します。" %}
{% translate "補助金" %}
{% translate "年の予算の「補助金」から出し、独立採算の施設（銀行を除く）にだけ出ます。生産補助は資源ごとか施設ごとに売上の割合を、設備投資補助は資源ごとに新しく建つ民営工場の建設費の割合を、救済補助は施設ごとに赤字の分を出します。割合 0 の命令でやめられます。" %}
{% translate "国有化と民営化" %}
{% translate "民営の施設は、純資産（資産 − 借入）の額で政府が買い取れます（借入も引き継ぎます）。差し押さえ中の施設は銀行から売り値で買います。国営の施設は、経済体制で民間が持てる施設なら、純資産の額で資本家階級に売れます。銀行の持ち主は国有化・民営化では変わりません（破綻処理で変わります）。" %}

{% translate "インフラの整備度" %}
{% translate "マスごとに道路・鉄道・上下水道・送電網の整備度（0〜100%）があり、毎ターン少しずつ傷みます。施設の周りの交通（道路と鉄道の高い方）が整うほど施設の生産性が上がり、運賃の道のりも短くなります（道路100%で半分、鉄道100%で3割）。都市に育つには上下水道50%、大都市には80%が要ります。整備度は地図の「重ねて表示」で見られます。" %}
{% translate "公共事業" %}
{% translate "地図の「インフラの工事」でマスを続けて選び、種類を選んで命令を出すと、工事の列に並びます。公共事業費から、先に傷んだ分の維持、次に並んだ順の工事に作業員の賃金と資材の代金を充てます。資材は国の倉庫にある分を先に使い、足りない分を市場で買います（石材のない島の道路は建材で作ります）。作業員は施設が雇った後に残った失業者から雇います。進まないまま続くと、わけ（公共事業費・人手・資材）がログに出ます。" %}
{% translate "教育" %}
{% translate "学校と大学は国営の施設で、教員の賃金と教材（消費財）は年の予算の「教育費」から出ます。島の教育水準は、学校の定員が子どもの数に足りているほど高い目標へ、毎ターン少しずつ動きます。教育水準が高いほど施設の生産性と幸福度が上がります。" %}
{% translate "技術者" %}
{% translate "製鉄所・機械工場・発電所・消費財工場などは、労働者の一部に技術者が要ります。技術者は大学で育ち、少しずつ引退します。席に就けない技術者が多いと、大学に入る人が減ります。技術者は通勤圏によらず島のどこの施設にも通い、賃金の高い施設から席に就きます（初めの賃金は一般の2倍）。技術者が足りない施設は、6割までしか動きません（「技術者不足」）。余った技術者は、人の集まらない一般の仕事にも就きます。" %}

{% translate "島の画面の「軍」で兵・国防費・部隊・艦隊・基地を確認し、命令を列に追加できます。移動は島の地図で部隊のマスから、航海は世界マップの「自分の艦隊」から行き先を選びます。命令はターン更新で実行されます。" %}

{% translate "兵の集め方と維持" %}

{% translate "建国の島は軍を持たず、国防費は 0 から始まります。軍を持つか、どれだけ持つかは国が決めます。志願の兵は、軍が出す賃金で失業者から先に集まります。軍の賃金が島の平均賃金より低いと、失業者しか集まりません。平均賃金以上なら、働いていた人も集まります。" %}

{% translate "徴兵は人口に比例したくじで集めます。志願より賃金が低く、働いていた人が抜けるため、人手の足りない施設が出ます。支持率が下がり、民主主義では議会の過半数の賛成が要ります。除隊した兵は失業者として家計に戻ります。新しい兵は練度が低く、訓練で育ちます。" %}

{% translate "国防費は「兵の賃金と食べ物」と「装備の買い入れと編成」に分けます。兵の賃金と食べ物は前者から払います。賃金が遅れると士気が下がり、兵が逃げて家計に戻ります。食べ物が尽きると練度が落ち、亡くなる兵も出ます。軍の画面の注意と、直近のターンに払えなかった賃金を確認してください。" %}

{% translate "部隊と艦隊の編成、基地と陣地" %}

{% translate "陸の部隊は歩兵と機甲です。兵舎のマスで編成します。艦隊は小さな軍艦・フリゲート・潜水艦・輸送船団で、軍港のある島で編成します。兵や乗員と装備がそろうまでは「編成中」、そろうと「そろった」になります。装備は「装備の買い入れと編成」の国防費で、国の倉庫と市場から集めます。部隊の解散では、兵は部隊に付いていない兵に、装備は国の倉庫に戻ります。除隊とは違い、兵は軍に残ります。" %}

{% translate "兵舎は置ける兵の数に上限があり、軍港は艦隊の母港です。レーダーは世界マップで見える範囲を広げます。要塞は施設としてマスを使い、そのマスで守る部隊を強くします。陣地は施設のマスを占めません。部隊が兵と建材を使って、何ターンかかけて掘ります。" %}

{% translate "動きと燃料" %}

{% translate "輸送船団への載せ降ろし" %}
{% translate "陸の部隊を島の外へ運ぶには、母港の軍港のマスから輸送船団に載せます。船の数で運べる重さが決まるため、空きが足りなければ載せられません。自国で降ろすときは母港の軍港を選びます。外国へは、戦争の相手の島の区画まで船団を運び、行き先の島と、港か海に接する平地の座標を指定して上陸します。港でない所は一度に降ろせる量が少なく、初めの戦闘でも弱くなります。" %}

{% translate "陸の戦闘と補給、占領と捕虜" %}

{% translate "戦争の相手の部隊と同じマスに入ると戦います。入った側が攻め、もとからいた側が守ります。兵の数だけでなく、装備・補給・士気・練度が力を左右します。山や森、町、陣地、要塞は守る側の助けになります。傷ついた兵の一部は、しばらくして戻ります。退く場所がない部隊は降伏し、兵は捕虜になります。" %}

{% translate "外国の島にいる兵は、自分で食べ物を運ばなければなりません。国の倉庫に食べ物・弾薬・燃料を備え、母港で輸送船団に積み、部隊のいる島へ運びます。相手の市場では買えません。蓄えが尽きると飢え、戦う力が落ち、亡くなる兵も出ます。軍の画面で補給の蓄えと飢えを確かめてください。" %}

{% translate "敵を追い出して自国の部隊だけになったマスは占領できます。土地と住民は元の国のままですが、施設は働き手が通えず、売ることもできません。占領したマスの在庫を、その場の部隊の補給に取り立てられます。取り立てるかは部隊ごとに選べます。" %}

{% translate "首都を占領されると降伏し、首都を落とした相手とは停戦になります。体制が倒れたら、軍の画面で体制を選び直します。ほかの国との戦争は続きます。停戦中も占領と取り立ては続き、講和で解けます。捕らえた捕虜には国防費で食べ物を用意します。捕虜は講和で返せるほか、長く捕らえたままにはできず、決められた期間で帰ります。" %}
