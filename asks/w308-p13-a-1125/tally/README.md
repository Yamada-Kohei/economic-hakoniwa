# probe13 の集計（w308_p13_tally.py）

使い方: `python w308_p13_tally.py <probe13 の出力が入ったフォルダ>`
（probe13-A-plan-s17-t1200.json のような名前の 32 本を読む。組ごとに 8 本そろっていなくても動くが、比べはそろった分だけになる。）

## 比べの作り

- 4 組（A・W・K2・WK）とも同じ列・同じ単位で出す（#4834 の「同じ単位」）。金額はその島の通貨で、種が同じ組どうし（A↔W、K2↔WK）の比べでは島がそろうので中央値の比べが目安になる。A 系と K2 系の金額の中央値を直接比べない。
- 表 1 は倒産した会社（facility_bankrupt のみ。foreclosure_demolished は同じ会社の続きなので数えない）の直前ターンの様子。probe12 の集計の「倒産＋取り壊し」の件数（142 など）は会社数の 2 倍になっている点に注意（1 社 = 倒産 1 件 + 取り壊し 1 件）。
- 表 2 は panel_ids で会社を追い、「後に倒産した会社」の会社 × ターンと「残った会社」の会社 × ターンを分ける。倒産した会社の買い増しの速さ（added_100）が、同じ組の残った会社と比べてどうかを見るのが主眼。
- 「買いすぎ」と読む材料: 表 1・表 2 で、建て増しあり（W・WK）の倒産した会社の買い増し（cum_added・added_100）が、建て増しなし側の倒産した会社と自組の残った会社の両方をはっきり上回り、借金・利息・資本費の重さが倒産の前に積み上がっていること。買い増しが目立たず、使い具合と現金収支が市場全体（表 4 と probe12 の world）で落ちている形なら、運賃・価格側の読みになる。判定そのものは会議でする。
- 表 4 の「0.5 隻未満の割合」と freight_paid の割合は観測。**条件 4 の 2 件（K2→WK の n の増えの残り、上位 2 割の外貨切れの相手先別）は、この集計でも閉じない（#4835 の 4）。**
