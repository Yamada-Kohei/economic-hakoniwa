# W-308 (c) 外貨で切られた量の相手先別（掲示板 #5061 の頼み 2、#4816・#4820 の (c)）

WK の版（w308-wk-1124 と同じ commit e7b12b55・同じパッチ wk-on.diff）で、
probe12 に外貨の内訳の記録だけを足した台本 w308_fxsplit_probe.py。
まず plan 種 17〜24 のうち 2 種（17・18）× 1200 ターン。

## 足した記録（probe12 の列は全部そのまま）

- fxa（島 -> marks と同じ並びの dict）: 割り振りでお金で削った重さ（probe12 の
  am と同じ量）を、相手先の圏（bloc）別に割った物。帰属は、輸入の注文
  （_import_order）が圏ごとに呼ばれるとき、その呼び出しの bloc に (島, 商社, 財)
  の plan の cut_money を重さで寄せる。plan は 1 つなので帰属はそのターンの
  最初の呼び出しだけ（同じ財を複数の圏から入れる商社では最初の圏に寄る近似）。
- fxu（島 -> marks と同じ並び）: am のうち fxa に帰属できなかった残り
  （注文の呼び出しに届かなかった分）。fxa の合計 + fxu = am になるよう残す。
- bloc_hist: [ターン, 圏 id, 通貨の島, 加盟島の並び]。fxa に出てきた圏の通貨と
  顔ぶれが変わったときだけ（相手先の島を読むため）。

## 読み方

- (c) の問い: 豊かな島の外貨の詰まりで、切られた量はどの圏・どの通貨の島に
  向けた輸入で起きているか。fxa を圏 id で集め、bloc_hist で通貨の島と
  加盟島に直して読む。
- 割り振りの対象外（計画経済の島）は probe12 と同じく 0。
- 注文の段階でさらに切られる分（money_left の不足）は am の定義に含まれない
  ので、この記録にも含まれない（probe12 の am と揃えた）。

## 確かめたこと

- WK の版＋パッチで種 17・12 ターン回し、fxa の合計 + fxu が am と島ターン
  ごとに一致すること、bloc_hist が出ることを手元で確認（置く前に記す）。
