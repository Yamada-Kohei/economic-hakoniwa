# H-7: 500 ターン目の写しの往復で、どの鍵が最初に割れるか（掲示板 #5811・#5876・#5882・#5888）

速くする束（W-236）の残り H-7 の次の一手。対照（#5876、受付の仕事 711 と
724）で「写しなし full 同士は別機械でも 200/200 一致、人口のずれ中央・
最大とも 0%」と分かり、#5546 の全セル割れは写し・復元の側が状態を落として
いることで説明がつく、と絞られた。先生の本命の仮説は「写しの外にある
次番号カウンタ」（#5552 の (a)）。

この包みは、同じ 500 ターン目から 2 本に分け、world_to_dict を鍵ごとに
比べて「最初に割れたターンの、最初に違う鍵」を出す（#5811 の短い包み）。

## 構成

- 版: main の df9d61a0 に固定（ask.json の commit）
- 場面 1 つ（open）× 種 1 つ（1）。500 ターンまで回して 2 本に分け、
  501〜510 ターンまで比べる + report
  - straight: 500 ターン目で写しをファイルに書き（中身は測りの写し
    snapshot_dict）、自分は写しを通さずそのまま続ける
  - resume: 別の実行で、写しのファイルを読んで作り直してから続ける
    （モジュール側の状態が混ざらないよう、2 本は別のプロセスで回す）
- 提出は claude-hakoniwa-2。本実行は受付に委ねる（この包みの置き場では
  回さない）。

## 比べ方

- 両本とも、500 ターン目（resume は復元直後）と 501〜510 の各ターンの
  終わりに world_to_dict を取る。写すときは型と鍵の並びを保つ形にする
  （tuple は tuple、数字の鍵は数字の鍵として残す。JSON の往復で型が
  変わる所そのものが (b)・(d) の証拠になるため）。
- report はターン順に比べ、最初に割れたターンで、通しの鍵の並び順に
  辿って最初に違う鍵を出す。比べるのは値だけでなく、鍵の集合・鍵の
  並び・値の型まで含む。
- あわせて次番号カウンタ類の値を、500（復元直後）と最初の差のターン
  （割れなければ最終ターン）で両本とも記録する。拾うのは: 世界の ext の
  中の seq / *_seq（貿易の bloc・contract・shipment、外交の treaty・war、
  軍事の seq など）、島ごとの economy の bond_seq・loan_seq・firm_seq、
  島の ext の facility_seq と ext の中の seq / *_seq。

## 成果物の読み（定型、#5882・#5888）

report には必ず次の 2 行を入れる:

- **差の性質 1 行**: 最初の差鍵が「ゲーム値の差」か、「外部表示・
  キャッシュ・順序の側（鍵の並び・型だけの差）」かを、道筋と種類つきで。
  鍵そのものが片側にだけある場合は「状態の欠落」としてゲーム値の側に
  数える。log の中の差は表示・記録の差として分ける。
- **次番号カウンタ値 1 行**: 世界段のカウンタは値をそのまま（差があれば
  通し/戻しの両方）、島別の欄は合計と「全島一致」か「差のある島の数」を
  1 行に。差がなくても値は残す。島別の差の詳細は report の下の表に出る。

## 読み方

- 500（復元直後）から割れていたら: 落ちているのは往復そのもので失われる
  状態。(b) 鍵の型と順・(d) 型の変化、または写しに入らない欄が当たり。
- 501 以降で割れたら: 往復で失われた状態が、そのターンの処理で初めて
  効いた形。最初の差鍵と、カウンタの差の有無で (a) 次番号カウンタ →
  (b) 鍵の型と順 → (c) 読み込みで作り直す覚え の順に切り分ける。
- 510 まで割れなかったら: この範囲では落ちる状態は見つからなかった。
  割れがもっと後なら、比べるターン数（--extra）を延ばした包みが要る。
- report の終了コードは、比べが済めば割れたかどうかによらず 0
  （割れること自体が測りの成果なので、仕事の失敗とはしない）。

## 煙確認（配置時にまず回す短い確認）

small・種 1・写しは 5 ターン目・続き 3 ターン（比べは 5〜8 ターン目）で
straight / resume / report を回し、(1) 両本が落ちずに dump と counters が
出ること、(2) report が「最初に割れたターン・最初の差鍵・差の性質・
次番号カウンタ値」の行を出すこと、を見る。本実行（open・500+10 ターン）
は受付を通して回す。
