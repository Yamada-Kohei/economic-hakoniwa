## 分布の注記（同じ記録から）

数え直しの土台にした kn の値の分布（nt=1 かつ印 n の全数の中）:

- K2（17,348）: kn = 3.0 が 16,383（94.4%）、kn = 0 が 823、1 <= kn <= 2 が 39、kn < 1 の
  小さい段が 103、記録なしが 63。
- WK（28,648）: kn = 3.0 が 28,174（98.3%）、kn = 0 が 370、1 <= kn <= 2 が 10、
  kn < 1 の小さい段が 41、記録なしが 53。

つまり集計の n のほぼ全部は「標準の見積もり運賃の 3 倍でも引き合う財がある」島ターンで、
kn は GRID の上限 3.0 に張り付いている。上限を 2.0・1.5 に締めると n は段階的に
減るのではなくほぼ消える（K2: 16,422 → 39 → 18、WK: 28,184 → 10 → 6）。
物差しの緩さは上限の値そのものより、「引き合う財が 1 つでもあれば kn が上限まで
上がる」という kn の作り方の粗さに出ている、というのが記録の指す形。
