# W-308 条件 4 の n の数え直し（島の戻り有無で分ける）

材料: probe13 の船団 panel（受付の仕事 357〜388）と probe12 の n 記録（仕事 251〜282・288・289）。
probe12 と probe13 は同じ commit・種・パッチで同じ世界を回した物（probe13 の note）で、
突き合わせの検算として、両者の failures（島・ターン・種別）が K2・WK とも全 8 種で完全一致した。

## 定義と手順（n を見る前に固定。#5081/#5083）

- 「戻った」: 島ごとに、最終窓（1101〜1200T）の船団の中央値が、その島の基準窓
  （501〜600T、後半の痩せが始まる直前の直近 100T）の船団の中央値以上に戻っている島。
  列は probe13 panel の fleet（1000 分の 1 隻）で両窓とも同じ。A/K2 基準との横比べは使わない。
- 中央値: 窓内のターンごとの船団（海運業が無いターンは観測なし）を並べた通常の中央値。
  偶数個なら中央 2 値の平均。
- どちらかの窓で観測が 100 件に満たない島は判定対象から外す（理由別に数を出す）。
- 判定順序: (1) 基準中央値を出す → (2) 戻った／戻っていないに分ける → (3) 各群で n の
  消えた／残ったを数える。n は nt=1 かつ印 n、1 <= kn <= 3.0（#4847・kn 再集計と同じ）。
- n の消えた／残った: 前 = 151〜1100T、最終 = 1101〜1200T。残った（前 >= 1 かつ最終 >= 1）／
  消えた（前 >= 1 かつ最終 = 0）／新たに出た（前 = 0 かつ最終 >= 1）／なし（両方 0）。

## 注記（集計した むぎ の読み）

- WK では、基準中央値が 0 より大きい島に限ると、戻った 66 島では最終窓の n は 0 ターン
  （残った島なし）で、n は戻っていない 210 島の側に残った（55 島・4,614 ターン）。
  「戻った島で n が消えた／残った」への答えは、この範囲では「消えた」。
- 「戻ったのに n が残った」7 島（554 ターン）は全部、基準中央値が 0 の島だった。
  501〜600T の時点で既に船団の中央値が 0、つまり後半に痩せた島ではなく、基準窓の時点で
  実質的に船が無かった島。この 24 島は定義上つねに「戻った」に入る（最終中央値 >= 0）ので
  戻り有無では分けられず、ここに n が残る理由はこの集計では未確認（船の無い島の常態か、
  kn の作り方側かは別の切り分けが要る）。
- K2（参考）では、基準中央値が 0 より大きい島でも、戻った島に n が残る例が 3 島・124 ターン
  ある（種 18・島 42、種 21・島 27、種 22・島 36）。WK では 0 だった。
- 対象外（WK 100 島）は最終窓の n が 18 ターンしかなく、判定の外に落ちた島に n の本体はない。
- 付録のとおり、最終窓の代表値を最終ターンの値・平均に変えても、WK の「戻った島で残った n」は
  554 ターンのままで、読みは変わらない。
