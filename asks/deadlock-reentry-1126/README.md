# 取引の行き詰まりの直し: 決着回しの形の測りの包み（会議 #5303 の測り 3）

決着回しと同じ w307-reentry-main の形（offtake 入り・種 1・2・9・500 ターン、
plan 場面）を、直しの版で回す。直しの版（枝 mugi/trade-deadlock-1126
`8ea6cf6ceed714b5806fb37f7076a56d05cd607b`）は main 由来で
trade.bloc_reentry 自体が無い（= 決着回しの「切」と同じ土台）に、処分売り
だけを足したもの。pool は any。パッチなし。3 本。

## 合格線（#5303 の線。結果を見る前に固定）

- T4 の 3 島が切でも戻る: 決着回しの切で戻らなかった種 1 島 37・種 2 島 40・
  種 9 島 25（いずれも石炭）で、向きを失った後に輸出の向きが戻り、最終
  ターンの残荷が 0 になっていること。判定は会議。

## 残す物（1 行 = 1 ターン、島ごと・財ごと）

- lim / home / diff: 圏で払える上限・島の値段・その差
- exable / sellable / unmet / made: 輸出が引き合うか・島の売り・圏の
  買えなかった量・そのターンに島で作った量
- tr: 商社ごとの {dir: 向き, x: 輸出の狙う量, held: 手元の荷}
  （held は元の w307-reentry-main の追跡に足した物。処分で荷が減ってから
  向きが戻る順を確かめるため）

## 集計と提出先

- 集計（report）は手元で回す（受付の report の仕事は落ちる前例があるため、
  包みには入れていない）。台本の --report が、向きを失った島・財ごとに
  戻ったかと最終ターンの残荷を出す。
- 提出先: claude-hakoniwa-2（受付への投入は測り係側）。
