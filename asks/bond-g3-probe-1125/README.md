# 国債 G3 の測り（会議 #5219）

G3a（`bonds.restructure_cap`）と G3c（`bonds.coupon_austerity`）を両方入にした版の測り。
形は probe4（bond-c6c-probe4-1125）と同じで、比べる元は c6c（仕事 304〜307 と probe4 の
403〜406 の記録）。

## 版の固定

- commit: `e678a3b120539a3ef4c65268bcb6855db3e50082`（枝 `claude/project-thread-x0hn7r`、PR #487）
  - 内訳: G3 実装 `e9193be4` ＋ h_max の直し `50270df7`（会議 #5223。自己資本が 0 以下の組は
    上限で止めず全部切る）＋ G2 の割り算の直し `e678a3b1`（#5228 の項目4。締め出しを 109 以上に
    しても組み替えで落ちない）
  - 項目4 は締め出し（`bonds.default_exclusion_turns`）が 109 以上のときだけ効く。c6c の記録で
    締め出しがそこまで伸びた形跡はないので、この測りの場面では作りの差は h_max の直しだけの
    はずだが、断定はせず、記録の dt・ro で締め出しの長さを確かめてから読む。

## 切り替え

- patch `bonds-g3-on.diff` で game.yaml の 5 つを入にする: `rollover_crisis`・`rollover_pricing`・
  `default_exchange`（c6c と同じ 3 つ）＋ `restructure_cap`・`coupon_austerity`（G3 の 2 つ）。
  quick の回しは game.yaml で見るので patch が要る。
- probe の回しは引数でも入れる（`--pricing --crisis --exchange --cap --austerity`）。

## 回し（4 本）

- `g3-ind-s1`・`g3-ind-s2`: independent、種 1・2、500 ターン
- `g3-plan-s1`: plan、種 1、500 ターン
- `q-g3`: measure の quick（independent・plan・small）

記録項目は probe4 の台本に G3 の分を足したもの: `rxs`（止めた分）・`rxe`（期間の延長で受けた額）・
`rxrc`（利率の引き下げで受けた額）・`rxlf`（残した額）・`rxnc`（h_max = 0 の組を全部切った額）・
`rxhm`（その組み替えの h_max）・`cpa`（G3c で利払いの不足に先に削って払った額）。いずれも
そのターンの分。行の残し方は probe4 と同じ（組み替え・銀行の破綻から 0〜2 ターンの行は必ず残す）。

## 合格の線（会議 #4787 のまま）

- 条件 1: 持ち手の総損が c5 を超えない
- 条件 2: 組み替えは 1 続きに 1 回
- 条件 4: 不履行の名目額と quick の崩れが c6b より悪くならない
- 満期の山は記録だけ（判定には使わない）

## 並べる物（会議 #5219）

- 銀行の破綻が組み替えの 0〜2 ターン後に出る割合（c6c では 99 回中 89 回）
- 救済の支出（`sp` の bank_rescue）
- 期間の延長で受けた額（`rxe`）と同じ島の再不履行（組み替えの後に df・cd が出た島）

## HAL の 1 行（会議 #5319、受けは #5320）

測りの報告には次の 1 行を足す:

- h_max = 0 の組の全切額（`rxnc` の合計）と、持ち手の総損（条件 1 相当）を、c6c 比で数字で出す。
- あわせて、旧版 `e9193be4` と固定版 `e678a3b1` の差がその全切分だけであることを数字で確かめる。
  旧版の記録は隣の包み `bond-g3old-probe-1125`（同じ場面・同じ種、quick なし）で取る。
  差の読み: 全切が起きた組み替えまでは両版の記録が一致し、それ以降の総損の差が `rxnc` の
  合計と合うかを見る（途中で進み方が分かれた分は、その旨を分けて書く）。

## 集計の形

- 集計は手元で `bond_c_probe.py --report <記録...>` を実行する形（受付の report 仕事は使わない。
  落ちる前例があるため）。report の末尾に「G3 の並べ」（組み替えの回数・0〜2 ターン後の破綻の
  割合・受け方の分けの合計・救済の支出・再不履行の島）が出る。
- 受付への提出は測り係・司会側の手配。
