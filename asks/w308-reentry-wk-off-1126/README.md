# W-308 海運再参入の測りの包み（WK・切）

倒れた海運の会社が戻る道（切り替え `trade.shipping_reentry`、W-308）の測り。
司会の頼みは掲示板 #5526、受けは #5528。線は結果を見る前に #5475 で固定したもの。

## この包みの組

K2＋建て増し（kprime-expand-on.diff）。再参入は切。

残りの組は同名の別包み（w308-reentry-{a,w,k2,wk}-{off,on}-1126、全 8 包み）。

## 版の固定

- 対象コード: commit `266cf73d192a33b01b9e91f7940f7b053d6d0cfb`
  （枝 `mugi/w308-shipping-reentry-1126` の機能コミット、PR #526 の枝先。
  その後に積まれた試験追加は計算に影響しないので、版はこのコミットに固定する）
- 場面 plan、種 17〜22、1200 ターン。probe14 と同じ世界・同じ種。

## 切の版を probe14 から流用しない理由（#5526・#5528 の確認結果）

probe14 の版は今回と同版ではない。A・W 組は `127e6dff`（PR #497 のマージ点）、
K2・WK 組は `e7b12b55`（枝 claude/project-thread-k6zgl8）＋パッチで、
今回の版とは対象コードと設定の両方が違う（A 組側でも hakoniwa_core の
9 ファイルと game.yaml に差分、K 組側では 23 ファイルに差分）。
よって #5528 の決めどおり、切の組も同じ版（266cf73d）で回す。
比べは常に同じ版の中の入／切で行う。

## 台本

- `w308_reentry_probe.py`: probe14 の `w281_probe14.py` を土台に、再参入の測りに
  要る記録だけを足したもの。panel の列（probe13 の 16 列＋運賃の側の 7 列）は
  probe14 と同じ。追加の記録は次の 3 つ:
  - `transfers`: 島ごとの移管の台帳（貿易の状態の shipping_transfers。施設の
    番号・買い手・移ったターン・船団の組）
  - `island_series`: 海運業の有無にかかわらず島ごとにターンごと記録する列
    （地元の運んだ量／他国・借りの船の運賃／船がなくて運べなかった荷／
    造船所の有無／港の有無）
  - failures の snap に `shipyard`（倒産直前のターンに造船所があったか）
- `w308_reentry_tally.py`: 集計（下の表 R1〜R4）。全 8 包みの出力を集めて回す。

## 合格線（#5475。結果の前に固定）

1. 倒産の判定から、後継（0 では買い手、2 では後継の会社）が初めて荷を運ぶまでの
   ターン数（#5469。取り壊しまでの約 11 ターンの待ちも含む物差し）
2. 900・1200 ターン時点で、後継がまだ荷を運んでいない島の割合
   （分母は 151 ターン開始時の全島。#5467）
3. 初回の倒産までのターン数と累積の割合（#5452・#5465 の窓）
4. 運んだ量は切より減らない
5. quick の崩れが種のゆらぎの内（従来の quick 集計で別に見る）

## 測る項目の追加（#5480・#5484・#5485 で受けた分）

- 移管の台帳: 引き継ぎがあった島は「移ったターンと買い手」を残し、
  買い手のもとでの初輸送を拾う（台帳は台本が `transfers` に出す）
- 倒産から 100 ターンの窓: 初回倒産から 100 ターン追えた島について、
  「運ぶ注文があったターン数」と「地元の海運の運んだ量が 0 だったターン数」
- 造船所のある島／無い島に分けて表を出す（#5484）

## 表の形（集計の出し方）

- 表 R1（倒産と復旧）: 組ごとに、初回倒産の島数・倒産ターンの中央値・
  900／1200 までの累積の割合・復旧までのターンの中央値・
  900／1200 時点の未復旧の割合
- 表 R2（100 ターンの窓）: 組 × 造船所の有無ごとに、追えた島数・
  注文があったターン数・うち地元の運んだ量が 0 のターン数と割合
- 表 R3（移管の台帳）: 組ごとに移管の件数・買い手の内訳・
  引き継ぎから初輸送までの中央値
- 表 R4（運んだ量）: 組ごとに会社 × ターン数・運んだ量の合計・中央値
- panel の運賃の側の表（probe14 の表 5〜7 の形）が要る場合は、panel の列が
  同じなので probe14 の集計台本がそのまま使える

## 数え方の注意

- 初回倒産は 151 ターン以降の判定（facility_bankrupt）だけを数える。
  151 より前に倒れた島は、分母（151 開始時の全島）には入るが、
  初回倒産の数には入らない。
- 「運ぶ注文があったターン」は、地元の運んだ量 > 0、または船がなくて
  運べなかった荷 > 0（再参入入のときだけ記録される）、または他国・借りの船の
  運賃 > 0、のどれかが成り立つターン。切の組では 2 つ目が残らないので、
  切の注文ターンは下振れし得る（比べはその前提で読む）。
