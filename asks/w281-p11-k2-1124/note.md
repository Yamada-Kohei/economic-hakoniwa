# W-281 / W-308 の測りの下地: probe11 の K2（plan 種 17〜24 × 1200T、8 本）

- 頼み元: スレッド「船を長い借りで買えるようにする」（W-281、C1）。会議の W-308 レビューの中間のまとめ 3・4。
- K2 = #399（e7b12b55）+ kprime（K2。gap2k の K2 と同じ）。読むだけの調べで、印は probe9・probe10 と同じになるはず。
- 足した記録: 割り振り（_allocate）で扱える重さで削った重さ・お金で削った重さ・割り振った重さ（島ターンごと）、雇いたい人数に届かない人数、扱った重さ。probe10 の注文の有無・島の豊かさも入っている。
- 使い道: A で扱える重さに切られた島ターンを固定（コホート）し、W-308 を入れた版（W・WK）で、その島ターンが「扱える重さだけ・お金だけ・両方・切られていない」のどれになったかを量で分ける。集計の台本は W・WK の記録が揃ってから置く。
- 出力の JSON は 1 本数 MB。集計に使うので共有フォルダへ写してください。
