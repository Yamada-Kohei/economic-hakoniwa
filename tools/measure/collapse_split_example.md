# 崩れの表を分ける道具の出力の例

材料: 既存の集計の 1 組（場面 small・種 1・300 ターン、main 6f4c4ba8 で
hakoniwa_core.simulate --gate --out --save を回した結果と写し）。
命令: python tools/measure/collapse_split.py <結果のフォルダ>

## 崩れの分け方（240 ターンの前後・発行国の体制ごと）

境目は 240 ターン（海外の商人が去るターン。境目のターンは「後」）。
発行国の体制は、結果の横の写し（最後のターンの状態）から引いた。
写しの無い結果は「不明」に分け、圏が複数ある世界は加盟国のいちばん多い圏の
発行国で代表させた。

| 組 | 崩れの合計 | 発行国の体制 |
|---|---|---|
| small-s1-t300 | 2 | mixed（発行国は島 2） |
