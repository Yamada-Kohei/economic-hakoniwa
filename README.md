# 経済版箱庭諸国

箱庭諸国の流れをくむ、ブラウザで遊ぶ島の育成ゲームです。農業と各種の工業によるサプライチェーン、
市場と通貨、価格の決まり方、市場経済から計画経済までの経済体制、陸海の軍事を遊べるようにすることを
目指しています。既存の箱庭諸国のコードは使わず、新しく書いています。

いまは **フェーズ3-1（貿易と為替）** です。建国して島を作り、施設を建てて
鉄鉱石 → 鋼鉄 → 機械 → 新しい工場、という生産の連鎖を回せます。人は町から通勤して働き、
町は働き口の近くに自然に形成され、村・町・都市・大都市へと発展します。
フェーズ2-1 から、資源は施設ごとの在庫として市場（板寄せ）で売り買いされ、値段は売れ行きで動きます。
就業者は賃金を受け取って食料や消費財を買い、政府は税を集めて公務員の賃金や公共事業に使い、
足りなければ国債を発行します。お金はすべて複式の帳簿で動きます。
フェーズ2-2 で銀行・融資・国債の入札・倒産と民営工場の参入が、フェーズ2-3 で道路・鉄道・上下水道・
送電網の整備度と公共事業、学校と大学（教育水準と技術者）、経済・市場・施設・財政・金融の画面が加わりました。
フェーズ3-1 で、島どうしの貿易が始まりました。港と輸送船で物を運び、商社が値段の差を見て自動で
輸出入し、政府は貿易圏を作って入ったり、ほかの国と二国間契約を結んだりします。通貨は国ごとに1つで、
為替のレートは売り買いで動きます（変動相場）。初めの 120 ターンは、海外の商人が石炭・鉄鉱石・鋼鉄・
機械・建材を割高な値段で売りに来ます。

## 遊び方

1. 「登録」でアカウントを作ると、建国の画面に進みます。
2. 世界マップの区画、島の形（描くか「ランダムな形」。離れ小島も描けます）、地形の変更、地下資源（2つまで）、
   首都、体制（政治体制・元首制度・経済体制）、名前、地名の様式（日本風・イギリス風など）を決めて
   「建国する」を押します。鋼鉄には鉄鉱石と石炭の両方が必要で、鉱山は1国2か所までです。
3. 島の画面で地図のマスを押し、建設・撤去・施設名や地名の変更・優先度や会計方式の変更の命令を追加します。
   税率・予算・失業手当・国の倉庫の売買・電気料金の上限などの命令もあります。
   インフラの工事（道路・送電網など）と開発禁止区域は「地図でマスを選択して出す命令」から、マスを続けて
   選んで追加します。
4. 命令はターンの更新で上から実行されます。1ターンに実行できる命令の数（行政力）は原則1つで、
   中央省庁の公務員が増えると最大5つまで増えます。名称の変更は数に含みません。
   何が起きたかは「出来事」とターンログで読めます。

くわしいしくみは画面の「手引き」にあります。

## 動かし方

Python 3.12 以上が要ります。

```sh
pip install -e ".[dev]"          # 1. 必要なものを入れる
python manage.py setup_dev       # 2. DB とサンプルの世界（島3つ）を作る
python manage.py runserver       # 3. http://127.0.0.1:8000/ を開く
```

開いたら「登録」から建国できます。ターンは `python manage.py run_turn --force` で進めます。

管理画面（http://127.0.0.1:8000/admin/）を使うには `python manage.py createsuperuser` で管理者を作ります。
管理画面では島を足したり、ターンを進めたり、バックアップから巻き戻したり、掲示板の書き込みを非表示にしたり、
登録の記録（同じ接続元からの重複登録を止めるためのもの）を消したりできます。

### よく使うコマンド

| コマンド | すること |
|---|---|
| `python manage.py run_turn` | 次の更新時刻になっていれば1ターン進める（cron などから数分おきに呼ぶ） |
| `python manage.py run_turn --force` | 時刻に関係なく今すぐ進める |
| `python manage.py rollback_turn 12` | ターン 12 の更新前の状態に戻す |
| `python manage.py check_defs` | 定義データ（パック）を検査する |
| `python manage.py create_sample_world --islands 50` | 試験用の島を足す |
| `python -m hakoniwa_core.simulate --islands 50 --turns 300 --autoplan` | 画面も DB もなしで、標準の計画で命令を並べながらターンを回す |
| `pytest` | 自動テスト |
| `ruff check . && ruff format --check .` | 書式と誤りの検査 |

### データベース

既定では SQLite（`db.sqlite3`）を使います。公開サーバーには PostgreSQL を勧めます
（ターン更新中も画面からの読み書きが止まりにくいため）。

```sh
pip install -e ".[postgres]"
export DATABASE_URL=postgres://user:password@localhost:5432/hakoniwa
python manage.py migrate
```

公開サーバーでは `DJANGO_SECRET_KEY`、`DJANGO_DEBUG=0`、`DJANGO_ALLOWED_HOSTS` も設定してください
（`server/settings.py` の先頭に一覧があります）。リバースプロキシの後ろに置くときは、利用者の IP を読む場所を
`HAKONIWA_CLIENT_IP_HEADER`（例: プロキシが書き込む `HTTP_X_REAL_IP`）で指定します。同じ接続元から登録できる数は
`game.yaml` の `accounts.signups_per_ip` で変えられます（0 で無制限）。

50 島の世界で 1 回のターン更新は約 2 秒です（[docs/scale.md](docs/scale.md)）。

## 構成

| 場所 | 中身 |
|---|---|
| `hakoniwa_core/` | ルール本体（コア）。Django も DB も使わない純粋な Python |
| `packs/base/` | 本体パック。財・地形・施設・命令などの定義データと表示名 |
| `schemas/` | 定義データの形（JSON Schema） |
| `server/` | Django のサーバー。保存・アカウント・画面・JSON API・ターン更新 |
| `server/static/js/` | 画面の JavaScript（ビルド不要の ES モジュール）。`map/` 俯瞰図、`island/` マスの情報と命令の列、`founding/` 建国 |
| `game.yaml` | サーバー設定（使うパック、段の並び、ゲームの数値） |
| `docs/` | 改造のための説明書 |
| `tests/` | 自動テスト（`core/` と `server/`） |

依存は「ブラウザ → Django → コア → 定義データ」の一方向です。詳しくは [docs/architecture.md](docs/architecture.md)。
