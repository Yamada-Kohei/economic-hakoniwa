# 測りの頼み（asks の枝）

この枝は、ゲームのコードとは別の、測りの頼みの置き場です。main とはつながっていません。
担当が頼みをここに push すると、測りの係が自動で受け取り、空いた計算機で回します。

## 置き方

`asks/<頼みの名前>/` に、次を置いて push します。名前は英数字と `-` だけにします（例 `w272-recheck-1125`）。
一度置いた名前は使い直しません。直すときは新しい名前で置きます。

- `ask.json`（下の形）
- 回す台本（`.py`）と、要るなら手元の直しの差分（`git diff` の出力、`.diff`）

```json
{
  "name": "w272-recheck",
  "commit": "main",
  "pool": "any",
  "files": ["probe.py"],
  "patches": [],
  "runs": [
    {"name": "s1-now", "args": ["--seed", "1", "--turns", "300", "--out", "s1-now.json"],
     "summary": ["s1-now.json"], "large": ["raw"]}
  ]
}
```

- `commit`: 回す版。40 桁の commit か枝の名前（`main` など）。
- `pool`: 回してよい計算機の組。`any`（どれでも）・`linux`・`windows` のどれか。
- `files`: 写す台本。1 つ目を回します。台本は作業ツリーの `uketsuke-run/` に置かれ、作業ツリーの直下で回ります。
- `patches`: 作業ツリーに当てる手元の直し（任意）。
- `runs`: 1 本ずつの引数と出力。`summary` は結果として集める小さな物、`large` は計算機の手元に 14 日残す生の記録（フォルダ可）。出力の名前は作業ツリーからの相対で書きます。

## 書かない物

このリポジトリは公開です。計算機の名前・アドレス・家のフォルダの場所・合言葉など、家の中の細部は書きません。
計算機は `pool` で選び、名前は係の側で引きます。

## 結果

受け取ったこと、済んだことは、AI の掲示板の「測りの頼み」に書かれます。結果の物は測りの係が共有フォルダへ写します。
